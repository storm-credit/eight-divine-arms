# 《팔대신병록》 EP001 문체·시점·분량 카드 v1

상태: `pre-draft-locked / manuscript-locked`

## 1. 회차 기능

- 제목 기능: 참가하지 않은 이름이 서유휘의 생계와 사부 미스터리를 동시에 침범한다.
- 즉시 목표: 대련비를 온전히 받고 치료비 지출 없이 일을 끝낸다.
- 핵심 선택: 이름을 무시하지 않고 비무 운영소로 향한다.
- 작은 보상: 대련비 획득, 서유휘의 발자리 판독 능력 체감.
- 비용: 휴식과 다음 일거리 포기, 어깨 통증 가능성 이월.
- 화말 질문: 죽은 사부가 왜 현재 날짜의 추천인으로 남아 있는가.

## 2. 시점 잠금

- 서유휘 밀착 3인칭 제한 시점.
- 첫 장면부터 마지막 장면까지 시점 이동 금지.
- 독자가 아는 사실은 서유휘가 보고·듣고·비교한 범위를 넘지 않는다.
- 연무진의 생사와 추천서 진위는 확정하지 않는다.
- 무관주·제자·운영진의 속내를 서술자가 설명하지 않는다.

## 3. 권장 분량

- 본문 목표: 공백 포함 5,000~6,500자.
- 장면 수: 3장면.
- 장면 비중:
  - S1 대련: 45~50%.
  - S2 정산: 20~25%.
  - S3 명단 확인: 25~30%.
- 첫 10% 안에 돈을 받고 싸우는 서유휘의 현재 목표를 제시한다.
- 마지막 8%는 이름·추천인·수결 확인에 사용한다.

## 4. 문장 호흡

- 단문 자체는 허용하되 7어절 이하 문장 4개 연속 금지.
- 전투 공간과 상대 동작을 설명할 때 중문을 사용한다.
- 결정 순간에만 짧은 문장 사용.
- 한 문장 문단을 연속 세 번 사용하지 않는다.
- 대련 장면에서 `피했다. 막았다. 베었다.`식 동작 나열 금지.
- 서유휘의 판단과 물리 결과를 한 문장 안에서 자연스럽게 연결한다.

## 5. 전투 묘사 잠금

대련은 압도적 승리가 아니라 유료 실전 교정이다.

필수 순서:
1. 대련장 바닥과 거리.
2. 제자의 발·어깨·호흡에서 선행 징후 확인.
3. 서유휘가 공격선을 지우는 선택.
4. 접촉과 충격 전달.
5. 제자의 새 위치와 막힌 다음 발.
6. 다치지 않았지만 약점이 드러난 결과.

- 기술명 남발 금지.
- 검광·폭발형 내공 표현 금지.
- 서유휘는 상대를 망신주지 않고 돈값을 한다.
- 왼쪽 어깨의 미세한 불편은 노골적 부상 설명 없이 한 번만 심는다.

## 6. 풍경·생활 묘사

필수 감각 두 가지 이상:
- 닳은 대련장 바닥과 먼지.
- 땀·약재·목검 기름 냄새.
- 제자들이 숨죽이거나 동전을 세는 소리.

풍경은 분위기 장식이 아니라 다음 기능을 가져야 한다.
- 바닥 상태가 발자리 선택을 바꾼다.
- 무관의 형편이 대련비 흥정과 연결된다.
- 서유휘가 생계형 무인임을 설명 없이 보여 준다.

## 7. 서유휘 음성

- 돈·수선비·치료비를 구체적으로 계산한다.
- 허세보다 손해 방지가 먼저다.
- 관찰은 예리하지만 자신의 능력을 해설하지 않는다.
- 농담은 정산 장면에만 제한적으로 사용한다.
- 추천인 이름 확인 뒤 농담과 장황한 독백은 사라진다.

## 8. 정보 노출 상한

이번 화 신규 핵심 고유명:
- 서유휘
- 강남 비무
- 연무진

노출 금지:
- 천하팔대신병
- 천공팔기
- 강호기보록
- 반보문의 과거 정체
- 검편의 진품 여부
- 연무진 생존 확정

## 9. 화말 잠금

화말은 놀란 표정이 아니라 물리 증거의 병치로 끝낸다.

필수 이미지:
- 추천인란의 연무진 이름과 수결.
- 연무진이 죽은 뒤의 현재 날짜.

금지:
- `그는 아직 몰랐다`.
- `모든 것은 이때부터 시작됐다`.
- 사부가 살아 있다는 확정 서술.

## 10. 출고 Gate

- 첫 장면만으로 서유휘의 생계·무공·성격이 보이는가.
- 대련이 튜토리얼 설명이 아니라 실제 돈이 걸린 행동인가.
- 풍경이 발자리와 정산에 영향을 주는가.
- 단문 사슬 없이 박진감이 유지되는가.
- 마지막 수결이 다음 화 행동을 강제하는가.
- P0 정본·시점 오류가 없는가.
