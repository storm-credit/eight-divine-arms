# 《팔대신병록》 EP001~010 제목·화말 훅 잠금 v1

상태: `pre-draft-locked / manuscript-locked`

## 운용 원칙

- 제목은 사건 기능을 직접 드러내되 정답을 노출하지 않는다.
- 화말 훅은 놀람 표정이나 임의 중단이 아니라 다음 행동을 강제하는 정보·비용·관계 변화다.
- 동일한 훅 유형을 세 화 연속 사용하지 않는다.
- 완성 문장 원고가 아니라 기능 잠금이다.

| 화 | 잠금 제목 | 화말 훅 기능 | 다음 화 강제 행동 |
|---|---|---|---|
| EP001 | 참가하지 않은 이름 | 죽은 사부 연무진의 이름·수결과 현재 날짜 병치 | 운영소로 가서 등록 원본 확인 |
| EP002 | 없는 문파 | 반보문 명의 보증금이 이미 완납 | 보증금·전표 출처 추적 |
| EP003 | 빼앗긴 출전권 | 상품 검편에서 연무진의 장인 표식과 닮은 무늬 발견 | 공개 감정회 접근 |
| EP004 | 가짜와 진짜가 붙어 있다 | 조작된 표면 아래 진짜 장인의 낙관 확인 | 검편 반입 장부 열람 시도 |
| EP005 | 장부를 보려면 출전하라 | 보증금이 여러 지역 소액 전표로 분할 납부 | 전표 원본과 발행지 추적 |
| EP006 | 죽은 뒤에 발행된 전표 | 연무진 실종 뒤 발행된 장강 하류 전표 | 명단 조작 절차와 장강 연결 확인 |
| EP007 | 정석의 칼끝 | 소연후가 반보문을 과거 재난 기록에서 봤다고 밝힘 | 정보 대가를 건 비공식 대련 |
| EP008 | 읽어도 늦는다 | 반보문은 문파가 아니라 재난 현장의 임시 협력명 | 대표 등록·서명 비교 |
| EP009 | 진짜 수결, 가짜 대표 | 내부 장부는 정식 출전자가 된 뒤에만 열람 가능 | 출전 여부 결정 |
| EP010 | 출전한다 | 출전 계약 성립과 동시에 첫 대진 상대 또는 조작 장부 접근 시한 공개 | 비무와 조사를 동시에 시작 |

- EP002: 돈·절차형.
- EP003: 물건·수집형.
- EP004: 진위 반전형.
- EP005: 추적망 확장형.
- EP006: 시간 모순형.
- EP007: 라이벌 정보형.
- EP008: 세계관 의미 변환형.
- EP009: 선택 강제형.
- EP010: 계약·행동 개시형.

## 화별 종료 금지

- EP001: 사부 생존 확정 금지.
- EP002: 반보문의 과거 설명 금지.
- EP003: 검편 진품 확정 금지.
- EP004: 천하팔대신병 명칭 공개 금지.
- EP005: 배후가 단일 조직이라는 확정 금지.
- EP006: 장강으로 즉시 출발 금지.
- EP007: 소연후를 친구·악역으로 확정 금지.
- EP008: 어깨 부상 전모 공개 금지.
- EP009: 연무진이 모든 문서를 만들었다는 오인 확정 금지.
- EP010: 모든 피해 복구나 출전권 문제 완전 해결 금지.

## 제목 QA

- 제목만 읽어도 10화가 같은 문서 추적 사건으로 보이지 않는가.
- 이름·문파·피해·검편·장부·전표·라이벌·무공·서명·선택이 교차하는가.
- 제목이 지나치게 시적이거나 내용과 무관하지 않은가.
- 결말 핵심 용어인 천하팔대신병·개로무극을 조기 노출하지 않는가.

## EP010 화말 구체 조건

EP010은 `출전한다`는 결정 자체로 끝내지 않는다. 결정 직후 반드시 새 비용이 발생해야 한다.

허용 예:
- 첫 대진 시각이 장부 열람 가능 시간과 겹친다.
- 피해 참가자의 복구 조건이 서유휘 승패와 연결된다.
- 대표 등록자가 경기장 안에 있다는 단서가 열린다.

금지:
- “그렇게 그의 비무가 시작됐다.”
- 단순 참가 선언 뒤 종료.
- 검편을 즉시 상품으로 지급.
