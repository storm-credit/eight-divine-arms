# 《팔대신병록》 ACT 1 1~10화 장면 설계 v1

상태: `scene-design / manuscript-locked / no-finished-prose`

## 장면 운용 원칙

- 한 화 3~5장면.
- 장면마다 `장소 / 참여자 / 표면 목표 / 숨은 기능 / 전환 / 이탈 정보`를 기록한다.
- 완성 대사와 묘사는 쓰지 않는다.
- 1화는 세계관 설명보다 서유휘의 행동과 이름 도용 사건을 우선한다.
- 신규 고유명은 한 화 최대 3개.

# EP001 장면 설계

## S1. 작은 무관의 대련장

- 참여자: 서유휘, 무관 제자, 무관주.
- 표면 목표: 서유휘가 돈을 받고 제자의 약점을 드러내 준다.
- 숨은 기능: 생계형 무인, 비살상 실전 감각, 발자리 관찰 소개.
- 전환: 제자가 강하게 밀어붙이지만 서유휘가 다음 발을 막아 흐름을 끊는다.
- 이탈 정보: 서유휘는 화려한 고수가 아니라 살아남는 싸움을 안다.

## S2. 대련비 정산

- 참여자: 서유휘, 무관주.
- 표면 목표: 치료비·장비 수선비까지 받아 낸다.
- 숨은 기능: 돈·밥·빚 농담과 생활형 성격.
- 전환: 무관주가 강남 비무 참가 명단을 보여 준다.
- 이탈 정보: 서유휘는 참가 신청을 하지 않았다.

## S3. 명단 확인

- 참여자: 서유휘 중심.
- 표면 목표: 동명이인인지 확인.
- 숨은 기능: 사건 입구를 빠르게 확정.
- 전환: 이름·나이·무공 특징까지 서유휘와 일치.
- 이탈 정보: 추천인 연무진.

## 화말 이미지

- 죽은 사부의 수결과 현재 날짜가 한 화면에 놓인다.

# EP002 장면 설계

## S1. 비무 운영소 앞

- 참여자: 서유휘, 접수 담당자, 대기 참가자.
- 표면 목표: 이름 삭제.
- 숨은 기능: 강남 비무의 행정 구조를 행동으로 노출.
- 전환: 담당자는 본인 확인만으로 취소할 수 없다고 한다.
- 이탈 정보: 등록금과 문파 보증금이 이미 납부됨.

## S2. 장부 창구

- 참여자: 서유휘, 장부 담당자.
- 표면 목표: 신청서 원본 열람.
- 숨은 기능: 서유휘가 사람의 말보다 실제 장부 이동을 관찰하는 성격.
- 전환: 소속란 `반보문` 확인.
- 이탈 정보: 사부가 농담처럼 쓰던 이름.

## S3. 즉시 판단

- 참여자: 서유휘.
- 표면 목표: 없는 문파라고 밝힐지 결정.
- 숨은 기능: 조급하지만 계산하는 주인공.
- 전환: 누가 그 이름을 아는지 찾기 위해 모르는 척하기로 함.
- 이탈 정보: 반보문 명의 보증금 완납.

# EP003 장면 설계

## S1. 운영소 밖 충돌

- 참여자: 서유휘, 출전권 피해자, 피해자 가족.
- 표면 목표: 서유휘에게 명단 삭제 요구.
- 숨은 기능: 이름 도용이 단순 미스터리가 아니라 다른 사람의 현실 피해라는 점 제시.
- 전환: 삭제해도 피해자의 대진이 즉시 복구되지 않음.
- 이탈 정보: 장부 조작 증거가 삭제될 위험.

## S2. 대진표 대조

- 참여자: 서유휘, 피해자.
- 표면 목표: 조작 시각과 순서를 찾는다.
- 숨은 기능: 서유휘가 변명보다 피해 구조부터 보는 선택.
- 전환: 자신의 이름이 들어온 시각과 상품 장부 수정 시각이 비슷함.
- 이탈 정보: 두 조작이 연결됐을 가능성.

## S3. 상품 목록 게시판

- 참여자: 서유휘.
- 표면 목표: 상품 장부 수정 항목 확인.
- 숨은 기능: 수집형 장기 욕망 첫 점화.
- 전환: 부러진 검편의 표식이 연무진의 장인 흔적과 닮음.
- 이탈 정보: 검편과 사부 연결.

# EP004 장면 설계

## S1. 공개 감정회 입장

- 참여자: 서유휘, 경비, 참가자들.
- 표면 목표: 검편 접근.
- 숨은 기능: 참가자 권한을 이용한 능동적 진입.
- 전환: 백여울이 이미 감정 중.
- 이탈 정보: 서유휘보다 빠른 경쟁자 등장.

## S2. 백여울의 감정

- 참여자: 서유휘, 백여울, 공식 감정가.
- 표면 목표: 진위 판정.
- 숨은 기능: 백여울의 전문성과 독립 목적 소개.
- 전환: 표면 조작은 가짜지만 내부 결은 오래된 진품.
- 이탈 정보: 가짜와 진짜가 동시에 존재.

## S3. 접근권 충돌

- 참여자: 서유휘, 백여울.
- 표면 목표: 누가 먼저 만지고 기록할지 결정.
- 숨은 기능: 장기 로맨스보다 먼저 경쟁 구조 확립.
- 전환: 서유휘가 강탈하지 않고 감정 절차를 관찰.
- 이탈 정보: 내부 낙관은 진짜 장인의 것.

# EP005 장면 설계

## S1. 상품 장부 요구

- 참여자: 서유휘, 상품 담당자.
- 표면 목표: 검편 반입 경로 열람.
- 숨은 기능: 권리·접근권 세계관을 사건으로 보여 줌.
- 전환: 정식 참가자와 문파 보증인만 가능.
- 이탈 정보: 출전 여부가 조사권과 연결.

## S2. 보증번호 추적

- 참여자: 서유휘, 백여울.
- 표면 목표: 참가 장부와 상품 장부의 연결 번호 확인.
- 숨은 기능: 둘이 서로 다른 전문성으로 같은 문제 접근.
- 전환: 반보문 보증번호가 여러 문서에서 반복.
- 이탈 정보: 누군가 문파를 행정적으로 실재하게 만들었다.

## S3. 납부 내역

- 참여자: 서유휘, 금융 창구 직원.
- 표면 목표: 보증금 출처 확인.
- 숨은 기능: 돈이 곧 단서가 되는 수집·생활 세계관.
- 전환: 여러 소액 전표로 분할 납부.
- 이탈 정보: 조직적이지만 흔적을 분산한 방식.

# EP006 장면 설계

- 표면 목표: 열람료 벌기.

## S3. 발행일 확인

- 숨은 기능: 사부 생존 미스터리 진전.
- 전환: 사망 뒤 발행된 전표 존재.
- 이탈 정보: 최신 발행지는 장강 하류.

# EP007 장면 설계

# EP010 장면 설계

## 화말 이미지

# 1~10화 연독 체크

- 1화: 이름 도용과 죽은 사부 훅.
- 2화: 존재하지 않는 문파.
- 3화: 타인의 출전권 피해와 검편.
- 4화: 백여울·진위 미스터리.
- 5화: 출전해야 조사 가능.
- 6화: 사망 뒤 전표.
- 7화: 소연후와 첫 수 싸움.
- 8화: 주인공 성장 결함.
- 9화: 복수 배후 가능성.
- 10화: 출전 선택과 첫 대진.

## 원고 단계 감시

- EP001 첫 장면이 대련 설명으로 40% 이상 길어지지 않게 한다.
- EP002~003 행정 설명은 장부·피해자 충돌 속에서만 노출한다.
- EP004 백여울 외형 설명보다 감정 행동을 먼저 보여 준다.
- EP007 소연후를 압도적 천재로 과장해 서유휘를 무능하게 만들지 않는다.
- EP008 어깨 부상은 비극적 독백보다 실제 움직임 지연으로 표현한다.
- EP010 계약은 장문 법률문이 아니라 핵심 조건만 제시한다.
