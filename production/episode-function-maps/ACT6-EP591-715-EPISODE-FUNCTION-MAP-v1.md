## EP591~EP600 — 세 지역 장인 의뢰

블록 정본: 세 의뢰를 하나로 묶지 않고 병행. 보상·이월 단서: 의뢰서 필체 중 하나가 위조.

- **EP591** 목표: 세 의뢰를 하나로 묶지 않고 병행. / 선택: 서유휘는 안전한 관망보다 현장 진입을 택한다. / 서브·복선: 장인 인연망의 첫 단서를 현재 사건에 연결한다. / **훅:** 의뢰서 필체 중 하나가 위조
- **EP592** 목표: ‘세 지역 장인 의뢰’ 관련 당사자들의 이해관계를 확인한다. / 선택: 가장 강한 세력보다 가장 약한 피해자의 말을 먼저 듣는다. / 서브·복선: 장인 인연망에 첫 관계 충돌을 더한다. / **훅:** 공식 설명과 현장 증언의 시각이 어긋난다.
- **EP593** 목표: ‘세 지역 장인 의뢰’의 기능이나 진위를 작은 실험으로 검증한다. / 선택: 실패를 감수하고 직접 몸으로 확인한다. / 서브·복선: 무공·도구 효용을 한 단계 시험한다. / **훅:** 예상과 반대되는 물리 결과가 나온다.
- **EP594** 목표: 시간·부상·제도 압력이 동시에 커진다. / 선택: 한 가지 이득을 포기해 피해 확산을 막는다. / 서브·복선: 장인 인연망의 비용을 실제 손실로 바꾼다. / **훅:** 포기한 목표가 상대의 손에 들어간다.
- **EP595** 목표: 앞서 심은 단서 하나의 현재 의미를 밝힌다. / 선택: 확실한 사실과 아직 모르는 사실을 분리한다. / 서브·복선: 장인 인연망을 설치에서 증폭 단계로 올린다. / **훅:** 의뢰서 필체 중 하나가 위조
- **EP596** 목표: 처음 세운 목표가 충분하지 않았음을 깨닫는다. / 선택: 소유·승리보다 사용·책임을 새 목표로 삼는다. / 서브·복선: 장인 인연망의 의미를 변환한다. / **훅:** 새 목표를 막는 얼굴 있는 반대자가 등장한다.
- **EP597** 목표: 동료·적대자·사용자와 권리와 책임을 협상한다. / 선택: 상대의 독립 목적을 인정하고 거래한다. / 서브·복선: 장인 인연망의 관계 상태를 비가역적으로 바꾼다. / **훅:** 합의 밖의 제3 권리자가 나타난다.
- **EP598** 목표: 앞선 단서를 추격·대련·구조·탈취 동선에 적용한다. / 선택: 가장 빠른 승리보다 퇴로와 후속 선택을 남기는 승리를 택한다. / 서브·복선: 장인 인연망을 행동과 물리 결과로 증명한다. / **훅:** 승리한 방식이 다음 문제의 원인이 된다.
- **EP599** 목표: 블록의 핵심 선택을 실행하고 대립자의 마지막 수를 받는다. / 선택: 완전한 승리보다 이후 책임 구조가 남는 선택을 한다. / 서브·복선: 맥거핀의 의미를 증폭하거나 뒤집는다. / **훅:** 결산 직전 다른 해석을 뒷받침하는 증거가 나온다.
- **EP600** 목표: ‘세 지역 장인 의뢰’의 보상과 후유증을 결산하고 다음 구간의 문을 연다. / 선택: 얻은 것과 남은 책임을 분리해 기록하고 독점을 피한다. / 서브·복선: 장인 인연망을 다음 구간으로 이월하고 열린 질문 하나를 부분 회수한다. / **훅:** 다음 구간 ‘위조 재료 판정’의 징후가 현재 결과에서 드러난다.

## EP601~EP610 — 위조 재료 판정

블록 정본: 비싼 재료보다 출처를 선택. 보상·이월 단서: 위조품이 오히려 필요한 성질 보유.

- **EP601** 목표: 비싼 재료보다 출처를 선택. / 선택: 공식 허가를 기다리기보다 물리 흔적을 직접 확인한다. / 서브·복선: 석주안·임강현의 영구 비용의 출발점을 만든다. / **훅:** 위조품이 오히려 필요한 성질 보유
- **EP602** 목표: ‘위조 재료 판정’의 공식 기록과 현장 증언을 대조한다. / 선택: 기록보다 물리 흔적을 우선한다. / 서브·복선: 석주안·임강현의 영구 비용의 오인을 강화한다. / **훅:** 증언과 기록의 시간이 맞지 않는다.
- **EP603** 목표: ‘위조 재료 판정’을 대련·감정·실험 중 하나로 재현한다. / 선택: 남의 설명을 받아들이지 않고 재현 조건을 요구한다. / 서브·복선: 석주안·임강현의 영구 비용에 공정 단서를 추가한다. / **훅:** 성공했지만 다른 조건에서만 작동한다.
- **EP604** 목표: ‘위조 재료 판정’을 둘러싼 압박이 사람과 물건 양쪽에서 커진다. / 선택: 이득을 늦추고 피해 확산을 막는다. / 서브·복선: 석주안·임강현의 영구 비용에 비가역 비용을 남긴다. / **훅:** 막아낸 피해 뒤 더 큰 손실이 발견된다.
- **EP605** 목표: ‘위조 재료 판정’에 대한 첫 오해를 깨뜨린다. / 선택: 정답을 독점하지 않고 반론 가능성을 남긴다. / 서브·복선: 석주안·임강현의 영구 비용의 1차 회수를 만든다. / **훅:** 위조품이 오히려 필요한 성질 보유
- **EP606** 목표: ‘위조 재료 판정’의 표면 목적이 뒤집힌다. / 선택: 처음 원했던 보상을 포기하고 더 큰 문제를 잡는다. / 서브·복선: 석주안·임강현의 영구 비용을 다음 단계로 넘긴다. / **훅:** 새 목표의 즉시 비용이 드러난다.
- **EP607** 목표: ‘위조 재료 판정’ 관련 권리와 책임을 교환한다. / 선택: 자신에게 유리한 독점 조항을 지운다. / 서브·복선: 석주안·임강현의 영구 비용의 신뢰 비용을 높인다. / **훅:** 서명 직전 숨은 예외가 드러난다.
- **EP608** 목표: ‘위조 재료 판정’을 두고 현장 승부를 치른다. / 선택: 앞서 심은 정보로 승부하되 손상을 감수한다. / 서브·복선: 전투·수집 보상을 발생시킨다. / **훅:** 승리 직후 숨은 손실이 드러난다.
- **EP609** 목표: ‘위조 재료 판정’의 승패를 결정할 마지막 수를 둔다. / 선택: 보상보다 이후의 책임 구조를 우선한다. / 서브·복선: 석주안·임강현의 영구 비용을 상위 액트와 연결한다. / **훅:** 마지막 순간 다른 해석이 제시된다.
- **EP610** 목표: ‘위조 재료 판정’의 보상과 후유증을 결산하고 다음 구간의 문을 연다. / 선택: 얻은 것과 남은 책임을 분리해 기록하고 독점을 피한다. / 서브·복선: 석주안·임강현의 영구 비용을 다음 구간으로 이월하고 열린 질문 하나를 부분 회수한다. / **훅:** 다음 구간 ‘기갑 호심편’의 징후가 현재 결과에서 드러난다.

## EP611~EP620 — 기갑 호심편

블록 정본: 방어구를 병기 연결판으로 시험. 보상·이월 단서: 호심편 안쪽 맥로 표시.

- **EP611** 목표: 방어구를 병기 연결판으로 시험. / 선택: 당장의 이익보다 원인 확인을 우선한다. / 서브·복선: 실패작의 유효성을 인물·물건·제도 중 하나와 연결한다. / **훅:** 호심편 안쪽 맥로 표시
- **EP612** 목표: ‘기갑 호심편’을 지키려는 인물과 정면 대면한다. / 선택: 양보 가능한 조건과 양보할 수 없는 책임을 나눈다. / 서브·복선: 실패작의 유효성을 인물 갈등으로 바꾼다. / **훅:** 협상 대상이 진짜 결정권자가 아님이 드러난다.
- **EP613** 목표: ‘기갑 호심편’의 가설을 제한된 조건에서 실행한다. / 선택: 완전한 성공보다 실패 원인을 얻는 쪽을 택한다. / 서브·복선: 후반 회수에 쓸 물리 법칙을 남긴다. / **훅:** 결락된 조건 하나가 드러난다.
- **EP614** 목표: 상대가 규칙과 지형을 이용해 서유휘를 몰아붙인다. / 선택: 정면 승부 대신 책임이 남는 선택을 한다. / 서브·복선: 실패작의 유효성의 결함을 드러낸다. / **훅:** 선택 때문에 동료와 갈등한다.
- **EP615** 목표: 물리 단서나 절차 단서가 실제 의미를 얻는다. / 선택: 현재 행동에 필요한 만큼만 공개한다. / 서브·복선: 실패작의 유효성의 공정성을 확보한다. / **훅:** 호심편 안쪽 맥로 표시
- **EP616** 목표: 중간 결과가 처음 가설을 부정한다. / 선택: 실패를 숨기지 않고 계획을 다시 짠다. / 서브·복선: 실패작의 유효성의 오인을 수정한다. / **훅:** 수정된 계획에 필요한 대가가 제시된다.
- **EP617** 목표: 현장 동료와 역할과 실패 책임을 나눈다. / 선택: 지휘권을 독점하지 않는다. / 서브·복선: 실패작의 유효성을 협업이 아닌 선택의 문제로 만든다. / **훅:** 합의 밖의 변수가 들어온다.
- **EP618** 목표: 축적한 단서를 전투 동선에 적용한다. / 선택: 상대를 쓰러뜨리는 대신 목표물을 지키는 데 힘을 쓴다. / 서브·복선: 실패작의 유효성의 물리적 회수를 만든다. / **훅:** 보호한 대상이 예상과 다른 선택을 한다.
- **EP619** 목표: 이전 선택의 대가를 감수하며 결산전에 들어간다. / 선택: 자신의 실수를 숨기지 않고 공개한다. / 서브·복선: 실패작의 유효성의 다음 회수 지점을 만든다. / **훅:** 얻은 것보다 잃은 것이 먼저 보인다.
- **EP620** 목표: ‘기갑 호심편’의 보상과 후유증을 결산하고 다음 구간의 문을 연다. / 선택: 얻은 것과 남은 책임을 분리해 기록하고 독점을 피한다. / 서브·복선: 실패작의 유효성을 다음 구간으로 이월하고 열린 질문 하나를 부분 회수한다. / **훅:** 다음 구간 ‘심법 조율 잔편’의 징후가 현재 결과에서 드러난다.

- **EP702** 목표: ‘대규모 사용과 영구 비용’을 지키려는 인물과 정면 대면한다. / 선택: 양보 가능한 조건과 양보할 수 없는 책임을 나눈다. / 서브·복선: 석주안·임강현의 영구 비용을 인물 갈등으로 바꾼다. / **훅:** 협상 대상이 진짜 결정권자가 아님이 드러난다.
- **EP703** 목표: ‘대규모 사용과 영구 비용’의 가설을 제한된 조건에서 실행한다. / 선택: 완전한 성공보다 실패 원인을 얻는 쪽을 택한다. / 서브·복선: 후반 회수에 쓸 물리 법칙을 남긴다. / **훅:** 결락된 조건 하나가 드러난다.
- **EP704** 목표: 상대가 규칙과 지형을 이용해 서유휘를 몰아붙인다. / 선택: 정면 승부 대신 책임이 남는 선택을 한다. / 서브·복선: 석주안·임강현의 영구 비용의 결함을 드러낸다. / **훅:** 선택 때문에 동료와 갈등한다.
- **EP705** 목표: 물리 단서나 절차 단서가 실제 의미를 얻는다. / 선택: 현재 행동에 필요한 만큼만 공개한다. / 서브·복선: 석주안·임강현의 영구 비용의 공정성을 확보한다. / **훅:** 복구 불가능한 감각 손실
- **EP706** 목표: 중간 결과가 처음 가설을 부정한다. / 선택: 실패를 숨기지 않고 계획을 다시 짠다. / 서브·복선: 석주안·임강현의 영구 비용의 오인을 수정한다. / **훅:** 수정된 계획에 필요한 대가가 제시된다.
- **EP707** 목표: 현장 동료와 역할과 실패 책임을 나눈다. / 선택: 지휘권을 독점하지 않는다. / 서브·복선: 석주안·임강현의 영구 비용을 협업이 아닌 선택의 문제로 만든다. / **훅:** 합의 밖의 변수가 들어온다.
- **EP708** 목표: 축적한 단서를 전투 동선에 적용한다. / 선택: 상대를 쓰러뜨리는 대신 목표물을 지키는 데 힘을 쓴다. / 서브·복선: 석주안·임강현의 영구 비용의 물리적 회수를 만든다. / **훅:** 보호한 대상이 예상과 다른 선택을 한다.
- **EP709** 목표: 이전 선택의 대가를 감수하며 결산전에 들어간다. / 선택: 자신의 실수를 숨기지 않고 공개한다. / 서브·복선: 석주안·임강현의 영구 비용의 다음 회수 지점을 만든다. / **훅:** 얻은 것보다 잃은 것이 먼저 보인다.
- **EP710** 목표: ‘대규모 사용과 영구 비용’의 보상과 후유증을 결산하고 다음 구간의 문을 연다. / 선택: 얻은 것과 남은 책임을 분리해 기록하고 독점을 피한다. / 서브·복선: 석주안·임강현의 영구 비용을 다음 구간으로 이월하고 열린 질문 하나를 부분 회수한다. / **훅:** 다음 구간 ‘충돌 조율 결산’의 징후가 현재 결과에서 드러난다.

## EP711~EP715 — 충돌 조율 결산

블록 정본: 완성품보다 운용 원리를 확보. 보상·이월 단서: 연무진이 완성 목록을 들고 귀환.

- **EP711** 목표: 완성품보다 운용 원리를 확보. / 선택: 서유휘는 안전한 관망보다 현장 진입을 택한다. / 서브·복선: 실패작의 유효성의 첫 단서를 현재 사건에 연결한다. / **훅:** 연무진이 완성 목록을 들고 귀환
- **EP712** 목표: ‘충돌 조율 결산’의 기능이나 진위를 작은 실험으로 검증한다. / 선택: 실패를 감수하고 직접 몸으로 확인한다. / 서브·복선: 무공·도구 효용을 한 단계 시험한다. / **훅:** 예상과 반대되는 물리 결과가 나온다.
- **EP713** 목표: 앞서 심은 단서 하나의 현재 의미를 밝힌다. / 선택: 확실한 사실과 아직 모르는 사실을 분리한다. / 서브·복선: 실패작의 유효성을 설치에서 증폭 단계로 올린다. / **훅:** 연무진이 완성 목록을 들고 귀환
- **EP714** 목표: 앞선 단서를 추격·대련·구조·탈취 동선에 적용한다. / 선택: 가장 빠른 승리보다 퇴로와 후속 선택을 남기는 승리를 택한다. / 서브·복선: 실패작의 유효성을 행동과 물리 결과로 증명한다. / **훅:** 승리한 방식이 다음 문제의 원인이 된다.
- **EP715** 목표: ‘충돌 조율 결산’의 보상과 후유증을 결산하고 다음 구간의 문을 연다. / 선택: 얻은 것과 남은 책임을 분리해 기록하고 독점을 피한다. / 서브·복선: 실패작의 유효성을 다음 구간으로 이월하고 열린 질문 하나를 부분 회수한다. / **훅:** ACT 7의 첫 사건으로 이어지는 인물·물건·기록이 모습을 드러낸다.

## ACT 완료 Gate
- 모든 화에 서유휘의 선택 또는 그 선택의 직접 비용이 존재한다.
- 각 블록은 기존 질문을 하나 이상 부분 회수하고 새 질문은 최대 두 개만 연다.
- 추적·거래·감정·전투·구조·복원 중심 동사를 한 액트 안에서 교차한다.
- 장기 맥거핀은 설치·증폭·변환·회수 중 한 단계에 연결한다.
- 가까운 30화만 상세 비트로, 가까운 10화만 장면표로 확장한다.
