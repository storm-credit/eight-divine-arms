- **EP479** 목표: ‘빈 검집’을 둘러싼 압박이 사람과 물건 양쪽에서 커진다. / 선택: 이득을 늦추고 피해 확산을 막는다. / 서브·복선: 빈 검집과 부러진 검편에 비가역 비용을 남긴다. / **훅:** 막아낸 피해 뒤 더 큰 손실이 발견된다.

- **EP577** 목표: ‘신병 부속 단서’을 지키려는 인물과 정면 대면한다. / 선택: 양보 가능한 조건과 양보할 수 없는 책임을 나눈다. / 서브·복선: 빈 검집과 부러진 검편을 인물 갈등으로 바꾼다. / **훅:** 협상 대상이 진짜 결정권자가 아님이 드러난다.
- **EP578** 목표: ‘신병 부속 단서’의 가설을 제한된 조건에서 실행한다. / 선택: 완전한 성공보다 실패 원인을 얻는 쪽을 택한다. / 서브·복선: 후반 회수에 쓸 물리 법칙을 남긴다. / **훅:** 결락된 조건 하나가 드러난다.
- **EP579** 목표: 상대가 규칙과 지형을 이용해 서유휘를 몰아붙인다. / 선택: 정면 승부 대신 책임이 남는 선택을 한다. / 서브·복선: 빈 검집과 부러진 검편의 결함을 드러낸다. / **훅:** 선택 때문에 동료와 갈등한다.
- **EP580** 목표: 물리 단서나 절차 단서가 실제 의미를 얻는다. / 선택: 현재 행동에 필요한 만큼만 공개한다. / 서브·복선: 빈 검집과 부러진 검편의 공정성을 확보한다. / **훅:** 재료 목록 중 하나가 위조
- **EP581** 목표: 중간 결과가 처음 가설을 부정한다. / 선택: 실패를 숨기지 않고 계획을 다시 짠다. / 서브·복선: 빈 검집과 부러진 검편의 오인을 수정한다. / **훅:** 수정된 계획에 필요한 대가가 제시된다.
- **EP582** 목표: 현장 동료와 역할과 실패 책임을 나눈다. / 선택: 지휘권을 독점하지 않는다. / 서브·복선: 빈 검집과 부러진 검편을 협업이 아닌 선택의 문제로 만든다. / **훅:** 합의 밖의 변수가 들어온다.
- **EP583** 목표: 축적한 단서를 전투 동선에 적용한다. / 선택: 상대를 쓰러뜨리는 대신 목표물을 지키는 데 힘을 쓴다. / 서브·복선: 빈 검집과 부러진 검편의 물리적 회수를 만든다. / **훅:** 보호한 대상이 예상과 다른 선택을 한다.
- **EP584** 목표: 이전 선택의 대가를 감수하며 결산전에 들어간다. / 선택: 자신의 실수를 숨기지 않고 공개한다. / 서브·복선: 빈 검집과 부러진 검편의 다음 회수 지점을 만든다. / **훅:** 얻은 것보다 잃은 것이 먼저 보인다.
- **EP585** 목표: ‘신병 부속 단서’의 보상과 후유증을 결산하고 다음 구간의 문을 연다. / 선택: 얻은 것과 남은 책임을 분리해 기록하고 독점을 피한다. / 서브·복선: 빈 검집과 부러진 검편을 다음 구간으로 이월하고 열린 질문 하나를 부분 회수한다. / **훅:** 다음 구간 ‘검진·현상금 결산’의 징후가 현재 결과에서 드러난다.

## EP586~EP590 — 검진·현상금 결산

블록 정본: 문파 현상금을 감수하고 사용권 분리. 보상·이월 단서: 세 지역 장인이 동시에 의뢰를 보냄.

- **EP586** 목표: 문파 현상금을 감수하고 사용권 분리. / 선택: 서유휘는 안전한 관망보다 현장 진입을 택한다. / 서브·복선: 젊은 제자의 전승 선택의 첫 단서를 현재 사건에 연결한다. / **훅:** 세 지역 장인이 동시에 의뢰를 보냄
- **EP587** 목표: ‘검진·현상금 결산’의 기능이나 진위를 작은 실험으로 검증한다. / 선택: 실패를 감수하고 직접 몸으로 확인한다. / 서브·복선: 무공·도구 효용을 한 단계 시험한다. / **훅:** 예상과 반대되는 물리 결과가 나온다.
- **EP588** 목표: 앞서 심은 단서 하나의 현재 의미를 밝힌다. / 선택: 확실한 사실과 아직 모르는 사실을 분리한다. / 서브·복선: 젊은 제자의 전승 선택을 설치에서 증폭 단계로 올린다. / **훅:** 세 지역 장인이 동시에 의뢰를 보냄
- **EP589** 목표: 앞선 단서를 추격·대련·구조·탈취 동선에 적용한다. / 선택: 가장 빠른 승리보다 퇴로와 후속 선택을 남기는 승리를 택한다. / 서브·복선: 젊은 제자의 전승 선택을 행동과 물리 결과로 증명한다. / **훅:** 승리한 방식이 다음 문제의 원인이 된다.
- **EP590** 목표: ‘검진·현상금 결산’의 보상과 후유증을 결산하고 다음 구간의 문을 연다. / 선택: 얻은 것과 남은 책임을 분리해 기록하고 독점을 피한다. / 서브·복선: 젊은 제자의 전승 선택을 다음 구간으로 이월하고 열린 질문 하나를 부분 회수한다. / **훅:** ACT 6의 첫 사건으로 이어지는 인물·물건·기록이 모습을 드러낸다.

## ACT 완료 Gate
- 모든 화에 서유휘의 선택 또는 그 선택의 직접 비용이 존재한다.
- 각 블록은 기존 질문을 하나 이상 부분 회수하고 새 질문은 최대 두 개만 연다.
- 추적·거래·감정·전투·구조·복원 중심 동사를 한 액트 안에서 교차한다.
- 장기 맥거핀은 설치·증폭·변환·회수 중 한 단계에 연결한다.
- 가까운 30화만 상세 비트로, 가까운 10화만 장면표로 확장한다.
