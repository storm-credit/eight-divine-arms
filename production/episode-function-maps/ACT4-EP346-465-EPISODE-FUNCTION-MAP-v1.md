## EP346~EP355 — 두 병기 등장

- **EP347** 목표: ‘두 병기 등장’ 관련 당사자들의 이해관계를 확인한다. / 선택: 가장 강한 세력보다 가장 약한 피해자의 말을 먼저 듣는다. / 서브·복선: 백여울의 회수자 정체성에 첫 관계 충돌을 더한다. / **훅:** 공식 설명과 현장 증언의 시각이 어긋난다.
- **EP348** 목표: ‘두 병기 등장’의 기능이나 진위를 작은 실험으로 검증한다. / 선택: 실패를 감수하고 직접 몸으로 확인한다. / 서브·복선: 무공·도구 효용을 한 단계 시험한다. / **훅:** 예상과 반대되는 물리 결과가 나온다.
- **EP349** 목표: 시간·부상·제도 압력이 동시에 커진다. / 선택: 한 가지 이득을 포기해 피해 확산을 막는다. / 서브·복선: 백여울의 회수자 정체성의 비용을 실제 손실로 바꾼다. / **훅:** 포기한 목표가 상대의 손에 들어간다.
- **EP350** 목표: 앞서 심은 단서 하나의 현재 의미를 밝힌다. / 선택: 확실한 사실과 아직 모르는 사실을 분리한다. / 서브·복선: 백여울의 회수자 정체성을 설치에서 증폭 단계로 올린다. / **훅:** 두 병기 모두 같은 오래된 흠집
- **EP351** 목표: 처음 세운 목표가 충분하지 않았음을 깨닫는다. / 선택: 소유·승리보다 사용·책임을 새 목표로 삼는다. / 서브·복선: 백여울의 회수자 정체성의 의미를 변환한다. / **훅:** 새 목표를 막는 얼굴 있는 반대자가 등장한다.

- **EP357** 목표: ‘감정서 조작 흠집’의 공식 기록과 현장 증언을 대조한다. / 선택: 기록보다 물리 흔적을 우선한다. / 서브·복선: 소연후와의 승부의 오인을 강화한다. / **훅:** 증언과 기록의 시간이 맞지 않는다.

- **EP360** 목표: ‘감정서 조작 흠집’에 대한 첫 오해를 깨뜨린다. / 선택: 정답을 독점하지 않고 반론 가능성을 남긴다. / 서브·복선: 소연후와의 승부의 1차 회수를 만든다. / **훅:** 감정서 서명이 서로 다른 시기에 덧대짐

- **EP370** 목표: 물리 단서나 절차 단서가 실제 의미를 얻는다. / 선택: 현재 행동에 필요한 만큼만 공개한다. / 서브·복선: 두 공동체의 생존권의 공정성을 확보한다. / **훅:** 시위 조각이 조수에 반응
- **EP371** 목표: 중간 결과가 처음 가설을 부정한다. / 선택: 실패를 숨기지 않고 계획을 다시 짠다. / 서브·복선: 두 공동체의 생존권의 오인을 수정한다. / **훅:** 수정된 계획에 필요한 대가가 제시된다.

- **EP457** 목표: ‘거리 선점 완성’을 지키려는 인물과 정면 대면한다. / 선택: 양보 가능한 조건과 양보할 수 없는 책임을 나눈다. / 서브·복선: 소연후와의 승부을 인물 갈등으로 바꾼다. / **훅:** 협상 대상이 진짜 결정권자가 아님이 드러난다.
- **EP458** 목표: ‘거리 선점 완성’의 가설을 제한된 조건에서 실행한다. / 선택: 완전한 성공보다 실패 원인을 얻는 쪽을 택한다. / 서브·복선: 후반 회수에 쓸 물리 법칙을 남긴다. / **훅:** 결락된 조건 하나가 드러난다.
- **EP459** 목표: 상대가 규칙과 지형을 이용해 서유휘를 몰아붙인다. / 선택: 정면 승부 대신 책임이 남는 선택을 한다. / 서브·복선: 소연후와의 승부의 결함을 드러낸다. / **훅:** 선택 때문에 동료와 갈등한다.
- **EP460** 목표: 물리 단서나 절차 단서가 실제 의미를 얻는다. / 선택: 현재 행동에 필요한 만큼만 공개한다. / 서브·복선: 소연후와의 승부의 공정성을 확보한다. / **훅:** 폐쇄 산문에서 같은 계보의 빈 검집 발견
- **EP461** 목표: 중간 결과가 처음 가설을 부정한다. / 선택: 실패를 숨기지 않고 계획을 다시 짠다. / 서브·복선: 소연후와의 승부의 오인을 수정한다. / **훅:** 수정된 계획에 필요한 대가가 제시된다.
- **EP462** 목표: 현장 동료와 역할과 실패 책임을 나눈다. / 선택: 지휘권을 독점하지 않는다. / 서브·복선: 소연후와의 승부을 협업이 아닌 선택의 문제로 만든다. / **훅:** 합의 밖의 변수가 들어온다.
- **EP463** 목표: 축적한 단서를 전투 동선에 적용한다. / 선택: 상대를 쓰러뜨리는 대신 목표물을 지키는 데 힘을 쓴다. / 서브·복선: 소연후와의 승부의 물리적 회수를 만든다. / **훅:** 보호한 대상이 예상과 다른 선택을 한다.
- **EP464** 목표: 이전 선택의 대가를 감수하며 결산전에 들어간다. / 선택: 자신의 실수를 숨기지 않고 공개한다. / 서브·복선: 소연후와의 승부의 다음 회수 지점을 만든다. / **훅:** 얻은 것보다 잃은 것이 먼저 보인다.
- **EP465** 목표: ‘거리 선점 완성’의 보상과 후유증을 결산하고 다음 구간의 문을 연다. / 선택: 얻은 것과 남은 책임을 분리해 기록하고 독점을 피한다. / 서브·복선: 소연후와의 승부을 다음 구간으로 이월하고 열린 질문 하나를 부분 회수한다. / **훅:** ACT 5의 첫 사건으로 이어지는 인물·물건·기록이 모습을 드러낸다.

## ACT 완료 Gate
- 모든 화에 서유휘의 선택 또는 그 선택의 직접 비용이 존재한다.
- 각 블록은 기존 질문을 하나 이상 부분 회수하고 새 질문은 최대 두 개만 연다.
- 추적·거래·감정·전투·구조·복원 중심 동사를 한 액트 안에서 교차한다.
- 장기 맥거핀은 설치·증폭·변환·회수 중 한 단계에 연결한다.
- 가까운 30화만 상세 비트로, 가까운 10화만 장면표로 확장한다.
