## EP716~EP725 — 연무진 귀환과 완성 목록

블록 정본: 사부의 해답을 즉시 거부하지 않고 검증. 보상·이월 단서: 목록 한 칸이 비어 있음.

- **EP716** 목표: 사부의 해답을 즉시 거부하지 않고 검증. / 선택: 서유휘는 안전한 관망보다 현장 진입을 택한다. / 서브·복선: 연무진과의 방식 충돌의 첫 단서를 현재 사건에 연결한다. / **훅:** 목록 한 칸이 비어 있음
- **EP717** 목표: ‘연무진 귀환과 완성 목록’ 관련 당사자들의 이해관계를 확인한다. / 선택: 가장 강한 세력보다 가장 약한 피해자의 말을 먼저 듣는다. / 서브·복선: 연무진과의 방식 충돌에 첫 관계 충돌을 더한다. / **훅:** 공식 설명과 현장 증언의 시각이 어긋난다.
- **EP718** 목표: ‘연무진 귀환과 완성 목록’의 기능이나 진위를 작은 실험으로 검증한다. / 선택: 실패를 감수하고 직접 몸으로 확인한다. / 서브·복선: 무공·도구 효용을 한 단계 시험한다. / **훅:** 예상과 반대되는 물리 결과가 나온다.
- **EP719** 목표: 시간·부상·제도 압력이 동시에 커진다. / 선택: 한 가지 이득을 포기해 피해 확산을 막는다. / 서브·복선: 연무진과의 방식 충돌의 비용을 실제 손실로 바꾼다. / **훅:** 포기한 목표가 상대의 손에 들어간다.
- **EP720** 목표: 앞서 심은 단서 하나의 현재 의미를 밝힌다. / 선택: 확실한 사실과 아직 모르는 사실을 분리한다. / 서브·복선: 연무진과의 방식 충돌을 설치에서 증폭 단계로 올린다. / **훅:** 목록 한 칸이 비어 있음
- **EP721** 목표: 처음 세운 목표가 충분하지 않았음을 깨닫는다. / 선택: 소유·승리보다 사용·책임을 새 목표로 삼는다. / 서브·복선: 연무진과의 방식 충돌의 의미를 변환한다. / **훅:** 새 목표를 막는 얼굴 있는 반대자가 등장한다.
- **EP722** 목표: 동료·적대자·사용자와 권리와 책임을 협상한다. / 선택: 상대의 독립 목적을 인정하고 거래한다. / 서브·복선: 연무진과의 방식 충돌의 관계 상태를 비가역정으로 바꾼다. / **훅:** 합의 밖의 제3 권리자가 나타난다.
- **EP723** 목표: 앞선 단서를 추격·대련·구조·탈취 동선에 적용한다. / 선택: 가장 빠른 승리보다 퇴로와 후속 선택을 남기는 승리를 택한다. / 서브·복선: 연무진과의 방식 충돌을 행동과 물리 결과로 증명한다. / **훅:** 승리한 방식이 다음 문제의 원인이 된다.
- **EP724** 목표: 블록의 핵심 선택을 실행하고 대립자의 마지막 수를 받는다. / 선택: 완전한 승리보다 이후 책임 구조가 남는 선택을 한다. / 서브·복선: 맥거핀의 의미를 증폭하거나 뒤집는다. / **훅:** 결산 직전 다른 해석을 뒷받침하는 증거가 나온다.
- **EP725** 목표: ‘연무진 귀환과 완성 목록’의 보상과 후유증을 결산하고 다음 구간의 문을 연다. / 선택: 얻은 것과 남은 책임을 분리해 기록하고 독점을 피한다. / 서브·복선: 연무진과의 방식 충돌을 다음 구간으로 이월하고 열린 질문 하나를 부분 회수한다. / **훅:** 다음 구간 ‘거짓 또는 미끼 칸’의 징후가 현재 결과에서 드러난다.

## EP726~EP735 — 거짓 또는 미끼 칸

블록 정본: 미끼를 폭로하되 사부 의도를 단정하지 않음. 보상·이월 단서: 거짓 칸이 누군가를 보호하기 위한 것.

- **EP726** 목표: 미끼를 폭로하되 사부 의도를 단정하지 않음. / 선택: 공식 허가를 기다리기보다 물리 흔적을 직접 확인한다. / 서브·복선: 만류귀일보 한 점 집중의 출발점을 만든다. / **훅:** 거짓 칸이 누군가를 보호하기 위한 것
- **EP727** 목표: ‘거짓 또는 미끼 칸’의 공식 기록과 현장 증언을 대조한다. / 선택: 기록보다 물리 흔적을 우선한다. / 서브·복선: 만류귀일보 한 점 집중의 오인을 강화한다. / **훅:** 증언과 기록의 시간이 맞지 않는다.
- **EP728** 목표: ‘거짓 또는 미끼 칸’을 대련·감정·실험 중 하나로 재현한다. / 선택: 남의 설명을 받아들이지 않고 재현 조건을 요구한다. / 서브·복선: 만류귀일보 한 점 집중에 공정 단서를 추가한다. / **훅:** 성공했지만 다른 조건에서만 작동한다.
- **EP729** 목표: ‘거짓 또는 미끼 칸’을 둘러싼 압박이 사람과 물건 양쪽에서 커진다. / 선택: 이득을 늦추고 피해 확산을 막는다. / 서브·복선: 만류귀일보 한 점 집중의 비가역 비용을 남긴다. / **훅:** 막아낸 피해 뒤 더 큰 손실이 발견된다.
- **EP730** 목표: ‘거짓 또는 미끼 칸’에 대한 첫 오해를 깨뜨린다. / 선택: 정답을 독점하지 않고 반론 가능성을 남긴다. / 서브·복선: 만류귀일보 한 점 집중의 1차 회수를 만든다. / **훅:** 거짓 칸이 누군가를 보호하기 위한 것
- **EP731** 목표: ‘거짓 또는 미끼 칸’의 표면 목적이 뒤집힌다. / 선택: 처음 원했던 보상을 포기하고 더 큰 문제를 잡는다. / 서브·복선: 만류귀일보 한 점 집중을 다음 단계로 넘긴다. / **훅:** 새 목표의 즉시 비용이 드러난다.
- **EP732** 목표: ‘거짓 또는 미끼 칸’ 관련 권리와 책임을 교환한다. / 선택: 자신에게 유리한 독점 조항을 지운다. / 서브·복선: 만류귀일보 한 점 집중의 신뢰 비용을 높인다. / **훅:** 서명 직전 숨은 예외가 드러난다.
- **EP733** 목표: ‘거짓 또는 미끼 칸’을 두고 현장 승부를 치른다. / 선택: 앞서 심은 정보로 승부하되 손상을 감수한다. / 서브·복선: 전투·수집 보상을 발생시킨다. / **훅:** 승리 직후 숨은 손실이 드러난다.
- **EP734** 목표: ‘거짓 또는 미끼 칸’의 승패를 결정할 마지막 수를 둔다. / 선택: 보상보다 이후의 책임 구조를 우선한다. / 서브·복선: 만류귀일보 한 점 집중을 상위 액트와 연결한다. / **훅:** 마지막 순간 다른 해석이 제시된다.
- **EP735** 목표: ‘거짓 또는 미끼 칸’의 보상과 후유증을 결산하고 다음 구간의 문을 연다. / 선택: 얻은 것과 남은 책임을 분리해 기록하고 독점을 피한다. / 서브·복선: 만류귀일보 한 점 집중을 다음 구간으로 이월하고 열린 질문 하나를 부분 회수한다. / **훅:** 다음 구간 ‘사부의 선행 구조 성공’의 징후가 현재 결과에서 드러난다.

## EP736~EP745 — 사부의 선행 구조 성공

블록 정본: 연무진 방식의 실제 효율을 인정. 보상·이월 단서: 구조된 이들이 선택권을 잃음.

- **EP736** 목표: 연무진 방식의 실제 효율을 인정. / 선택: 당장의 이익보다 원인 확인을 우선한다. / 서브·복선: 백여울·소연후의 독립 선택의 첨 단서를 현재 사건에 연결한다. / **훅:** 구조된 이들이 선택권을 잇인다.
- **EP737** 목표: ‘사부의 선행 구조 성공’ 관련 당사자들의 이해관계를 확인한다. / 선택: 가장 강한 세력보다 가장 약한 피해자의 말을 먼저 듣는다. / 서브·복선: 백여울·소연후의 독립 선택에 첫 관계 충돌을 더한다. / **훅:** 공식 설뮥과 현장 증어의 시각이 어거나다.
- **EP738** 목표: ‘사핀의 선행 구조 성공’의 기능을나 진위를 작은 실험으로 검증한다. / 선택: 실패를 감수하고 직접 몸으로 확인한다. / 서브·복선: 무공·도구 효용을 한 단계 시험한다. / **훅:** 예상과 반눀되는 물리 결과가 다나온다.
- **EP738** 목표: 시간·관상은 동시에 커진다. / 선택: 한 가지 이익보다 포기해 피해 확산을 막슸다. / 서브·복선: 백여울·소연후의 독립 선택의 뱄용을 실제 손실로 바꾼다. / **훅:** 포기한 목표가 상눀의 손에 들어간다.
- **EP739** 목표: 지지잠들을 보호 공동체를 압박한다. / 선택: 단서 하나를 포기한다. / 서브·복선: 만류귀일보 한 점 집중의 비용을 실제 손실로 바꾼다. / **훅:** 지지잠들이 서유휘를 밨해자로 규정한다.
- **EP740** 목표: 빈칸이 단순 누락이 아님을 증쮩한다. / 선택: 확실한 사실을 만 공개한다. / 서브·복선: 연무진과의 방식 충돌의 공정성을 확��한다. / **훅:** 목록 한 칸이 비어 있음.

- **EP742** 목표: 동료·적대자·사용자와 권리와 책임을 협상한다. / 선택: 상대의 독립 목적을 인정하고 거래한다. / 서브·복선: 백여울·소연후의 독립 선택의 관계 상태를 비가역점으로 바꾼다. / **훅:** 하쥘 바의 제3권리자가 나타남다.
- **EP743** 목표: 앞서 단서를 충격·대련·구조·탈취 동선에 적용한다. / 선택: 가장 빼른 승리보다 텴로와 후속 선택을 나는 승리를 택한다. / 서브·복선: 백여울·소연후의 독립 선택을 행동과 물리 결과로 증명한다. / **훅:** 승리한 방식이 다음 문제의 원인이 된다.
