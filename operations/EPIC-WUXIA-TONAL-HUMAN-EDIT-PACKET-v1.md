# 《팔대신병록》 대하 무협 감각 Human Edit 패킷 v1

상태: `review-ready / human-edit-pending`

## 1. 사용자 방향

- 표국·조선소가 작품의 핵심 느낌은 아님
- 《천룡팔부》 같은 대하 무협 감각 희망
- 결말 우선·맥거핀 등 여러 작법을 전문 에이전트로 운용

## 2. PM 권고

> **T-B — 1+2 삼인 운명교차형**

- 서유휘: 독자 앵커, 시점 55~65%
- 공동 주인공 B: 정체·민족·국가 비극, 17~23%
- 공동 주인공 C: 사승·욕망·기환·계승의 역설, 17~23%

세 인물은 처음부터 상시 파티가 아니다.

1. 독립 시작
2. 간접 인과
3. 첫 만남과 오해·대결
4. 짧은 공조
5. 분리
6. 재회
7. 서로 다른 최종 선택이 하나의 시대적 결과를 만듦

## 3. 표국·조선소 처리 권고

- 표국: 서유휘의 출신·능력·삶으로 유지 가능
- 표국 중심 직업물: 효력 정지
- 조선소: 첫 사건 후보 중 하나로 재비교
- 장기 분산 호송: 한 액트 또는 서유휘 축의 행동 구조로 재사용 가능
- 진아령: 서유휘 축의 직업 라이벌 후보

## 4. 승인 뒤 즉시 진행

1. 결말 4안 — 결말 우선·역산
2. 공동 주인공 B 4안
3. 공동 주인공 C 4안
4. 맥거핀 4안
5. 세 축 Want/Need/Lie/Wound
6. 세 운명축 교차표
7. 전체 화수·액트·서브액트 4안
8. 무료분 시작점 4안

## 5. 현재 선택

- `T-B로 진행` — PM 권고
- `T-B지만 서유휘 비중 70%`
- `T-C에 가깝게` — 세 명 동등
- `T-A` — 서유휘 단일 주인공

추가로 한 문장 보정 가능:

- `표국은 유지`
- `표국은 배경만`
- `조선소 시작은 빼기`
- `조선소도 후보로 비교`

## 6. 중지요건

선택 전에는 결말·공동 주인공·총화수·무료분을 정본화하지 않는다.
