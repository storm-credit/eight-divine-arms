## 3. 사용자 확정과 PM 작업값 구분

### 사용자 확정

- 주인공 이름 서유휘
- 여성 주인공
- 서유휘 단일 주인공
- 약 1000화 장기 규모 예상
- 표사 아님
- 회귀·빙의·상태창 없음
- 전통 무협의 뼈대와 트렌디한 전면
- 팔대신병 수집 퀘스트 금지

### PM Human Edit 작업값

- 남의 수련 상대를 해 주는 생계
- 참가한 적 없는 비무 명단 + 가짜 문파 + 사라진 사부 추천
- 남성 윤겸, 무당 계열 라이벌
- 여성 현장 구조 무인 사부
- 8부 약 850~1100화
- 사부의 실제 성공과 제한된 강제 연결
- 제1부 80~100화 이름 없는 신병 작동
- 가상 수운 도시 결말
- 서유휘 무공 상실이 아닌 다중 발자리 무공 변신
- 사부 생존과 지역별 책임

PM 작업값은 사용자 거부·수정 전 정본이 아니다.
