# 《팔대신병록》 완성형 설계 패키지 구성표 v2

상태: `active-scope / tonal-reset`

## 1. 목적

`설계서가 다 되었다`는 말은 아래 묶음이 서로 연결되고 감사를 통과했다는 뜻이다. 문서 개수가 많은 상태를 완료로 보지 않는다.

## 2. 필수 묶음

| 묶음 | 산출물 | 현재 상태 |
|---|---|---|
| 작품 감각 | 한 문장 약속·정서·비극성·독자 앵커 | 재설계 중 |
| 결말 | 물리 위기·도덕 선택·인물별 최종 상태·역산표 | 재개방 필요 |
| 공동 주인공 | 1+2 또는 다른 구조·독립 욕망·교차 인과 | 미설계 |
| 맥거핀·비밀 | 전면 맥거핀·보조 대상·공정 단서·오인·회수 | 미설계 |
| 세계·시스템 | 역사·강호·국가·무공·기환·팔대신병 | 핵심 유지 |
| 인물·관계 | Want/Need/Lie/Wound·관계 부채·비극 패턴 | 재배치 필요 |
| 세력 구조 | 문파·가문·국가·상업·민족의 갈등층 | 핵심 유지, 플롯 배치 필요 |
| 무협 액션 | 대표 전투·무기 상성·전투 뒤 상태 변화 | 부분 설계 |
| 전체 플롯 | 액트·서브액트·전환·반전·보상 | 재설계 필요 |
| 한국 웹연재 | 무료분·유료 전환·소구간·절단·보상 주기 | 기존안 정지 |
| 전체 화수 | 화수 후보 4안·액트/서브액트 배분 | 미설계 |
| 용어 | 무협·세력·무공·행정·직업어 도입표 | 프레임 있음 |
| 집필법 | 시점·문장·대화·전투·설명·리비전 규칙 | 프레임 있음, 감각 재설정 반영 필요 |
| 연속성 | 시간·이동·부상·정보·맥거핀·관계·권리 | 미완 |
| 작법 에이전트 | 결말·맥거핀·운명직조·액션·연재·감사 역할 | 프로토콜 작성 |
| 최종 감사 | 재미·연독·정합성·복선·과잉·시장 진입 | 미착수 |

## 3. 설계 완료 조건

다음을 모두 만족해야 한다.

1. 작품 감각을 사용자가 명시 승인
2. 결말을 먼저 확정하고 역산 인과표 완성
3. 공동 주인공 구조와 각자 독립 결말 확정
4. 맥거핀이 감정 핵심을 대체하지 않음
5. 액트·서브액트가 주인공별 변화와 세력 변화를 동시에 기록
6. 무료분과 유료 전환의 약속·보상·절단 설계
7. 전체 화수는 이야기 기능으로 산출하며 임의로 늘리지 않음
8. 무협 용어 도입과 전투 규칙이 화 단위 Outline에 연결
9. 모든 설치·회수·비밀·부상·이동이 장부에 기록
10. 전문 에이전트 결과를 반대감사자가 독립 검토
11. P0 없음, P1 보정
12. 사용자 집필 준비 승인

## 4. 현재 정확한 위치

완성된 것:

- 세계·시스템 핵심
- 팔대신병 개별 핵심
- 서유휘 기본 인물 자산
- 용어·메타 프롬프팅·에이전트 작법 프레임

다시 해야 하는 것:

- 작품 감각
- 결말
- 공동 주인공
- 맥거핀
- 전체 플롯
- 무료분
- 전체 화수·액트·서브액트

## 5. 새 본선 순서

1. 작품 감각 Human Edit
2. 결말 4안과 승인
3. 1+2 공동 주인공 4안과 승인
4. 맥거핀·미스터리 4안과 승인
5. 세 운명축의 Want/Need/Lie/Wound
6. 세 축의 독립 시작·첫 교차·분리·재회·최종 교차
7. 전체 화수·액트·서브액트 4안
8. 무료분 진입점 4안
9. Plot Master
10. 무료분 1~25화
11. 전체 화 단위 Outline
12. 작법별·연속성·FUN 독립 감사
13. 집필 준비 판정

## 6. 현재 금지

- 표국·조선소를 작품 전체 정체로 자동 복원
- 천룡팔부의 인물·반전·장면 대응 복사
- 결말 전에 전체 화수 확정
- 공동 주인공 전에 액트 배분 확정
- 맥거핀을 팔대신병 수집 퀘스트로 변환
- 원고 작성
