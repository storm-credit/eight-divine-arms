# 《팔대신병록》 완성형 설계 패키지 구성표 v2

상태: `integrated-draft-complete / finalization-active`

## 1. 완료 정의

`설계서가 다 되었다`는 말은 문서가 많다는 뜻이 아니다.

다음을 모두 만족해야 한다.

- 작품의 시작·중간·결말이 인과적으로 연결
- 전 화 기능 Outline 존재
- 인물·맥거핀·부상·정보·관계가 연속
- 재미·반복·역사·무협 행동 감사를 통과
- 사용자 Human Edit와 집필 준비 승인

## 5. 남은 수정 묶음

### R1 인물 관계 구체화

- 서유휘 가족 2~3명
- 유청하의 장애 동문·스승
- 나해란 가족 선주·젊은 항해자
- 이름·욕망·관계 부채·결말 영향

### R2 기계·역사 검증

- 봉서심통과 봉쇄문 규격 계보
- 실제 장소·거리·수운·계절풍
- 명 가정 연간 군문·금의위·문파 활동 경계

### R3 재미 압축

- 50화 단위 반복 감사
- 10화 단위 관계·유머 보상
- 사문경 과강화 보정
- 151~225화 권리 논쟁 행동화 재확인

### R4 최종 통합

- 인물 바이블 v3
- Plot Master v3
- 최종 FUN·연속성·용어 감사
- 사용자 집필 준비 승인
