## 1. 최신 사용자 방향

- 주인공은 서유휘 한 명이며 약 1000화를 관통한다.
- 서유휘는 표사가 아니다.
- 김용의 대서사·사승·은원·강호 확대를 구조 모티브로 사용한다.
- 고룡·《절대쌍교》의 인물 대비와 관계 반전, 《열혈강호》의 접근성과 유머, 《용비불패》의 말맛·현장 전투를 참고한다.
- 《화산귀환》·《광마회귀》·《절대회귀》·《일타강사 백사부》 등 한국 무협 웹소설의 쉬운 욕망·주인공 음성·관계 집단·회차 보상을 적용한다.
- 작품·인물·장면·대사·반전을 복제하지 않는다.
- 본문은 쉬운 말, 설계서는 정밀한 말로 분리한다.
- 익숙한 정통 무협 문법을 전면에 두고, 낯선 고유 설정은 뒤에서 작동시킨다.

## 2. 통합 PM 기준안

FUN 검증용 작업 문장:

> 사라진 사부가 강남에서 가장 이름난 젊은 검객에게 도전장을 보냈다. 문파도 돈도 없는 서유휘는 이유를 묻기 위해 남의 문파 이름을 빌려 비무판에 들어간다.

정본 소개가 아니다.

서유휘 작업값:

- 남의 무공 수련 상대를 해 주며 돈을 버는 무소속 무인
- `대련꾼`은 설계 작업어일 뿐 전면 직업명으로 쓰지 않음
- 시비는 웃으며 피하지만 자기 편이 다치면 농담이 사라짐
- 사람을 지키면서도 누군가 자기 편이 되는 것은 믿지 못함
- 초반에는 사라진 사부를 찾아 직접 묻고 싶어 함
- 중반 이후에는 자기 때문에 떠돌게 된 사람들이 돌아올 길을 만들려 함
- 오래 내공을 운용하지 못함
- 상대의 손보다 다음 발자리와 퇴로를 봄
- 자기 좋은 자리를 차지하는 무공에서 여러 사람의 길을 잇는 무공으로 성장

## 4. 부별 서유휘 변화

1. 남의 이름을 빌린 무소속 무인 → 자기 이름을 얻음
2. 이름을 얻은 떠돌이 → 이름이 타인을 위험하게 함을 앎
3. 사람을 데려오는 무인 → 떠나는 사람의 뒤를 지킴
4. 사부를 찾는 제자 → 사부를 막을 수도 있는 무인
5. 외부 고수 → 정파와 관부가 함께 쫓는 무인
6. 자기 몸으로 길을 여는 무인 → 자신 없이도 동료가 움직이게 함
7. 사부의 잘못을 밝히는 제자 → 더 나은 답을 실제로 증명해야 하는 무인
8. 아무 데도 속하지 못한 무인 → 여러 사람에게 돌아갈 길을 남기는 대협

## 5. 이번 P1 보정

### 제2부 — 첫 신병

- 안개 속 세 척의 배와 낡은 사슬 수문
- 거짓 타격 신호 때문에 배들이 한 점에서 충돌할 위기
- 연화진 작업명의 생활 기술이 신병 감각을 해석
- 서유휘는 신병을 쓰지 않고 사슬 위에서 세 배의 다음 발자리를 연결
- 승리 조건은 적 격파가 아니라 세 배·사용자 생존

### 제3부 — 정보전

- 자정 전 떠날 사람·남을 사람·추적받는 가족의 세 길을 열어야 함
- 하진이 계획을 세우고 서유휘는 빈 봉투를 든 미끼 역할
- 일부는 떠나고 일부는 남으며 일부는 결정을 미룸
- 서유휘가 모두 데려오면 실패

### 제4부 — 두 진품

- 실종 선원 구조 반복을 제거
- 전승품과 복원품 사용자가 공식 결투장에서 서로 죽도록 강요됨
- 승자 하나·원본 하나를 만드는 판에서 두 사용자 모두 살아 나오는 것이 목표
- 백리현은 물건을 확보할 기회와 사용자의 생명 중 선택
- 사부 생존·과거 희생·현재 목적의 큰 답을 이 부에서 지급

### 제6부 — 삼분 재련

- 첫 재련은 실제 실패
- 보호 기능이 끊겨 석아문 작업명의 옛 부상이 되살아남
- 먼 사용자 연화진에게 통증 전이
- 사용자별 다른 거부 동작을 찾아야 함
- 세 지역 작전은 모두 완벽히 성공하지 않음
- 명령 흔적 일부가 남고 사부 발동 조건이 열림

## 6. 사부 설계

사부는 무능한 위선자나 단순 흑막이 아니다.

실제 성공 후보:

- 과거 여러 신병 사용자의 동작을 강제로 맞춰 대형 수운 재난을 막음
- 수백 명을 살렸지만 작은 나루 한 곳의 퇴로를 닫음
- 제7부 초반에도 서유휘보다 빠르게 대형 사고를 멈춤
- 사용자들은 살아남지만 자기 의지와 다른 움직임으로 다침

핵심 지지자 권고:

- 작업명 고연주
- 장강 나루의 구조·신호 책임자
- 사부의 선택으로 수백 명과 가족이 살았지만 남동생은 닫힌 나루에서 사망
- 사부를 숭배하지 않으면서도 그 선택을 부정하지 못함
- 최종부에도 사부에게 감화되어 즉시 전향하지 않으며 현장 구조 원칙에 따라 움직임

사부 금지:

- 모든 사건을 미리 설계
- 악역 연기로 제자를 시험
- 마지막에 갑자기 광인화
- 죽음으로 모든 책임 청산

---

## 7. 사부 강제 연결 한계

본선 노출 규칙 7개:

1. 중심 신병 흔적이 몸과 물건에 남은 핵심 사용자만 직접 영향
2. 여러 신병이 같은 순간 울릴 때만 사부가 개입
3. 먼 거리에는 종·사슬·신호탑 같은 중간 박자 필요
4. 한 번에 단순 동작 하나만 강제 가능
5. 긴 전투 전체를 원격 조종할 수 없음
6. 사용자에게 관절·호흡·기억 혼선, 사부에게 통증·방향 감각 붕괴
7. 사용자 고유 거부 동작·지역별 다른 박자·신호 흐리기로 대응

감사용 작업값:

- 직접 연결 핵심 사용자 최대 8명
- 일반 무인 직접 조종 불가
- 생각·기억 읽기 불가
- 복잡한 무공·살인 명령 전달 불가

## 9. 명대·무당·장강·연해 고증 방향

### 무당

- 명대의 큰 도교 성지·건축·순례·약방·산길 생활은 사용 가능
- 현대적 단일 무당파 무공 체계를 역사 사실처럼 단정하지 않음
- 백리현 소속은 무당 전체가 아니라 특정 궁관·속가 무림 계통 후보

### 장강·수운

- 나루·선주·창고·수문·운하·부교·좁은 사슬 통과 구간 사용 가능
- 장강 본류를 거대 문 하나로 막는 현대식 시설 금지
- 최종 무대는 장강과 연결된 지류·운하·항구가 합쳐진 가상 수운 도시

### 연해

- 가정 연간 1550~1560년대 강소·절강·복건의 해금·밀무·해상 약탈·상단·수군 갈등을 후경 골격으로 사용
- 왜구를 전부 일본인 악역으로 단순화하지 않음
- 중국인·외국인·지역 상인·무적자·피난민이 섞인 해상 세계로 표현

### 이동

- 강남·장강 하류에서 무당까지 며칠 만에 이동 금지
- 수로·육로 환승, 산길, 부상, 기상 지연을 이동 장부에 반영
- 정확한 지명과 날짜는 국소 경로 조사 전 미확정

## 11. 최종 물리 클라이맥스

권고 후보:

> 장강과 연결된 가상 수운 도시에서 서유휘는 사부를 이길 수 있는 완성 초식을 한 점에 모으지 않고, 밧줄·다리·배·종소리·동료의 발자리로 나누어 여러 퇴로를 연다.

장면 5단계:

1. 서쪽 나루의 밧줄과 배
2. 중앙 종루의 지역별 전령 신호
3. 동쪽 사슬교의 독립 판단 대형
4. 상류 지류 수문의 수동 개방
5. 사부를 이길 마지막 발자리를 여러 퇴로로 분산

손실:

- 무공 전체 상실 금지
- 특정 절정 경로와 대표 초식만 다시 한 점에 모을 수 없음
- 이후에도 고수·스승·여행자로 활동
