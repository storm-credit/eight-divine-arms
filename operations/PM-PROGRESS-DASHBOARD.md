## 1. 사용자 확정 방향

- 주인공은 **서유휘** 한 명이며 약 1000화를 관통한다.
- 서유휘는 여성이고 표사가 아니다.
- 회귀·빙의·상태창을 사용하지 않는다.
- 김용의 대서사·사승·은원·강호 확대를 구조 모티브로 삼는다.
- 고룡·《절대쌍교》의 인물 대비, 《열혈강호》의 접근성과 유머, 《용비불패》의 말맛·현장 전투를 참고한다.
- 《화산귀환》·《광마회귀》·《절대회귀》·《일타강사 백사부》 등 한국 무협 웹소설의 쉬운 욕망·주인공 음성·관계 집단·회차 보상을 적용한다.
- 작품·인물·장면·대사·반전을 복제하지 않는다.
- 본문은 쉬운 말, 설계서는 정밀한 말로 분리한다.
- 익숙한 정통 무협 문법을 전면에 두고, 낯선 고유 설정은 뒤에서 작동시킨다.
- 팔대신병은 순차 수집물이 아니다.
- 사용자 집필 준비 승인 전 원고를 쓰지 않는다.

## 2. 현재 PM 권고 입구

정본이 아닌 FUN 검증 기준:

> 남의 제자 대신 맞아 주며 먹고살던 서유휘의 이름이 강남 비무대회 명단에 올라 있었다. 소속은 사부가 농담처럼 말하던 문파, 추천인은 죽은 사부였다.

서유휘 작업값:

- 남의 무공 수련 상대를 해 주며 돈을 버는 무소속 무인
- `대련꾼`은 설계 작업어일 뿐 전면 직업명이 아님
- 평소에는 돈·밥·빚 농담으로 관계를 피함
- 자기 편이 다치면 농담이 사라지고 문장이 짧아짐
- 초반에는 사라진 사부를 찾아 직접 묻고 싶어 함
- 중반 이후에는 사람들이 돌아가 문을 두드릴 장소를 남기려 함
- 오래 내공을 운용하지 못함
- 상대 손보다 다음 발자리와 퇴로를 봄
- 한 자리 선점에서 여러 사람의 다음 자리 연결로 성장

## 4. 부별 서유휘 변화

1. 남의 이름을 빌린 무소속 무인 → 자기 이름을 얻음
2. 이름을 얻은 떠돌이 → 이름이 타인을 위험하게 함을 앎
3. 사람을 데려오는 무인 → 떠나는 사람의 뒤를 지킴
4. 사부를 찾는 제자 → 사부를 막을 수도 있는 무인
5. 외부 고수 → 정파와 관부가 함께 쫓는 무인
6. 자기 몸으로 길을 여는 무인 → 자신 없이도 동료가 움직이게 함
7. 사부의 잘못을 밝히는 제자 → 더 나은 답을 실제로 증명해야 하는 무인
8. 아무 데도 속하지 못한 무인 → 여러 사람에게 돌아갈 길을 남기는 고수

## 6. 핵심 관계 권고 작업명

서유휘만 확정이다.

- 윤겸: 무당 계열 라이벌
- 양소홍: 객잔 주인
- 하진: 독립 전령·작전 설계자
- 곽소무: 정보 친구·배신과 회복
- 두약란: 의원·작업 중단권
- 임초: 장강 조타수·첫 신병 사용자
- 위담: 사부 성공과 희생을 증언하는 해상 고수
- 문기서: 무당 동문·산문 안팎 연결
- 고유선: 사부 방식으로 실제 살아남은 구조 책임자
- 석헌: 산길 신병 사용자
- 한지백: 공정하지만 위험한 정파 회수 책임자

이름은 모두 Human Edit와 기존 작품 충돌 감사 전 미확정.

## 7. 팔대신병

장기 배치:

- 1부: 이름 없는 금속 흔적
- 2부: 첫 실물과 장강 생활 사용자
- 3부: 영웅 전설의 실패 흔적
- 4부: 전승품과 복원품이 서로 다른 의미에서 둘 다 진짜
- 5부: 문파 성물과 명령 보조 성질
- 6부: 감지·보호·명령 성질의 불완전 분산과 실제 실패
- 7부: 사부의 제한된 강제 연결
- 8부: 사용·거부·기능 약화·공동체 귀환

금지:

- 신병 하나당 한 부
- 여덟 개 순차 수집
- 서유휘 전부 소유·적합
- 신병으로 무공 자동 습득
- 서유휘 혼자 구조를 보고 즉시 해체

## 8. 사부

현재 권고:

- 실제 대형 수운 재난을 막아 수백 명을 살림
- 전체를 살리기 위해 작은 나루 하나의 퇴로를 닫음
- 제7부 현재에도 서유휘보다 빠르게 대형 사고를 막음
- 사람을 숫자로만 보지 않고 희생자 이름을 기억
- 다시 같은 조건이면 같은 결정을 할 가능성이 큼
- 서유휘가 더 나은 답을 만들기를 바라지만 실패 가능성이 있는 자유보다 성공 확률 높은 강제를 선택

능력 한계:

1. 핵심 사용자 최대 여덟
2. 여러 신병이 같은 순간 울릴 때만 직접 개입
3. 종·사슬·신호탑 같은 중간 박자 필요
4. 한 번에 단순 동작 하나만 강제
5. 생각·기억 읽기 불가
6. 복잡한 무공·살인 명령 원격 전달 불가
7. 사용자와 사부 모두 신체·감각 후유증

미정:

- 이름
- 성별
- 사적 호칭
- 강호 별칭
- 결말 생사
