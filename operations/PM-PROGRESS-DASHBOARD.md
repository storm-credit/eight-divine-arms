# 《팔대신병록》 PM 진행 대시보드

상태: `pm-human-edit-complete / naming-audit-complete / user-veto-pending / manuscript-locked`

총괄: PM 오케스트레이터
원고: `locked`

---

## 1. 사용자 확정

- 주인공은 **서유휘** 한 명이며 약 1000화를 관통한다.
- 서유휘는 여성이고 표사가 아니다.
- 회귀·빙의·상태창을 사용하지 않는다.
- 정통 무협의 대서사·사승·은원·강호 확대를 뼈대로 사용한다.
- 고룡식 인물 대비, 《열혈강호》의 접근성·유머, 《용비불패》의 말맛·현장 전투, 한국 웹소설의 회차 보상을 참고한다.
- 기존 작품을 직접 복제하지 않는다.
- 본문 언어는 쉽고 트렌디하게, 설계서는 정밀하게 쓴다.
- 팔대신병은 순차 수집물이 아니다.
- 사용자 집필 준비 승인 전 원고를 쓰지 않는다.

---

## 2. 현재 PM 작품 입구

> 남의 제자 대신 맞아 주며 먹고살던 서유휘는 참가한 적 없는 강남 비무 명단에서 자기 이름을 발견한다. 소속은 사부가 술김에 지어낸 문파. 추천인은 강에 떨어져 죽은 줄 알았던 사부였다.

PM 세부 작업값:

- 가짜 문파 문서명: `반보문`
- 실제 과거 정체: 정식 문파가 아닌 구조 동행 `반보회`
- 비급·본산·혈통·장문 계승권 없음

서유휘:

- 남의 무공 수련 상대가 되어 돈을 버는 무소속 무인
- `대련꾼`은 설계 작업어
- 평소 돈·밥·빚 농담으로 거리를 둠
- 자기 편이 다치면 농담이 끊김
- 오래 내공을 운용하지 못함
- 상대 손보다 다음 발자리와 퇴로를 봄
- 사부에게 이유를 묻는 사람에서 사부보다 나은 구조 방식을 증명하는 사람으로 성장

## 3. 관계·이름 최신 상태

서유휘만 정식 사용자 확정 이름이다.

### 라이벌

PM 작업명: **소겸**

- 남성
- 무당산 특정 궁관·속가 계통
- 부드럽고 사교적이지만 승부·규칙에는 냉정
- 서유휘의 발자리 원리를 처음 파훼
- 로맨스 미정, 초반 관계 주축 아님

폐기:

- `윤겸`은 영화 《물괴》와 장르 인물 충돌로 정식명 후보에서 제외.
- 구버전 문서의 윤겸은 소겸 역할을 가리키는 폐기 작업명.

### 사부

- 여성 현장 구조 무인
- 본명 PM 후보 `연소담`
- 보조 별호 PM 후보 `선보`
- 실제 재난을 막아 수백 명을 살렸으나 작은 나루 하나의 퇴로를 닫음
- 최종전 뒤 생존하고 능력·영웅 지위를 잃은 채 지역별 책임

### 핵심 조연 작업명

- 양소홍: 객잔 주인
- 하진: 독립 전령·작전 설계자
- 곽소무: 정보 친구·배신과 회복
- 두약란: 의원·작업 중단권
- 임초: 장강 조타수·첫 신병 사용자
- 위담: 사부 성공과 희생의 해상 증언자
- 문기서: 소겸 동문·문파 내부의 생활 비용
- 고유선: 사부 방식으로 실제 살아남은 구조 책임자
- 석헌: 산길 신병 사용자
- 한지백: 공정하지만 위험한 정파 회수 책임자

모두 충돌 검색과 사용자 검토 전 미확정.

## 6. 사부·결말 PM 권고

사부:

- 실패 가능성이 있는 자유보다 성공 확률 높은 강제를 선택
- 핵심 사용자 최대 여덟
- 여러 신병이 같은 순간 울리고 중간 박자가 있을 때만 개입
- 한 번에 단순 동작 하나
- 생각·기억 읽기와 복잡한 무공 원격 명령 불가
- 사용자와 사부 모두 후유증

최종 장소:

- 장강 본류와 연결된 지류·성내 운하·항구 수로의 가상 수운 도시

최종 선택:

> 서유휘는 사부를 이길 수 있는 완성 초식을 한 점에 모으지 않고, 밧줄·다리·배·종소리·동료의 발자리로 나눠 도시의 여러 퇴로를 연다.

결과:

- 무공 전체 상실 없음
- 한 점의 옛 절정 초식이 다중 발자리 무공으로 변함
- 서유휘는 다른 종류의 절정 고수
- 맹주·장문인 지위 거부
- 여행·대련·가르침 계속
- 사부 생존, 능력·권위 상실, 지역별 책임

## 8. 사용자 거부·수정 가능 핵심 축

1. 남의 수련 상대 + 반보문 비무 명단 입구
2. 남성 소겸 + 여성 사부 연소담 후보
3. 사부의 강제 구조 방식이 최종 가치 대립인 것
4. 사부 생존 + 서유휘 무공 변신 결말
