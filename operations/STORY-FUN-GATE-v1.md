# 《팔대신병록》 STORY FUN GATE v1

상태: `active-gate / not-passed`
입력:
- `audit/MOTIF-NOVEL-REFERENCE-AND-FUN-AUDIT-v1.md`
- `design/PLOT-REDESIGN-FOUR-OPTIONS-v3.md`
- `operations/PLOT-REDESIGN-HUMAN-EDIT-PACKET-v3.md`

## 1. 목적

설정과 논리가 맞는 것만으로 통과시키지 않는다.

이 Gate는 이야기가 실제로:

- 다음 장을 읽게 하는가
- 서유휘가 능동적으로 움직이는가
- 동료와 라이벌이 기억되는가
- 무협 행동이 충분한가
- 중간 보상과 최종 카타르시스가 있는가

를 검증한다.

## 2. 통과 기준

### 훅과 속도

- [ ] 1장 안에 구체적 물리 위기와 손실 위험이 보임
- [ ] 3장 안에 서유휘의 자발적 계획이 시작됨
- [ ] 3~5장마다 승리·실패·배신·발견 중 하나의 큰 변화
- [ ] 2장 연속 설명 목표 금지

### 주인공

- [ ] 시작 욕망이 한 문장으로 설명됨
- [ ] 매 막 서유휘가 먼저 세운 계획이 있음
- [ ] 매 막 계획 때문에 생긴 부작용이 있음
- [ ] 결말에서 시작 욕망의 핵심을 스스로 포기함

### 라이벌·적대

- [ ] R-1 정식 인물 설계 완료
- [ ] R-1이 최소 네 번 다른 우위로 등장
- [ ] 사문경·위철산·장계엄과 R-1의 기능 중복 없음
- [ ] 중반 이전 초반 피해 책임 일부 결산

### 동료·관계

- [ ] 완전 변화축 최대 세 명
- [ ] 선택 시점 최대 네 명
- [ ] 장기 관계축 최소 세 개
- [ ] 각 막에 생활 마찰·유머·애착 장면 기능 최소 하나
- [ ] 동료가 정보 전달자나 전문 도구로만 쓰이지 않음

### 무협 행동

- [ ] 각 막에 장기 육체 행동축 하나
- [ ] 각 막에 기억되는 전투·추적·구조 약속 하나
- [ ] 전투 결과가 사람·경로·증거·관계 상태를 바꿈
- [ ] 신병 능력으로 자동 해결하지 않음

### 미스터리

- [ ] 현재 사건·원사건·권리 결론 분리
- [ ] 마지막 새 문서 하나로 해결하지 않음
- [ ] 최소 두 번의 공정한 오인과 재해석
- [ ] 신병 잔흔의 한계를 독자가 미리 앎
- [ ] 한 교차는 결론 유보

### 재미 보상

- [ ] 각 막의 작은 승리가 구체적임
- [ ] 각 막의 손실이 다음 막에 남음
- [ ] 초반 약속 최소 세 개가 후반에 회수됨
- [ ] 결말에 물리적 선택과 감정적 선택이 일치
- [ ] 완전 승리 대신 납득 가능한 보상과 손실

### 과밀 방지

- [ ] 독자 전면 운반 대상 최대 세 종류
- [ ] 한 장 핵심 질문 최대 두 개
- [ ] 한 장 새 핵심 고유명 최대 세 개
- [ ] 권역당 새 A급 인물 최대 한 명
- [ ] 설정 설명이 행동을 멈추지 않음
