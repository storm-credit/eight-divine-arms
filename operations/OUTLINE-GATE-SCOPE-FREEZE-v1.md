## 1. 현재 효력

Outline Gate의 범위 정의는 유지하지만 실행·통과 효력은 일시 정지한다.

이유:
- Plot Human Edit 승인 결정이 없음
- 50장 Outline은 승인되지 않은 플롯 후보 위에서 작성됨
- POV·반복 구조·무협 행동축·결말 행동화 수정 필요

현재 Outline 파일은 `validation-draft`다.

## 2. 재개 조건

1. Plot Human Edit 승인 또는 수정
2. 심소연 시작 욕망 고정
3. 반복 현장 적대자 역할 고정
4. 8구간 반복 공식 해체 기준 승인
5. POV 목표와 조연 변화축 축소

## 3. 재개 뒤 포함 범위

1. 장 수 후보 재검토
2. 막·구간별 장 배분
3. 각 구간의 시작 상태·목표·압력·비가역 변화
4. 핵심 인물 주도권과 관계 변화
5. 세력·신병·증거의 진입·퇴장
6. 이동·계절·체류·회복 시간
7. 부상·치료·수배·신용·권리 상태
8. 단서 공개·오인 가설·재해석
9. 각 장의 기능 단위 개요
10. Outline 전체 교차감사

## 4. 제외 범위

- 소설 문장
- 대사
- 장면별 동작과 감정 연출
- 전투 세부 수순
- 모든 객잔·시장·음식·의복 설정
- 등장하지 않는 문파·세력의 도감
- 모든 초식·영초·부적 이름
- 기존 60장안과 장면 카드 자동 복원

## 5. 국소 상세화 허용

다음에 직접 영향을 주는 경우만 새 설정을 만든다.

- 장의 목표·전환
- 단서와 오인
- 인물의 선택
- 전투·호송·치료·협상의 결과
- 이동·가격·권리의 가능성
- 반복 등장 장소·세력

## 6. Outline 카드 필수 필드

각 장은 다음을 기록해야 한다.

- 장 번호·작업 제목
- 시점 인물
- 장소·시간 범위
- 장의 목표
- 압력·충돌
- 공개 정보·숨은 정보
- 인물 선택
- 상태 변화
- 다음 장 연결

현재 50장 초안은 장소·시간·다음 연결 필드가 불완전하므로 완료로 보지 않는다.

## 7. 검증 범위

- 목표 범위: 46~52장
- 현재 50장안: 검증 초안
- 장 수는 플롯 수정과 POV 재배치 뒤 다시 산정

## 8. 완료 조건

- Plot Human Edit 기준과 일치
- 5막·8구간이 독립 목표와 비가역 변화를 가짐
- `신병·전문가·과오` 반복 공식이 해체됨
- 심소연 시점 약 64~70%
- 선택 시점 최대 4명
- 각 막에 육체적 무협·호송·구조 행동축 존재
- 중반 정보 구간에도 현재 피해와 추적 압력 존재
- 이동·부상·치료 시간이 모순 없음
- 결말이 물리적 선택 뒤에 제도적 결산으로 이어짐
- 장 수가 설정 설명 때문에 부풀지 않음
- 원고 없이도 각 장의 기능을 이해할 수 있음

## 9. 현재 작업 금지

- 50장안의 정본 승격
- 장면 카드 확대
- 대사·전투 수순 작성
- 초고 작성
