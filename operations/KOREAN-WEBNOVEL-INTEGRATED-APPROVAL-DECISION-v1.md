상태: `user-approved / canon-authorized`
승인 표현: `통합권고 승인`

## 1. 승인된 결정

1. 주인공 정식 작업명: **서유휘**
2. 대서사: **B 장기 분산 호송형**
3. 서유휘의 주손실: **진원표국 분점 보증과 직업적 신용**
4. 반복 라이벌: **진아령형 경쟁 표국 특급 회수표사**
5. 서유휘 음성·행동 리듬:
   - 생활형 반문
   - 검표·하중·연결부 관찰
   - 책임을 먼저 떠안는 내면 결함
6. 무료분 1~5화:
   - H-C 먼저 분산하는 구조
   - H-A 조선소 붕괴 즉시 훅
   - H-D 진아령의 구조·압류 첫 등장

## 2. 승인 효력

이 결정으로 다음 작업을 정식 개방한다.

- 서유휘 이름·욕망·음성 정본 동기화
- 진아령 정밀 카드
- 무료분 1~25화 설계
- Plot Master v3
- 전체 화수·액트·서브액트 후보 비교
- 한국 웹소설 화 단위 Outline

다음은 별도 Human Edit 대상이다.

- 전체 목표 화수
- 액트·서브액트 최종 개수
- 플랫폼·회당 목표 글자 수
- 로맨스 상대·강도
- 핵심 인물 사망 여부 변경

## 3. 원고 잠금

이 승인은 설계서 진행 승인이다. 장면별 완성 대사·묘사·초고 작성 승인이 아니다.

원고는 다음까지 잠근다.

1. Plot Master v3
2. 무료분 1~25화 Master
3. 전체 화수·액트·서브액트 정본
4. 화 단위 Outline
5. 연속성·FUN Gate 통과
6. 사용자 집필 승인
