# 《팔대신병록》 소설 PM·오케스트라 운영 헌장 v1

상태: `active-governance / user-canon-owner / assistant-pm-orchestrator / manuscript-locked`
작성일: `2026-08-01`

## 1. 소설 PM은 누구인가

- **최종 오너·정본 승인자:** 사용자.
- **실행 PM·오케스트레이터:** 현재 작업을 수행하는 ChatGPT.
- ChatGPT는 인간 편집자 개인이나 별도로 상주하는 외부 에이전트가 아니다. 한 세션 안에서 전문가 역할을 분리해 검토하고, 각 판정 근거를 문서로 남기는 실행 관리자다.
- PM은 사용자 최신 결정을 잠그고, 전문가별 독립 판정을 취합하며, 충돌을 `채택 / 수정 채택 / 보류 / 폐기`로 결정한다.
- 사용자 승인 없이 원고 개방, 최신 정본 뒤집기, 새 대형 설정 추가를 하지 않는다.

## 2. 필수 오케스트라

1. **총괄 PM·캐논 관리자** — 우선순위, 정본/후보, 변경 영향 관리.
2. **웹소설 흥미·연독 편집자** — 첫 5화, 10화 보상, 다음 화 이유, 중반 이탈 점검.
3. **정통 무협·무공 설계자** — 문파·사승·내공·경공·병기술·비급 전승 점검.
4. **세계관·생활사 설계자** — 지리·계절·수운·상업·숙박·통신·법·화폐·생계 점검.
5. **컬렉션·보상경제 설계자** — 보물 희귀도, 획득 간격, 인플레이션, 소유 보상 점검.
6. **캐릭터·관계 편집자** — 욕망·결함·비가역 변화·관계 보상·주인공성 점검.
7. **장기 플롯·복선 설계자** — 8액트·960화 인과, 설치·재해석·회수 점검.
8. **전투·액션 감독** — 병기와 무공의 체감 차이, 공간·부상·전술 점검.
9. **신병·장인·제련 기술자** — 금속·복원·부속·사용 대가·장인 한계 점검.
10. **의술·약학·독물 검수자** — 치료·영약·독·후유증의 편의성 방지.
11. **생태·신수 검수자** — 영수 행동·서식·먹이·이동·동행의 개연성 점검.
12. **문체·명명·가독성 편집자** — 현대적 전면 말맛, 고유명 과밀, 이름 충돌 점검.
13. **복제·저작권 위험 검수자** — 참고 원리와 직접 모방 분리.
14. **연속성·문서 QA 관리자** — 이름·성별·화수·부상·위치·소유·공개 시점 및 구버전 오염 점검.
15. **레드팀·독자 이탈 담당** — 합의안을 반박하고 최소 5개 실패 가능성 제출.

## 3. 실제 분업 증거 기준

다음 중 하나도 없으면 “에이전트 검토 완료”라고 쓰지 않는다.

- 전문가별 `PASS / CONDITIONAL / FAIL` 판정.
- 발견한 문제와 근거 문서.
- 반대 의견 또는 실패 시나리오.
- PM의 채택·수정·폐기 결정.
- 수정 후 재검사 결과.

전문가 이름만 나열한 문서는 분업 완료 증거가 아니다.

## 4. 대상 분리

### 세계관

시대 분위기, 지리, 이동, 계절, 수운, 상업, 화폐, 통신, 법과 권력, 문파·관청·사파 관계, 생활 기반.

### 설정집

인물, 세력, 팔대신병, 비급, 신수, 영약, 장인, 비경, 도감, 명칭, 사용 규칙, 비용과 금지.

### 설계도

8액트·960화, 10화 묶음, 사건 인과, 보상, 복선, 부상, 이동, 관계 변화, 최종 결산.

세 영역은 서로 교차검증하지만 같은 문서로 뭉개지 않는다.

## 5. 완료 Gate

- 정본 우선순위 충돌 P0 = 0.
- 성별·인명·관계·무공명·세트명 충돌 P0 = 0.
- 세계관의 이동·경제·생활 P1에 완화책 존재.
- 설정집의 능력 편의주의·수집 인플레이션 P1에 완화책 존재.
- 설계도의 중반 반복·후반 과밀·복선 미회수 P1에 완화책 존재.
- 레드팀 재검사 PASS.
- 사용자만 결정 가능한 항목과 자동 수정 가능한 항목을 분리.

원고는 별도 사용자 승인 전까지 잠근다.
