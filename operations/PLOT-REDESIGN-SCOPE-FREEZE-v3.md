## 1. 목적

설정과 인물 프레임을 폐기하지 않고, 현재 플롯·Outline에서 발견된 다음 문제를 해결하는 대서사 구조를 다시 비교한다.

1. 심소연의 시작 욕망과 능동성 부족
2. 반복 현장 적대자 부재
3. 문서·재심·권리 절차가 무협 행동을 압도할 위험
4. `새 권역·새 신병·새 전문가·과오` 반복 공식
5. 심소연 시점 비중 부족
6. 가족·가업의 실제 플롯 영향 부족
7. 결말이 분류·회의·제도 설명으로 보일 위험

## 2. 유지하는 정본·프레임

- 전통 무협 + 역사 미스터리 + 저강도 기환
- 진원표국 검표수·인계표사 심소연
- D3 철조구 제한 적합과 어깨 부상·하중 환각
- 진소무·두약란·유청하·나해란의 핵심 기능
- 고정문·마윤경·한목수의 반복 기능
- 사문경·위철산·장계엄의 독립 적대 논리
- 팔대신병의 분산 보관·사용·수리·증언 구조
- 쇄조도 원사건과 현재 사건의 책임 분리
- 단계적 합증·분산 귀환을 유력 결말 후보로 유지

## 3. 재설계 대상

- 심소연의 시작 욕망
- 현재의 직접 손실과 시간 제한
- 심소연이 먼저 세우는 계획
- 반복 현장 적대자의 역할
- 대서사의 물리적 행동축
- 권역·신병·인물의 진입 방식
- 5막·8구간 유지·축소·변형 여부
- POV 구조
- 가족·가업의 개입 방식
- 마지막 물리적 선택과 영구 손실

## 4. 이번 Gate에서 하지 않는 것

- 46~52장 장 수 확정
- 장 단위 Outline 수정
- 장면 카드·대사·묘사·전투 수순
- 새 문파·도시·영초·초식 도감
- 주인공·핵심 인물 이름 전면 변경
- 기존 플롯 후보의 자동 정본화
- 사용자 승인 없는 결말 확정

## 5. 작업 순서

1. 맹점 훑기
2. 먼저 짚을 함정 — 프리모텀
3. 오픈소스 본보기 검토
4. 대서사 디자인 시안 네 개 비교
5. PM 권고 조합 작성
6. 사용자 인터뷰
7. 명시 승인 뒤 Plot Master v3 설계
8. 새 교차감사
9. 그 뒤 Outline 재구축

## 6. 완료 조건

- P0 승인·상태 문제가 없음
- 네 시안이 서로 다른 설계 철학을 가짐
- 각 안에 주인공 욕망·현장 적대자·행동축·결말 비용이 있음
- 무협 장르 행동이 막 단위 인과를 움직임
- 순례·수집·도덕 시험 반복을 통제함
- 가족·가업이 최소 세 막의 선택에 영향을 줌
- 심소연 중심 시점 구조를 만들 수 있음
- 사용자에게 필요한 결정이 구체적으로 정리됨

이 Gate의 산출물은 사용자 승인 전까지 `recommended-default / human-edit-pending`이다.
