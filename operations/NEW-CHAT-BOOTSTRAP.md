# 《팔대신병록》 새 대화 시작용 부트스트랩

아래 문장을 새 ChatGPT 대화 첫 메시지로 사용한다.

---

GitHub 저장소 `storm-credit/eight-divine-arms`의 `main` 브랜치를 직접 읽고 현재 상태를 확인한 뒤 작업해줘.

반드시 먼저 다음 파일을 읽어라.

1. `governance/STORY-ORCHESTRATOR-CONSTITUTION-v1.md`
2. 저장소에 존재하는 Canon Constitution, Canon Amendment, Decision Log
3. 상태·연속성 장부
4. 현재 요청과 관련된 분야별 설정집과 이야기 설계도
5. 필요한 경우에만 관련 원고

정본 우선순위는 다음과 같다.

1. 내가 현재 메시지에서 명시적으로 확정한 내용
2. 내가 이후 명시적으로 승인한 결정
3. Canon Constitution
4. Canon Amendment 및 Decision Log
5. 상태·연속성 장부
6. 분야별 설정집
7. 전체 이야기 설계도
8. Context Pack 및 작법 배치
9. 원고
10. 폐기·참고 자료

확정되지 않은 제안은 후보·가설·검토안으로 표시하고, 내 승인 전에는 정본으로 확정하지 마라.

이번 작업을 시작하기 전에 반드시:

- 최신 `main` 상태 확인
- 필요한 정본과 승인 상태 확인
- 관련 Context Pack 작성
- 설정 공백과 의존성 확인
- 연속성·독자경험·반복·유사성·편의적 해결 감사

를 수행하라.

계획만 말하고 끝내지 말고, 내가 파일 생성·수정·커밋을 요청했다면 실제로 GitHub에 반영한 뒤 커밋 SHA를 보고하라. 확인하지 않은 실행이나 검증을 통과했다고 말하지 마라.

별도 지시가 없는 한 신규 소설 원고를 작성하지 마라.

현재 작업 요청:

[여기에 이번 작업을 적는다]

---

## 사용법

1. 새 대화를 연다.
2. 위의 구분선 사이 내용을 복사한다.
3. 마지막 `[여기에 이번 작업을 적는다]`를 실제 요청으로 바꾼다.
4. 저장소를 읽기 전에는 완료됐다고 가정하지 않도록 한다.

## 주의

- 이 부트스트랩은 정본이 아니라 새 대화가 정본을 찾도록 안내하는 진입문이다.
- 실제 설정 충돌은 `governance/STORY-ORCHESTRATOR-CONSTITUTION-v1.md`와 저장소의 정본 문서에 따라 해결한다.
- 원고 집필을 재개하려면 사용자가 현재 메시지에서 명시적으로 허용해야 한다.
