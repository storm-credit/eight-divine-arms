# 《팔대신병록》 주인공 이름 결정 v1

상태: `user-selected / synchronization-pending`
사용자 선택: `서유휘`
기존 작업명: `심소연`

## 1. 결정

주인공의 정식 작업 이름은 **서유휘**로 한다.

유지하는 구조:

- 여성
- 진원표국 검표수·인계표사
- 절강 연해 생업 가문
- D3 철조구 제한 적합
- 과거 인계 기록 수정 과오
- 어깨 부상과 하중 환각
- 명문 혈통·신병 소유·선택받은 영웅 구조 없음

## 2. 동기화 원칙

플롯 구조가 사용자 승인되기 전에는 모든 과거 검증 초안을 즉시 대량 치환하지 않는다.

다음 정본 문서부터 `서유휘`를 사용한다.

- Plot Master v3
- 수정 인물·관계 매니페스트
- R-1 설계
- 5막·장기 행동구간
- 새 Outline

기존 문서의 `심소연` 표기는:

- 과거 작업명으로 간주
- 정본 근거로 인용할 때 `서유휘(구 작업명 심소연)`로 해석
- Plot Master v3 승인 뒤 일괄 동기화 감사 수행

## 3. 이름 국소 감사

추후 확인:

- 한자 후보
- 절강·강남권 시대감
- 가족 항렬과 성씨 자연성
- 동음·유사 이름 충돌

한자와 항렬은 현재 플롯 Gate를 막지 않는다.
