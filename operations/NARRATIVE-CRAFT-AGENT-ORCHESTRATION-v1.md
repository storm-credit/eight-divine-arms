## 1. 기본 원칙

- 작법은 정답 공식이 아니라 문제를 푸는 렌즈다.
- 같은 산출물을 최소 두 개의 다른 작법 렌즈로 검토한다.
- 작성 에이전트와 감사 에이전트를 분리한다.
- 사용자 취향·결말·주인공 구조를 에이전트가 몰래 확정하지 않는다.
- `천룡팔부 느낌`은 장면·인물 복사가 아니라 **운명 교차·다중 영웅·세력과 국가·혈연 비극·인과의 대가**로 추상화한다.
- 한국 웹소설이므로 한 명의 명확한 독자 앵커와 회차 보상은 유지한다.

# 2. 작법 라이브러리

## M01. 결말 우선 설계 — Ending First / Backward Design

질문:

1. 마지막에 누가 무엇을 선택하는가?
2. 그 선택으로 무엇을 영구히 잃는가?
3. 어떤 잘못된 믿음이 무너지는가?
4. 첫 화의 선택이 결말에서 어떤 반대 형태로 돌아오는가?
5. 결말을 가능하게 하는 단서·관계·부상은 어디서 심는가?

출력:

- 마지막 물리 위기
- 마지막 도덕 선택
- 주인공별 최종 상태
- 역산 인과표
- 필수 복선과 회수 시점

실패 신호:

- 결말이 주제 설명이나 회의로 끝남
- 마지막에 새 정보·새 능력으로 해결
- 초반 선택과 결말 선택이 무관함

## M02. 맥거핀 설계

정의:

> 인물과 세력을 움직이게 하지만, 작품의 진짜 감정 핵심은 아닌 추적 대상·정보·사람·권리.

질문:

- 누가 왜 그것을 원하는가?
- 독자가 그것을 원하는 이유를 이해하는가?
- 맥거핀을 얻었을 때 인물의 진짜 문제가 해결되지 않는가?
- 맥거핀이 사람·관계·정체성 갈등을 드러내는가?

후보 유형:

1. 물리 맥거핀 — 신병·상자·문서 원본
2. 인물 맥거핀 — 증인·실종자·계승자
3. 정보 맥거핀 — 쇄조도 책임 구조·출생·사승의 진실
4. 권리 맥거핀 — 보관권·계승권·공개권·전쟁 명분
5. 거짓 맥거핀 — 모두가 핵심이라 믿지만 실제로는 불완전한 대상

《팔대신병록》 원칙:

- 팔대신병 여덟 개를 차례로 수집하는 구조 금지
- 맥거핀은 최대 1개의 전면 대상과 2개의 보조 대상으로 압축
- 진짜 감정 핵심은 인물의 정체·의리·가족·사승·국가·선택이어야 함

## M03. 다중 주인공 운명 직조 — Braided Narrative

질문:

- 각 주인공은 독립된 장기 욕망과 장르 약속을 갖는가?
- 서로 만나기 전에도 자기 작품의 중심처럼 보이는가?
- 한 사람의 선택이 다른 사람의 삶을 간접적으로 바꾸는가?
- 합류가 단순 파티 결성이 아니라 가치 충돌인가?
- 분리 후에도 독자가 각 축을 기다리는가?

권고 구조:

- 명확한 독자 앵커 1명
- 공동 주인공급 운명축 2명
- 시점 비중 작업값: 55~65 / 17~23 / 17~23
- 세 축은 `직업·정체·사승/국가`처럼 서로 다른 질문을 담당

금지:

- 세 인물이 같은 사건을 반복 조사
- 한 축이 설정 설명 전용
- 초반부터 모두 모여 상시 파티화
- 독자가 주인공을 바꿔 탄다고 느끼는 무근거 시점 전환

## M04. 인물 비극 설계 — Want / Need / Lie / Wound

각 핵심 인물 카드:

- Want: 지금 얻고 싶은 것
- Need: 실제로 배워야 할 것
- Lie: 세상과 자신에 대한 잘못된 믿음
- Wound: 그 믿음을 만든 상처
- Strength: 성공하게 하는 능력
- Fatal Pattern: 장점이 반복되어 파국을 만드는 방식
- Irreversible Cost: 결말에서 지불할 대가

원칙:

- 비극은 악운만이 아니라 인물의 반복 선택에서 발생
- 좋은 의도가 다른 집단에 피해를 줌
- 정체·가족·사승·민족·국가가 한 인물 안에서 충돌 가능

## M05. 세력·국가·혈연 갈등 설계

갈등층:

1. 개인
2. 가족·사승
3. 문파·직업 공동체
4. 지역·민족·국가
5. 역사·종교·세계관

원칙:

- 큰 층이 작은 층을 대체하지 않고 압박함
- 국가 갈등도 한 사람의 혼인·성씨·사승·귀향·생계로 체감
- 세력은 선악이 아니라 보호 대상과 희생 대상을 다르게 선택

## M06. 미스터리·비밀 설계

사용:

- 출생·신분·사승 비밀
- 과거 참변의 책임
- 신병의 진짜 기능과 계승
- 인물의 잘못된 기억·기록

필수:

- 독자가 풀 수 있는 단서
- 오인 가능한 합리적 가설 최소 2개
- 폭로 전에도 장면 자체가 재미있음
- 진실이 관계·권력·행동을 바꿈

금지:

- 마지막 문서 한 장
- 모든 비밀이 한 흑막으로 연결
- 출생 비밀만으로 인물 가치 결정

## M07. 약속–진행–보상 — Promise / Progress / Payoff

- 작품 약속: 독자가 무엇을 계속 보게 되는가
- 진행: 능력·관계·세력·미스터리가 단계적으로 변함
- 보상: 기다린 대결·정체 폭로·재회·희생·승리

한국 웹소설 작업 기준:

- 1화: 핵심 약속 1개
- 3~5화: 첫 증명과 손실
- 10~20화: 첫 소구간 보상
- 25~45화: 액트 보상
- 각 대형 보상 뒤 더 큰 질문 또는 관계 변화

## M08. 시도–실패–악화 — Try / Fail Cycles

각 목표를 최소 세 방식으로 압박:

1. 능력 부족
2. 정보 오판
3. 성공했지만 더 큰 비용

반복 방지:

- 같은 종류의 실패를 연속 사용하지 않음
- 실패 뒤 인물·관계·노선·세력 상태 중 하나가 비가역적으로 변함

## M09. 장면–후속 장면 — Scene / Sequel

장면:

- 목표
- 충돌
- 결과/재난

후속:

- 감정 반응
- 딜레마
- 새 결정

웹소설에서는 후속 장면을 길게 정체시키지 않고 관계 케미·정보 해석·다음 행동 선택으로 압축한다.

## M10. 전투는 논쟁이다 — Battle as Argument

전투는 누가 강한가만이 아니라:

- 무엇을 지킬 것인가
- 사람과 물건 중 무엇을 우선하는가
- 집중과 분산 중 어떤 책임이 옳은가
- 문파 규율과 현장 판단 중 무엇을 택하는가

를 몸으로 증명한다.

각 대표 전투 뒤에는 최소 하나가 변한다.

- 관계
- 명예
- 신분
- 부상
- 맥거핀 소유
- 세력 균형
- 인물의 믿음

## M11. 설치–회수 장부 — Setup / Payoff Ledger

필드:

- 설치 항목
- 최초 노출
- 독자 예상
- 잘못된 해석 가능성
- 중간 변형
- 회수
- 감정 보상
- 미회수 시 영향

## M12. 회차 절단 설계

절단 유형:

1. 행동 직전
2. 예상보다 나쁜 성공
3. 정체 폭로
4. 관계 배신/선언
5. 새로운 선택
6. 기다린 대결의 시작
7. 거짓 승리
8. 조용한 감정 결산

같은 절단 유형을 3화 연속 쓰지 않는다.

# 3. 전문 에이전트 구성

## A0. PM 오케스트레이터

역할:

- 사용자 목표·정본·후보 상태 관리
- 각 에이전트 프롬프트 생성
- 결과 충돌표 작성
- Human Edit 항목 선별

직접 하지 않을 것:

- 모든 작법 산출물을 한 번에 작성하고 스스로 통과 선언

## A1. 결말 설계자

사용 작법: M01, M04, M10
출력:

- 결말 4안
- 주인공별 최종 선택·상실
- 결말 역산표
- 첫 화와 결말의 대칭

중지:

- 핵심 사망·주손실·세계 질서 변경처럼 사용자 승인이 필요한 결정

## A2. 맥거핀·미스터리 설계자

사용 작법: M02, M06, M11
출력:

- 맥거핀 4안
- 추적 주체와 욕망
- 비밀 계층
- 공정 단서·오인·회수 장부

## A3. 운명 직조 설계자

사용 작법: M03, M05, M07
출력:

- 1+2 공동 주인공 후보
- 각 축의 독립 시작점
- 교차 시점과 간접 인과
- 합류·분리·재회 구조

## A4. 인물 비극·관계 설계자

사용 작법: M04, M08, M09
출력:

- 핵심 인물 Want/Need/Lie/Wound
- 관계별 사랑·존경·질투·부채·배신
- 선택이 파국을 만드는 연쇄

## A5. 무협 액션 설계자

사용 작법: M10
출력:

- 대표 대결의 목적·지형·상성·결과
- 무공이 인물 철학을 드러내는 방식
- 전투 뒤 상태 변화

금지:

- 기술 이름 목록만 작성
- 경지표로 승패 결정

## A6. 한국 웹연재 설계자

사용 작법: M07, M08, M12
출력:

- 무료분 1~25화
- 소구간 보상표
- 회차 절단 분포
- 전체 화수·액트·서브액트 후보

## A7. 세계·용어 통합 설계자

역할:

- 기존 설정 중 실제 플롯에 필요한 것만 활성화
- 무협 용어 도입표
- 세력·지역·무공·신병의 등장 비용 관리

## A8. 연속성 감사자

검사:

- 시간·이동·부상·정보·맥거핀·권리·관계·시점

## A9. 반대감사자 / Red Team

원칙:

- 작성자의 의도를 변호하지 않음
- 작품이 실패했다고 가정
- 최소 세 개의 반대 구조를 비교
- `천룡팔부 느낌`이 이름만 남고 실제로는 직업 호송물인지 검사
- 다중 주인공 때문에 한국 웹소설의 앵커가 사라지는지 검사

# 5. 현재 프로젝트 적용 판정

현재의 `표국 장기 분산 호송 + 조선소 붕괴`는 다음으로 재분류한다.

- 작품 전체 감각: 정본 아님
- 서유휘의 직업 후보: 유지 가능
- 첫 사건 후보: 조선소 포함 재비교
- 장기 행동축 후보: 호송 포함 재비교
- 진아령 후보: 운명 직조 구조에서 역할 재검토
