# 《팔대신병록》 서유휘 직업·출발점 재설정 v1

상태: `user-direction / protagonist-occupation-reopened`

## 1. 사용자 방향

사용자 판단:

> 서유휘가 표사인 것은 아닌 것 같다.

이 판단은 다음과 같이 반영한다.

- `표사·검표수·인계표사`를 서유휘의 정본 직업에서 해제한다.
- 표국 중심 대서사와 장기 호송 구조는 효력 정지 상태를 유지한다.
- 과거 표국 설계는 삭제하지 않고 `deferred-reference`로 보존한다.
- 새 직업이나 출신은 재미 검증 전 정본화하지 않는다.

## 2. 무엇이 문제였는가

표사는 플롯 운용에는 편리했다.

- 지역 이동이 자연스럽다.
- 사람·물건·비밀을 운반할 명확한 임무가 생긴다.
- 여러 세력과 충돌할 수 있다.

그러나 주인공 출발점으로는 다음 위험이 컸다.

1. 서유휘보다 의뢰와 화물이 이야기의 중심이 된다.
2. 사건을 일으키기보다 전달하는 인물로 보인다.
3. 표국 규칙·계약·인계 설명이 무협의 호쾌함을 누른다.
4. 《팔대신병록》의 대하감보다 직업 에피소드물이 먼저 보인다.
5. 사용자가 원한 작품 감각에서 출발한 선택이 아니라 PM 편의로 정해졌다.

## 3. 유지할 수 있는 자산

직업을 폐기해도 다음 인물 자산은 재검토 가능하다.

- 이름: 서유휘
- 여성 주인공
- 현장에서 위험을 먼저 발견하는 관찰력
- 규칙보다 사람의 실제 피해를 먼저 보는 성향
- 과거 선의로 규칙을 바꿨다가 누군가를 해친 과오
- 어깨 또는 상체의 지속 부상 후보
- 팔대신병과 자동으로 연결되는 혈통·소유자·선택받은 자 구조 금지

`검표·하중·인계` 같은 직업 특화 표현은 새 출발점이 정해질 때까지 정본에서 제외한다.

## 4. 다음 설계 원칙

새 출발점은 직업 명칭보다 아래를 먼저 증명해야 한다.

1. 1화에서 서유휘가 누구인지 행동으로 드러난다.
2. 독자가 서유휘 개인 때문에 다음 화를 읽고 싶다.
3. 첫 관계 갈등이 장기 감정축으로 발전한다.
4. 강호·문파·가족·국가로 자연스럽게 확대된다.
5. 팔대신병과 연결되지만 수집 퀘스트나 선택받은 혈통이 되지 않는다.
6. 한국 웹소설의 초반 보상과 대하 무협의 장기 비극을 모두 만들 수 있다.

## 5. 상태 처리

- 표사 서유휘: `rejected-as-core / deferred-reference`
- 표국 설정: 세계의 한 업종으로 유지 가능
- 진아령 표국 라이벌안: `deferred-reference`
- 조선소 시작안: `candidate-only`, 직업과 분리해 재검토
- 서유휘 새 출발 신분: `four-options-required`
