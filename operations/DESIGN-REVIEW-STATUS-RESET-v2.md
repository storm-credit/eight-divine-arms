# 《팔대신병록》 설계 재검토 상태 재분류 v2

상태: `resolved-review / active-correction`
근거: `audit/DESIGN-PACKAGE-REVIEW-v2.md`
총괄: PM 오케스트레이터

## 1. 상태 재분류

- 설정 핵심: `canon / 유지`
- 인물 프레임: `canon-framework / 유지`
- 플롯 권고안: `recommended-default / human-edit-pending`
- 5막·8구간: `validation-framework`
- 50장 Outline: `validation-draft / revision-required`
- 기존 Outline 교차감사 v1: `superseded`
- 장면·대사·원고: `locked`

## 2. 재분류 이유

1. 플롯 Human Edit 승인 결정이 없는데 Outline Gate가 개방됨
2. 8구간 기능 행렬 파일이 불완전함
3. 48장·50장 기준이 문서마다 다름
4. 장 카드에 장소·시간·다음 연결 필드가 누락됨
5. 문서·권리 절차가 무협 행동축보다 강함
6. `신병·전문가·과오` 반복 공식 위험
7. 심소연 시점이 27/50장, 54%로 중심성이 낮음

## 3. 현재 유효한 것

- 작품 헌법
- 세계·무공·기환·팔대신병 상한
- 국가·강호·상업·권리 체계
- 심소연의 직업·과오·제약
- 핵심 인물의 전문 분야
- 삼각 적대 논리
- 단계적 합증·분산 귀환과 5막·8구간을 유력 후보로 검증하는 것

## 4. 정본화 금지 항목

- 첫 사건의 세부 원인·실행자
- 총 50장 확정
- 각 구간과 신병의 1:1 배치
- 현재 POV 배분
- 네 신병 짝의 완전한 결론
- 49~50장 결산 방식

## 5. 수정 순서

1. 8구간 기능 행렬 복구
2. 상태 문서·허브 동기화
3. 플롯 Human Edit 승인 또는 수정
4. 주인공 적극 욕망·반복 현장 적대자 고정
5. 반복 공식 해체와 무협 행동축 보강
6. POV·조연 변화축 축소
7. 시간·이동·부상·권리·단서 장부
8. Outline 재조정·새 감사

## 6. 원고 잠금

플롯 Human Edit와 새 Outline 감사가 끝날 때까지 원고·장면 카드·대사를 작성하지 않는다.
