# 《팔대신병록》 1000화·단일 주인공·정통 무협 전면 방향 v1

상태: `user-direction / scale-and-surface-reopened`

## 1. 최신 사용자 방향

- 예상 규모는 약 1000화다.
- 장기 연재 때문에 주인공이 교체되는 구조를 원하지 않는다.
- 서유휘 한 명이 작품 전체를 관통해야 한다.
- 낯선 창작 문파·무가·기관·지명 때문에 정통 무협이 아닌 것처럼 보이는 것을 우려한다.
- 특히 `쇄조도`처럼 독자에게 사전 맥락이 없는 고유 설정을 작품 전면에 두는 안을 재검토한다.

## 2. 즉시 상태 변경

- 300화 완결안: `compressed-proof-of-concept / superseded-as-full-length`
- 1~300화 기능 Outline: 인과·장면 아이디어 참고용. 1000화 전체 정본 Outline 아님.
- 서유휘: `single-protagonist-anchor / maintain`
- 유청하·나해란: 주인공 교체용 영웅이 아니라 장기 조연·라이벌·동료 후보.
- 1000화: 정확한 숫자 확정이 아니라 `longform-target / architecture-required`.
- 쇄조도: `late-secret-location-or-remove / front-facing-use-rejected`.
- 봉서심통·분산 합증 등 낯선 용어: 초반 전면 약속에서 제외하고 필요 시 후반 비밀층에서만 검토.

## 3. 정통 무협 전면 원칙

독자가 초반에 만나는 세계는 설명 없이 알아볼 수 있는 무협 문법을 우선한다.

- 강호, 문파, 사승, 비무, 은원, 협행, 마도·사파·정파 갈등
- 객잔, 장강 수로, 산문, 표국·상단·관부는 세계의 익숙한 기능으로 사용
- 소림·무당·화산·아미·개방 등 익숙한 전통 문파군은 실제 사용 여부를 별도 검토하되, 창작 문파만 가득한 세계는 피함
- 창작 문파·가문은 한 대구간의 전면 기준 1~2개로 제한
- 팔대신병은 초반부터 행정적 권리·합증 개념으로 설명하지 않고, 강호에서 탐내고 두려워하는 신병 전설과 실제 대결로 먼저 보여 줌
- 역사·제도·책임 구조는 독자가 인물과 강호에 애착을 가진 뒤 깊어진다.

권고 표면 비율 작업값:

- 익숙한 정통 무협 문법 70~80%
- 작품 고유 설정 20~30%

정확한 비율은 정본이 아니라 감사 기준이다.

## 4. 1000화에서 주인공 운용

- 서유휘 시점과 행동 인과가 전체의 절대 중심이다.
- 대구간이 바뀌어도 주인공이 교체되지 않는다.
- 다른 인물 시점은 서유휘가 직접 볼 수 없는 위험·적대 계획·관계 비용을 보여 줄 때만 제한 사용한다.
- 각 대구간은 서유휘의 신분·무공·관계·평판·목표 중 최소 두 가지를 비가역적으로 변화시킨다.
- 1000화 동안 같은 비밀 하나를 끌지 않는다. 80~160화 규모의 대서사들이 독립 결산되고 더 큰 강호 인과로 합류한다.

## 5. 새 설계 순서

1. 정통 무협의 표면 약속 4안
2. 서유휘 단일 주인공의 출발 신분·문파 관계 4안
3. 1000화 전체 성장 단계 4안
4. 6~10개 대서사부의 독립 약속·결산·상위 인과
5. 팔대신병의 등장 순서가 아닌 `강호 사건과 인물 변화` 중심 배치
6. 익숙한 문파·지역과 창작 요소 배합 감사
7. 1부 1~120화 정밀 Outline
8. 이후 대서사부는 10화·25화·대구간 기능표로 설계

## 6. 금지

- 부마다 새 주인공으로 교체
- 여덟 신병당 주인공 한 명 배정
- 창작 고유명만으로 강호를 채움
- `쇄조도`, `봉서심통`, `합증`, `보관권`을 1화의 장르 약속처럼 전면 설명
- 300화 플롯을 반복 사건으로 1000화까지 단순 연장
- 익숙한 문파 이름만 빌리고 실제 사승·은원·비무·협행의 재미가 없는 구조

## 7. 현재 판정

> 서유휘가 바뀌는 8인 군상극이 아니라, 서유휘 한 사람이 약 1000화 동안 강호를 살아 내며 여러 대서사를 통과하는 정통 무협 장편으로 다시 설계한다. 기존 300화안은 전체 완결안이 아니라 압축된 아이디어·인과 실험으로 재분류한다.
