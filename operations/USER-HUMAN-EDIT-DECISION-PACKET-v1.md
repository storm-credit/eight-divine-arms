## 1. 이미 사용자 확정인 항목

- 여성 단일 주인공은 **서유휘**다.
- 서유휘는 표사가 아니며 회귀·빙의·상태창을 사용하지 않는다.
- 전통 무협의 뼈대와 트렌디한 웹소설 전면을 결합한다.
- 팔대신병은 순차 수집물이 아니다.
- 사부는 전지적 흑막이 아니며 최종전 뒤 생존하고 책임을 진다.
- 서유휘는 문파·지부·왕국을 세우지 않는다.
- 결말에서 힘 전체를 잃지 않는다.
- 집필 준비 승인 전 원고를 쓰지 않는다.

## 2. 사용자 검토가 필요한 고위험 선택 7개

### D-01 라이벌 이름

PM 기본안: **소겸**

- 기능: 특정 무당 궁관·속가 계통의 남성 라이벌.
- 장점: 짧고 절제된 인상, 서유휘와 음성 대비가 좋음.
- 위험: 연소담·양홍주와 함께 있을 때 `소` 음절 밀집 가능.
- 기본 권고: 유지 후보.

사용자 선택 슬롯: `유지 / 수정 / 폐기 / 미정`

### D-02 여성 사부 이름과 별호

PM 기본안: **연소담**, 보조 별호 **선보**

- 기능: 현장 구조 무인, 강제 구조의 실제 성공과 책임을 함께 가짐.
- 별호 운용: 홍보 핵심어가 아니라 강호 내부의 제한적 호칭.
- 위험: `선보`는 검색 고유성이 낮고 평범함.
- 기본 권고: 본명 유지 후보, 별호는 조건부 유지.

사용자 선택 슬롯: `유지 / 본명만 유지 / 별호 교체 / 전부 재명명 / 미정`

### D-03 핵심 조연 재명명 묶음

PM 병합 직전 작업명:

- 양홍주 — 객잔 주인.
- 진하 — 젊은 전령·작전 설계자.
- 곽무소 — 정보 친구.
- 두약란 — 의원.
- 임도초 — 장강 조타수.
- 위담 — 해상 증언자.
- 문계서 — 소겸 동문.
- 고유직 — 구조·신호 책임자.
- 석헌 — 산길 신병 사용자.
- 한백지 — 정파 회수 책임자.

주의:

- 모두 역할 보존용 PM 후보이며 정본이 아니다.
- 이름을 바꿔도 과거·관계·플롯 기능은 바꾸지 않는다.
- 기본 권고: 직접 충돌 교체인 `양홍주·문계서`는 우선 유지 검토, 나머지는 말맛 검토 후 선택.

사용자 선택 슬롯: `일괄 유지 / 일부 수정 / 전부 재검토 / 미정`

### D-04 가짜 문파 이중명

PM 기본안:

- 문서상 소속: **반보문**.
- 실제 과거 동행: **반보회**.

기능:

- 비무 명단의 거짓 소속과 사부 과거를 연결한다.
- 정식 문파·본산·비급·혈통·장문 계승권이 없다.

위험:

- 독자가 숨은 절세 문파로 오독할 수 있음.
- 무공명에 `반보`를 반복하면 비밀 신법처럼 들릴 수 있음.

기본 권고: 유지 후보.

사용자 선택 슬롯: `유지 / 한쪽만 교체 / 전부 재명명 / 미정`

### D-05 팔대신병 이중 명명

PM 기본안:

1. 개문창 / 문창
2. 절류도 / 줄칼
3. 철조구 / 끌쇠
4. 묵형척 / 검은 자
5. 연생장 / 잇대
6. 청맥인 / 맥칼
7. 해명궁 / 울림활
8. 봉서검 / 편지검

기본 권고:

- D1·D2·D3·D4·D7·D8 유지 후보.
- D5는 `장법` 오독 때문에 조건부 유지.
- D6은 기록명 난해성 때문에 원고 직전 재검토.

사용자 선택 슬롯: `일괄 유지 / D5·D6만 재명명 / 일부 수정 / 전부 재검토 / 미정`

### D-06 총화수 중심값

PM 기본안: **960화 중심 착지**

- 회당 4,500~5,500자.
- 총 432만~528만 자.
- 실제 집필 허용 900~1050화.
- 전체 정책 허용 850~1100화.

장점:

- 정확히 1000화를 채우기 위한 팽창을 피함.
- 8부별 독립 결산과 장거리 이동을 유지할 수 있음.

기본 권고: 960화는 계획 중심값으로만 유지하고 집필 중 압축 허용.

사용자 선택 슬롯: `960 중심 / 1000 중심 / 900 중심 / 미정`

### D-07 로맨스 사용 여부

현재 미정.

고정 경계:

- 소겸과의 라이벌 관계가 먼저다.
- 연애가 서유휘의 장기 욕망과 주인공성을 삼키지 않는다.
- 초반 계약 연애·운명적 남주 중심 전환을 하지 않는다.

PM 권고 선택지:

- A. 무로맨스.
- B. 저강도 장기 긴장만 유지하고 결말 확정 없음.
- C. 후반 상호 선택형 로맨스, 별도 구원 서사 금지.

기본 권고: **B**.

사용자 선택 슬롯: `A / B / C / 미정`

## 4. 승인 단위 규칙

- 사용자가 하나의 이름만 승인해도 다른 후보까지 자동 승인하지 않는다.
- `진행`·`이어서`는 설계 지속 명령이지 승인 문구가 아니다.
- 정본 승격은 사용자가 명시적으로 `정본`, `확정`, `승인` 중 하나를 대상과 함께 말했을 때만 수행한다.
- 부분 승인 시 승인된 항목만 `user-canon`으로 표시하고 나머지는 후보 상태를 유지한다.
- 원고 개방은 이름 승인과 별개이며 별도 집필 준비 승인이 필요하다.
