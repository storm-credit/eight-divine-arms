# 《팔대신병록》 통합 작품 설계 교차감사 v1

상태: `audit-complete / conditional-pass / human-edit-required`
대상:

- 통합 작품 설계 PART 1·2
- 무료분 1~25화
- 화 단위 기능 Outline 26~300화
- 집필·문체 지침
- 통합 연속성 장부
- 주인공 프레임 오버라이드

감사 원칙:

- 작성 의도를 변호하지 않는다.
- 재미·주인공성·무협 행동·인과·연속성·웹연독만 기준으로 본다.
- 사용자 승인 전 정본이나 집필 준비 완료로 판정하지 않는다.

## 1. 총판정

> **1~300화가 끊기지 않는 통합 설계 초안은 성립했다. 구조적 P0는 발견되지 않았으나, 사용자 Human Edit와 P1 보정 전에는 정본으로 승격할 수 없다.**

판정:

- 구조적 P0: 0
- 절차적 차단: 사용자 미승인
- P1: 9
- P2: 7
- 1~300화 기능 누락: 없음
- 결말 역산 연결: pass
- 원고 조기 개방: 없음
- 표사안 자동 복원: 없음
- 팔대신병 수집 퀘스트화: 없음
- 최종 회의·문서 해결: 없음

현재 Gate:

- `recommended-integrated-draft`
- `conditional FUN pass`
- `human-edit-required`
- 원고 `locked`

## 2. 강점

### 2.1 주인공 첫 행동과 결말이 반대 형태로 연결

- 초반: 사람을 살리기 위해 명문의 보검을 부러뜨림
- 결말: 사람을 살리기 위해 가문 복권 원본인 봉서심통을 부러뜨림

같은 행동이 반복되지만 의미는 변한다.

- 초반에는 결과를 충분히 알지 못하고 혼자 결정
- 결말에는 비용을 알고, 다른 사람에게 숨기지 않고, 책임을 나누며 결정

### 2.2 표사안보다 제목·무협·인물성이 직접 연결

- 병기 수리 가문은 팔대신병과 연결되지만 소유자·선택받은 혈통이 아님
- 공개 비무·파검·수리 검증·문파 정치로 전통 무협의 표면 재미 확보
- 수리 기술이 조사만이 아니라 전투·구조·관계 선택에 사용됨

### 2.3 단일 주인공성과 대하감의 균형

- 서유휘 시점 65~70%
- 유청하·나해란은 독립 욕망과 비용을 가지지만 서유휘를 교체하지 않음
- 세 인물이 동일한 영웅 유형이 아니며 가치 충돌이 실제 결별을 만듦

### 2.4 맥거핀이 감정 핵심을 대체하지 않음

봉서심통은 인물을 움직이지만 최종 감정 질문은:

- 서유휘의 가문 복권
- 유청하의 사승 명예
- 나해란의 공동체 안전
- 현재 생존자의 익명·복권 선택

이다.

### 2.5 결말의 물리성

- 조수·붕괴·봉쇄문·구금자·수군·문파 병력이 동시에 작동
- 심통 파괴가 문을 여는 물리 선택
- 원본과 생존자의 양립 불가가 사전 설치됨
- 마지막 새 문서·새 능력·흑막 자백 없음

## 4. 프리모텀

이 작품이 재미없이 실패했다고 가정한다.

| 실패 원인 | 예방 장치 | 실패 신호 |
|---|---|---|
| 주인공이 감정가처럼 설명만 함 | 수리 판단 뒤 즉시 구조·전투·관계 선택 | 3화 연속 핵심 행동이 감정·열람 |
| 천룡팔부 느낌이 아니라 복잡한 증거극이 됨 | 사승·가족·우정·국가의 얼굴을 고정 | 독자가 사건명은 기억하지만 인물 관계를 기억 못함 |
| 유청하·나해란이 곁가지가 됨 | 각자 독립 승리·손실·결말 유지 | 두 인물 화를 건너뛰어도 본편 이해에 영향 없음 |
| 반대로 서유휘가 조정자만 됨 | 첫 사건·중간 반전·최종 선택은 서유휘만 가능 | 주요 폭로와 승리를 조연이 모두 수행 |
| 중반 권리 논쟁이 늘어짐 | 논쟁마다 검문·대피·해전·대결과 결합 | 10화 동안 장소·관계·통제권 변화 없음 |
| 심통 탈취 반복이 게임 퀘스트처럼 보임 | 이동 방식과 감정 비용을 매번 다르게 함 | 두 번 연속 습격→탈취→추적 |
| 비극이 과도해 숨이 막힘 | 10화 관계 보상, 25화 대승·성장 보상 | 20화 이상 상실만 지속 |
| 결말 장치가 작위적임 | 심통 잠금축 기능과 쇄조도 규격 계보 조기 설치 | 250화 이후 처음 열쇠 기능 언급 |
| 세계가 너무 넓어 핵심이 흐림 | 전면 세력 3~5개, 신병 1~2개 제한 | 한 화에 신규 고유명 4개 이상 반복 |
| 모티브 복제품으로 보임 | 모든 행동을 수리 가문·부상·과오에서 파생 | 인물 이름을 김용 인물로 바꿔도 장면이 그대로 성립 |
