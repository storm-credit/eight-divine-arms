# 《팔대신병록》 제목·인물·문파 명명 충돌 검색 감사 v1

상태: `search-audit-complete / not-legal-clearance / renaming-actions-active`
확인일: `2026-07-29`

목적:

> 작품명·주요 인물·가짜 문파·별호·팔대신병 이름이 기존 유명 작품·주요 캐릭터·실존 유명인·강한 상표와 즉시 충돌하는지 1차 확인한다.

한계:

- 공개 웹 검색과 주요 플랫폼 색인에 잡힌 결과만 확인했다.
- 모든 출판물·게임·웹툰·비공개 원고·상표를 망라하지 않는다.
- 법률상 상표·저작권·부정경쟁 최종 검토가 아니다.
- 검색 결과가 없다는 사실은 이름의 독점 가능성이나 완전한 고유성을 보장하지 않는다.

---

## 1. 작품명 《팔대신병록》

검색 판정:

- 공개 검색에서 두드러진 동일 제목의 상업 웹소설·웹툰·영상 작품이 확인되지 않음.
- `팔대신병`과 유사한 일반 표현·게임식 용어가 개별적으로 존재할 가능성은 남음.

위험도: `low / maintain-candidate`

조치:

- 제목 유지.
- 정식 출간 전 플랫폼 내부 검색·서점 ISBN·상표 검색을 다시 수행.

---

## 2. 주인공 서유휘

판정:

- 사용자 확정 이름이므로 유지.
- 현재 공개 검색에서 널리 알려진 동일 무협 주인공 충돌은 별도 확인되지 않았으나, 이후 전체 충돌 검색에 포함.

위험도: `user-fixed / recheck-before-publication`

---

## 3. 기존 라이벌 작업명 윤겸

확인 결과:

- 2018년 영화 《물괴》의 중심 무사 캐릭터 이름이 윤겸.
- 로맨스·장르소설 검색에서도 인물명 사용 사례가 노출됨.
- 서유휘와 장기간 함께 노출될 핵심 라이벌 이름으로 쓰면 기존 영상 캐릭터 연상이 생길 가능성이 큼.

위험도: `medium-high / reject-as-final`

조치:

- 라이벌 정식명 후보에서 윤겸을 내림.
- 과거 문서의 윤겸은 역할 식별용 폐기 작업명으로만 취급.
- 새 PM 작업명은 별도 4안에서 선정.

---

## 4. 사부 본명 후보 연소담

확인 결과:

- 숙박·식당·카페·공간 이름 등 상업 상호 사용 사례가 존재.
- 공개 검색에서 널리 알려진 장르소설 핵심 인물명 충돌은 두드러지지 않음.
- 상호와 캐릭터 이름은 사용 영역이 다르므로 현재 단계에서 치명 충돌로 보지 않음.

위험도: `low-medium / maintain-candidate`

조치:

- 연소담 PM 후보 유지.
- 출간 전 장르 플랫폼 내부 인물 검색 재확인.

---

## 5. 사부 별호 후보 선보(先步)

확인 결과:

- `선보`는 인명·상호·일반 한자어·기타 고유명에 폭넓게 쓰이는 문자열.
- 검색 고유성과 단독 식별력이 낮음.
- 강호 별호로 본문 안에서 제한 사용하면 큰 문제는 없지만 작품 홍보 핵심어로는 약함.

위험도: `medium / usable-as-secondary-epithet`

조치:

- 별호 후보 유지 가능.
- 작품 소개·표지 카피·검색 태그의 핵심어로 사용하지 않음.
- 본문에서도 `선보 연소담`을 반복 호명하지 않음.

---

## 6. 가짜 문파 후보 반보문

확인 결과:

- 공개 검색에서 널리 알려진 상업 무협 문파·작품 핵심 세력의 정확한 동일 이름은 두드러지지 않음.
- 개인 프로필·일반 문자열 수준의 사용 사례는 있을 수 있음.
- `반보`는 실제 무술·보법 표현과 결합될 가능성이 있으므로 비밀 절세 신법 오독에 주의.

위험도: `low-medium / maintain-candidate`

조치:

- 반보문·반보회 후보 유지.
- 정식 문파·비급·혈통 계보가 아니라 실패한 현장 동행 이름이라는 설정을 전면 유지.
- 무공명에 `반보`를 반복 사용하지 않음.

---

## 7. 라이벌 대체명 검색 결과

### 소겸

- 공개 장르 검색에서 널리 알려진 무협 핵심 캐릭터 충돌은 두드러지지 않음.
- 고려 사료에 금나라 사신 `소겸(蕭謙)`이 등장하는 역사 인명 사용 사례가 있음.
- 희귀한 현대 인명 사용 사례가 있으나 대중적 유명인 충돌은 낮음.

판정: `low-medium / PM-first-candidate`

역사 인명과의 동일은 16세기 반가상 중원 무협에서 치명적이지 않지만, 실제 역사 인물로 오인될 구체 이력·관직은 피한다.

### 위겸

- 게임 《원신》 관련 NPC 이름 검색 결과가 노출됨.
- 현재 핵심 조연 작업명 `위담`과 성씨·음성이 겹침.

판정: `medium-high / reject`

### 담율

- 세무·법률·상업 브랜드와 현대 인명 사용이 다수 노출됨.
- 장르 캐릭터 직접 충돌은 낮지만 현대 한국식 이름 인상이 강함.

판정: `medium / tone-reject`

### 백규

- 전국시대 상인·사상가 백규와 한국 역사 인물·자호 용례가 강함.
- 역사 인물 연상이 캐릭터 고유성을 압도할 수 있음.

판정: `high-historical / reject`

### 백유현

- 최근 문피아 무협 자유연재 작품의 주인공 이름으로 확인.
- 유사한 무공 흐름 파악 능력을 가진 캐릭터 설명까지 노출되어 오독 위험이 큼.

판정: `high-fiction / reject`

### 진율

- 기존 완결 무협 《천위》의 주인공 이름.
- 최근 무협 연재 소개에도 같은 이름 사용이 노출됨.

판정: `high-fiction / reject`

### 강무연

- 네이버 무협 웹소설 《흑객》의 주인공 이름.

판정: `high-fiction / reject`

### 류담

- 배우·방송인과 소설가의 이름으로 널리 사용.

판정: `high-real-person / reject-for-core-character`

### 연백

- 동명 로맨스 판타지 장편 제목이 확인됨.

판정: `high-title / reject-for-core-character`

## 8. 팔대신병 이름 충돌 기본 판정

기존 기록명:

- 개문창
- 절류도
- 철조구
- 묵형척
- 연생장
- 청맥인
- 해명궁
- 봉서검

현재 판정:

- 설명형 한자 조합이라 개별 일반 용례·유사 기술명이 존재할 가능성이 높음.
- 작품의 상표적 고유성을 각 기록명 하나에 의존하지 않는다.
- 생활명과 사용자·장면을 함께 사용해 식별한다.

생활명 후보:

- 문창
- 줄칼
- 끌쇠
- 검은 자
- 잇대
- 맥칼
- 울림활
- 편지검

위험:

- 생활명은 검색 고유성보다 이해 가능성을 우선한 일반어다.
- 단독 상품명·제목으로 사용하지 않는다.

판정:

- 이중 명명 체계 유지.
- 개별 정식명 충돌은 출간 전 다시 검색.

## 10. 재검색 Gate

다음 시점에 다시 검색한다.

1. 사용자 고영향 축 검토 뒤
2. 정본 캐릭터 바이블 병합 전
3. 플랫폼 등록 직전
4. 표지·소개문 확정 전
5. 출판 계약 또는 상표 검토 시

검색 대상:

- 정확 일치
- 한자 표기
- 발음 유사
- 장르 플랫폼 내부 검색
- 게임·웹툰·영상 주요 인물
- 실존 유명인·기업·상표

현재 정확한 표현:

> **1차 충돌 검색에서 작품명·연소담·반보문은 유지 가능 후보로 남았고, 윤겸은 영화·장르 인물 충돌 때문에 정식명 후보에서 내려갔다. 새 라이벌 PM 작업명은 소겸이며 정본 확정 전 추가 검색이 필요하다.**
