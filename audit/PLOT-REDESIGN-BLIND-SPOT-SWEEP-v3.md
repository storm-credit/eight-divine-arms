## 2. 맹점 표

| 맹점 | 심각도 | 근거 | 수정 조건 |
|---|---|---|---|
| 플롯 승인 전 Outline 정본화 위험 | P0 | Plot Human Edit 승인 파일 없음 | 새 안은 사용자 명시 승인 전 `recommended-default` 유지 |
| 심소연의 시작 욕망이 추상적 | P1 | 정확한 인계·책임 판단은 가치이나 초반에 얻고 싶은 구체 결과가 약함 | 첫 막에 기한·손실·성공 조건이 있는 욕망 고정 |
| 심소연이 사건에 반응함 | P1 | 붕괴·감정 제안·재심·압수 등 외부 압력에 대응하는 장이 다수 | 심소연이 먼저 세운 계획이 적대자와 다음 막을 움직여야 함 |
| 현장 적대자의 얼굴 부재 | P1 | 사문경·위철산·장계엄은 제도·논리 압력, 초반 실행 책임자는 일회성 | 1막부터 후반까지 반복 충돌하는 실행자 1명 배치 |
| 무협 행동이 절차 사이의 양념이 될 위험 | P1 | 조사·감정·열람·재심 목표가 장 기능의 다수를 차지 | 각 막의 주동 인과가 호송·추적·구조·돌파·방어 중 하나여야 함 |
| 도덕 시험형 순례 반복 | P1 | 새 권역마다 신병·전문가·과오·정통성 검증 구조 | 적어도 세 구간은 신병 감정이 아닌 이전 선택의 후폭풍으로 시작 |
| 팔대신병이 설계된 퍼즐처럼 보임 | P1 | 여덟이 네 쌍으로 정확히 교차하고 모든 구간에서 주제 기능이 정렬됨 | 한 신병은 현물 미등장, 한 교차는 결론 유보, 일부 증거는 쓸모없거나 손실 |
| 금릉·서남 구간의 분리감 | P1 | 장부 조사와 의료 조사가 독립 수사물처럼 작동 | 하나의 지속 호송·추적·도피 목표가 두 구간을 관통해야 함 |
| 결말의 물리적 절정 부족 | P1 | 마지막 선택이 공개·제한·봉인 분류에 집중 | 증거 보존과 현재 생존 구조가 직접 충돌하고 영구 손실 발생 |
| 가족·가업이 설정에만 존재 | P1 | 가족 원칙은 강하나 현재 Outline의 결정 인과에는 희박 | 1막 시작 손실, 3막 관계 비용, 5막 최종 포기와 연결 |
| 시점 분산 | P2 | 심소연 54%, 선택 시점 6명 | 심소연 64~70%, 선택 시점 최대 4명 |
| 조연 변화축 과잉 | P2 | 핵심 인물 다수가 과오 공개·변화·결산을 모두 가짐 | 완전 변화축 3명, 부분 2명, 나머지는 기능·압력 중심 |
| 회색 적대자 과잉 | P2 | 모두 일부 옳고 일부 틀려 감정적 분노와 승리감이 약해질 수 있음 | 현장 실행 책임과 피해는 명확히 결산, 상위 논리만 회색 유지 |
| 시작 사건의 책임 분산 | P2 | 부실·훼손·탈취·봉쇄·명부 회수가 겹침 | 독자가 초반에 이해할 책임 얼굴과 사건 질문을 2개 이하로 제한 |
| 현재 사건과 원사건의 정서적 거리 | P2 | 역사 책임은 정교하지만 현재 인물의 생존·관계 손실보다 앞설 수 있음 | 현재 피해자의 선택이 원사건 해석보다 항상 우선 |
| 로맨스 미정이 관계 설계를 유예시키는 문제 | P2 | 로맨스 없음도 가능하지만 정서적 친밀도의 최종 형태가 불명확 | 플롯 정본에서는 로맨스가 없어도 완결되는 관계 비용을 먼저 고정 |

## 3. 반드시 보존할 강점

- 심소연의 직업 전문성이 사건 접근권과 윤리 문제를 동시에 만든다.
- 신병은 소유·화력보다 사용·보관·수리·증언·권리 문제를 가진다.
- 현재 사건의 물리 책임과 원사건의 역사 책임이 분리된다.
- 사문경·위철산·장계엄은 서로 다른 독점·보호 논리를 대표한다.
- 결말은 전면 공개·전면 파기·중앙 독점의 단순 삼택일을 피한다.
- 저강도 기환과 역사적 물질 증거가 서로의 사각지대를 제한한다.

## 4. 네 시안이 답해야 할 질문

각 디자인 시안은 다음을 한 문장으로 답해야 한다.

1. 심소연은 첫 장에서 무엇을 얻으려 하는가?
2. 실패하면 30일 안팎에 무엇을 잃는가?
3. 심소연이 먼저 세우는 계획은 무엇인가?
4. 독자가 반복해서 맞닥뜨릴 현재의 적은 누구인가?
5. 장편을 관통하는 물리적 행동은 무엇인가?
6. 팔대신병이 순례 보상이 되지 않는 이유는 무엇인가?
7. 가족·가업은 어느 선택을 어렵게 만드는가?
8. 결말에서 심소연은 무엇을 영구히 포기하는가?
