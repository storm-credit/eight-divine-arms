# 《팔대신병록》 오케스트라 P1 종결 감사 — 2026-08-01

상태: `orchestra-evidence / P0-zero / P1-closed-for-design / manuscript-locked`

## 1. 감사 범위

- 32서브액트별 대표 적대축과 전투·사건 세트피스.
- 천하팔대신병 8개 개별 형상·기능·사용자·대가·처분.
- ACT 6 기술 설명 속도.
- ACT 8 최종 결산 감정 호흡.
- 최신 정본 인명·무공명·세트명 동기화.

## 2. 전문가별 독립 판정

### 총괄 PM·캐논 관리자 — PASS

- 구 인명과 구 무공명이 제작 문서에 남아 있던 문제를 수정했다.
- 정본 승격 사항과 원고 잠금을 분리 유지했다.

### 웹소설 흥미·연독 — PASS

- 32서브액트 각각에 명확한 목표·장애·보상·비용·다음 문이 존재한다.
- ACT 6은 설명 연속 제한, ACT 8은 결산 순서 고정으로 이탈 위험을 낮췄다.

### 정통 무협·무공 — PASS

- 신병 능력을 개념 조작이 아닌 병기·신호·지형·호흡 원리로 제한했다.
- 만류귀일보·개로무극이 내공 없는 시스템 능력처럼 작동하지 않는다.

### 세계관·생활사 — PASS

- 세트피스가 수운·산악·광산·해안·문파·경매·기록 관습과 연결된다.
- 구조와 소유권이 전투 결과에 실제 영향을 준다.

### 컬렉션·보상경제 — PASS

- 신병 8개의 발견·부속·사용권·처분 방식이 서로 다르다.
- 직접 소유가 적어도 원리·사용권·기록·평판 보상이 남는다.

### 캐릭터·관계 — PASS

- 소연후는 내부 책임, 백여울은 기록과 독점 감시, 진서하는 독립 작전이라는 자기 축을 유지한다.
- 연무진의 실제 성공을 보존하면서 서유휘의 선택이 최종 인과를 만든다.

### 장기 플롯·복선 — PASS

- ACT 1 검편·기록에서 ACT 8 봉서검·권리 분리까지 회수선이 연결된다.
- 팔대신병 8/8 확인과 실물 집결의 시점을 분리했다.

### 전투·액션 — PASS

- 32세트피스의 지형·승리 조건이 반복되지 않는다.
- 단순 격파보다 구조·감정·협상·기록·통로 확보가 승리 조건에 포함된다.

### 신병·장인·제련 — PASS

- D1~D8의 형상·전투 기능·생활 기능·부속·대가가 구분된다.
- ACT 6의 복원 실패와 성능 상한이 고정됐다.

### 의술·약학·독물 — PASS

- 청맥인은 즉시 치료 도구가 아니며 오진·통증 전이 위험을 가진다.
- 영약은 만성 손상을 초기화하지 않는다.

### 신수·생태 — PASS

- 영수가 8번째 신병을 단독 탐지하는 구조를 금지했다.
- 장인 기록·서식지 정보·후각 단서가 함께 필요하다.

### 문체·명명·가독성 — CONDITIONAL PASS

- 기록명·생활명 이중 체계는 유효하다.
- 본문에서 기록명 다중 나열과 한 화 신규 고유명 3개 초과를 계속 감시해야 한다.

### 복제·저작권 — PASS

- 개별 신병은 재난 대응 체계라는 통합 원리를 가지지만, 기존 특정 작품의 고유 병기·장면·대사 조합을 직접 복제하지 않는다.

### 연속성·문서 QA — PASS

- `소겸`, `진하`, `만류귀종` 잔존을 수정했다.
- 최신 정본 문서와 신병 장부·960화 지도 간 주요 충돌이 없다.

### 레드팀 — 수정 후 PASS

최악 가정:

1. 팔대신병이 구조 도구라 전투적 쾌감이 약하다.
2. 서유휘가 신병을 나눠 줘 수집 보상이 약하다.
3. ACT 6이 제작 설명으로 늘어진다.
4. ACT 8이 도덕적 협동 구호로 보인다.
5. 봉서검이 개념 조작 만능검이 된다.
6. 연무진이 주인공보다 유능해 보인다.
7. 백여울 로맨스가 최종전 뒤 부록처럼 붙는다.

완화:

- 각 신병 전투 기능과 첫 완전 사용 세트피스를 고정.
- 서유휘 직접 장비 묵형척과 비상 사용권·원리·기록권을 보장.
- ACT 6 장면 비율·설명 제한 고정.
- 개로무극을 다섯 물리 구역에 연결.
- 봉서검은 이미 존재하는 명령 매개만 해제 가능.
- 연무진의 빠른 성공 뒤 손상과 강제 비용을 동시에 제시.
- 백여울 결산 전 책임·처분 구간을 두고, 다음 행동으로 관계 확정.
