# 《팔대신병록》 대하 무협 감각 재설정 영향 감사 v1

상태: `audit-complete / redesign-required`

## 1. 결론

> 기존 설계의 세계·무공·신병·서유휘 핵심은 살릴 수 있다. 그러나 `표국 장기 호송물`을 작품 전체 정체로 고정한 플롯·무료분·라이벌·결말 후보는 재검토해야 한다.

P0:

- 작품 감각 사용자 방향과 현재 대서사 후보 불일치

P1:

- 서유휘 단일 주인공 고정 가능성
- 진아령이 작품 전체 라이벌로 과도하게 중심화
- 조선소 붕괴가 세계의 크기를 너무 일찍 한 직업 사건으로 축소
- 분점 보증이 최종 비극으로는 규모가 작을 가능성

## 2. 유지 가능한 자산

### 세계·설정

- 명대 역사 골격
- 강호·국가·상업·지역 공동체 충돌
- 무공·병장기·의술·저강도 기환 상한
- 팔대신병의 잔흔·보관·계승·책임
- 쇄조도 원사건

### 서유휘

- 이름
- 검표수·인계표사 경력
- 사람을 지키려 규칙을 바꾸는 반복 결함
- 어깨 부상·하중 환각
- 기록 수정 과오

단, 표국 직업은 `작품 전체 장르`가 아니라 `서유휘 축의 정체와 능력`으로 재검토한다.

### 기존 인물·세력

- 진소무·두약란·유청하·나해란은 공동 주인공 또는 핵심 관계 후보로 재배치 가능
- 사문경·위철산·장계엄의 세 보호 논리는 대하 갈등에 적합
- 진아령은 서유휘 직업축의 라이벌 후보로 유지 가능하나 전체 작품의 유일 반복 적대자 여부는 재검토

## 3. 효력이 정지되는 항목

- B 장기 분산 호송형의 정본화
- 조선소 붕괴 1화 확정
- 무료분 H-C+A+D 조합 정본화
- 분점 보증·직업 신용의 최종 주손실 확정
- 5막·6장기 행동구간
- 기존 50장 및 새 화수 추정

이 문서들은 폐기하지 않고 `deferred-candidate / reusable-parts`로 보존한다.

## 4. 새 작품 중심 질문

1. 서유휘 외 두 운명축은 누구인가?
2. 세 사람은 각각 무엇을 원하고 무엇 때문에 파국을 만드는가?
3. 팔대신병은 세 삶을 어떻게 간접적으로 연결하는가?
4. 개인·가족·사승·문파·국가 갈등이 어디서 한 선택으로 겹치는가?
5. 결말에서 세 사람이 같은 장소에 모여야 하는가, 아니면 서로 다른 선택이 하나의 결과를 만드는가?
6. 독자가 첫 25화 동안 기다릴 대형 약속은 무엇인가?

## 5. 먼저 짚을 함정

| 함정 | 예방 | 실패 신호 |
|---|---|---|
| 천룡팔부 이름만 참고하고 실제로는 호송물 유지 | 세 독립 욕망·세 독립 결말 설계 | 다른 두 축이 서유휘 의뢰인 |
| 다중 주인공으로 초반 이탈 | 1+2 구조, 무료분 서유휘 앵커 | 5화 전에 시점 3개 |
| 출생 비밀 남발 | 정체 비밀 외에 사승·국가·욕망 축 분산 | 세 명 모두 혈통 반전 |
| 세계가 커져 설정 설명 증가 | 각 축의 몸·관계·전투로 세계 제시 | 세력 설명 문단 연속 |
| 비극만 있고 웹소설 보상 부족 | 축별 호쾌한 승리·케미·재회 보상 | 10화 내 작은 승리 없음 |
| 팔대신병이 여덟 퀘스트가 됨 | 맥거핀 1+2 압축, 현물 미등장 활용 | 신병별 액트 반복 |
