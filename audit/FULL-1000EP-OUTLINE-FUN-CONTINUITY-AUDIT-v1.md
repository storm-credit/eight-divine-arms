## 1. 총판정

> 1~1000화 전체가 약 10화 단위 목표·보상·관계 변화·절단을 가지며, 약 100~130화 단위 대서사부가 독립 결산된다. 구조적 P0는 없다. 설계 패키지는 통합 초안 단계에서 완성으로 판정할 수 있다. 다만 이름·사부 완성 인물안·첫 문파 이름·정확한 지명·플랫폼 분량은 사용자 Human Edit 뒤 정본화해야 한다.

판정:

- 구조적 P0: 0
- 대서사부 8개 독립성: pass-draft
- 서유휘 단일 주인공: pass
- 10화 단위 보상: pass-draft
- 25화 단위 비가역 변화: pass-draft
- 팔대신병 수집물 방지: pass
- 사부 과점 방지: pass-draft
- 관계·생활 반복 엔진: pass-draft
- 이동·계절·부상: conditional-pass
- 결말 역산: pass-draft
- Human Edit 전 정본화: 불가
- 원고 개방: 불가

- 같은 비무대회·수성전·유물 추적 반복 없음.
- `사람을 살린다`는 공통 주제는 유지되지만 장면 기계와 관계 비용이 다르다.

## 3. 주인공성 감사

### 제1부

- 명단을 확인하고 거짓 소속을 사용할지 서유휘가 결정.
- 결승 포기도 서유휘 선택.
- pass.

### 제2부

- 배 전문성은 임초에게 있지만 서유휘가 자기 퇴로를 구조선으로 돌림.
- 임초를 조연 기술자로 소비하지 않음.
- pass.

### 제3부

- 하진이 계획을 설계하고 서유휘는 자기 통제 습관을 내려놓는 역할.
- 주인공이 모든 작전을 지휘하지 않아도 감정·선택 중심은 서유휘.
- pass-draft.

### 제4부

- 두 사용자가 주체적으로 기능을 멈추며 서유휘는 바깥 발자리를 바꿈.
- 사부 증언 수령에 그치지 않고 윤겸과 관계 손실을 직접 만듦.
- pass.

### 제5부

- 윤겸 문파 이야기지만 서유휘가 외부 개입의 비용과 현상범 상태를 직접 얻음.
- 윤겸이 주인공으로 교체되지 않음.
- pass-draft.

### 제6부

- 재련 목표를 제안하지만 실패하고 결정권을 사용자에게 나눔.
- 세 지역에서 한 곳만 직접 맡아도 제6부 위기의 원인은 서유휘 선택.
- pass.

### 제7부

- 사부가 먼저 사람을 살려도 서유휘가 대안 실험을 선제적으로 실행.
- 반응형 추적물로만 흐르지 않음.
- pass-draft.

### 제8부

- 최종 양립 불가 선택은 서유휘만 할 수 있지만 실행은 여러 사람이 독립 수행.
- pass.

## 4. 회차 보상 감사

각 10화 묶음에는 최소 하나가 있다.

- 작은 승리
- 새로운 관계
- 관계 손실
- 무공의 성공 또는 실패
- 장소 획득
- 비밀 지급
- 신분·평판 변화
- 명확한 제한 시간

주의가 필요한 구간:

1. 376~415화 — 두 진품 시연이 설명 연속이 되지 않게 사고·선택 장면 유지.
2. 501~530화 — 무당 생활 소개가 관광 안내가 되지 않게 약방·징계·제자 이동 목표 유지.
3. 776~800화 — 사부 지지자 증언이 회의가 되지 않게 구조·치료·보수 행동 속에 배치.
4. 981~1000화 — 후일담이 20화 동안 정리만 되지 않게 대련·귀환·새 문제의 작은 생활 사건 사용.

판정: `pass-draft / four-watch-zones`

## 5. 반복 감사

### 반복 가능 위험 A — 적을 잡지 않고 사람을 구함

여러 부에서 서유휘가 적 추격보다 사람을 선택한다.

차별화 규칙:

- 1부: 자기 우승 포기
- 2부: 자기 퇴로 포기
- 3부: 사람을 데려올 권리 포기
- 4부: 진짜 하나를 정할 권리 거부
- 5부: 라이벌 대신 선택하지 않음
- 6부: 작업 책임 독점 포기
- 7부: 자기 방식이 늦을 수 있음을 인정
- 8부: 절정 초식 집중 포기

같은 감정 문장으로 반복하지 않고 포기하는 대상과 손실을 다르게 한다.

### 반복 가능 위험 B — 문을 연다·길을 만든다

작품 중심 은유이지만 본문 대사로 계속 설명하면 올드해진다.

규칙:

- `길·문·선택`이라는 주제어 직접 대사는 부당 최대 2회 권고.
- 나머지는 밧줄·방·다리·배·약방·신호 같은 물리 행동으로 표현.

### 반복 가능 위험 C — 신병 사용 대가

매번 통증·기억 혼선만 반복하지 않는다.

대가 분산 후보:

- 감각 혼선
- 관절·호흡 손상
- 공동체 생계 의존
- 정치적 소유권 갈등
- 잘못된 신호
- 사용자 교대 필요
- 기존 기능의 영구 약화

## 6. 부상 연속성

서유휘:

| 구간 | 상태 |
|---|---|
| 1~30 | 일상적 어깨 부담, 짧은 내공 한계 노출 |
| 31~50 | 윤겸 파훼 뒤 어깨·내공 경로 손상 |
| 51~120 | 치료와 제한 사용, 완전 회복 아님 |
| 121~200 | 사슬 위 장면으로 재악화 |
| 201~365 | 장시간 전력 사용 제한, 정보전·관계 선택 비중 증가 |
| 366~490 | 연해 이동 중 회복하나 배 위 장기전 제한 |
| 491~620 | 산길·검진에서 재발 위험, 명령 흐름 끊기 중심 |
| 621~750 | 재련 작업과 현상범 이동으로 누적 피로 |
| 751~880 | 최종 초식과 퇴로 원리가 같은 경로를 사용한다는 위험 확정 |
| 881~1000 | 여러 퇴로 선택으로 특정 절정 경로 영구 손실 후보 |

다른 인물:

- 임초: 첫 신병 감각 혼선과 제6부 통증 전이 지속.
- 석헌: 오른손 감각 손상 후보를 완치하지 않음.
- 문기서: 장애가 사라지지 않고 이동·전투 방법에 지속 영향.
- 신병 사용자: 제8부 장시간 사용 불가.

판정: `pass-draft / exact-injury-ledger-finalization-pending`

## 8. 정보·비밀 연속성

### 사부

- 1부: 최근 활동 가능성·큰 잘못 하나 암시.
- 2~3부: 신규 핵심 단서 없음.
- 4부: 생존·과거 성공·희생·현재 계획 확정.
- 5~6부: 등장 없이 독립 사건.
- 7부: 실제 재회·성공·능력 한계.
- 8부: 최종 방식 충돌.

### 팔대신병

- 1부: 이름 없는 금속 흔적.
- 2부: 첫 실물과 생활 사용자.
- 3부: 영웅 전설의 실패 흔적.
- 4부: 두 계승이 모두 진짜.
- 5부: 문파 성물과 명령 보조 성질.
- 6부: 감지·보호·명령 성질의 불완전 분산.
- 7부: 강제 연결 실제 작동·한계.
- 8부: 사용·거부·약화·귀환 결산.

판정: `pass-draft`

## 10. 남은 P1

1. 사부 완성 인물 4안: 이름·성별·호칭·결말 생사.
2. 핵심 이름군 기존 작품·실존 인물 충돌 검색.
3. 첫 문파 이름과 참가 문서의 구체 접수 경로.
4. 가상 수운 도시 구역 간 거리·수위·작업 종 시간 카드.
5. 플랫폼 회당 글자 수에 따른 실제 850~1100화 재산출.
6. 로맨스 유무와 윤겸 관계가 자동 로맨스로 보이지 않는지 감사.
7. 팔대신병 정식 이름은 각 사용자·생활 용도 확정 뒤 별도 설계.
8. 최신 Outline을 정본 캐릭터·세계 바이블에 병합.
