# 《팔대신병록》 결말·플롯 Gate 전체 교차감사 v2

상태: `superseded / pass-withdrawn`

대체 감사: `audit/DESIGN-PACKAGE-REVIEW-v2.md`

## 1. 기존 판정 처리

기존 `PLOT GATE DESIGN PASS — HUMAN EDIT REQUIRED` 판정은 철회한다.

유지되는 것은 결말·대서사 후보의 가치와 비교 자료이며, Plot Gate 통과 효력은 없다.

## 2. 철회 이유

재검토에서 다음을 확인했다.

1. 문서·권리·재심 절차가 무협 행동보다 전면화될 위험을 과소평가함
2. 8구간이 `신병·전문가·과오`의 반복 공식으로 굳을 위험
3. 현장 책임과 삼각 적대 압력 사이에 반복 추적 적대자가 없음
4. 심소연의 시작 욕망과 능동적 사건 인과가 약함
5. 핵심·반복 인물 전원에게 과오·변화축을 부여해 과밀함
6. 금릉·서남이 독립 수사물처럼 분리될 위험을 충분히 해결하지 못함
7. 결말의 행정적 분류 위험을 물리적 최종 선택으로 전환하지 못함
8. 가족·가업의 중간 이상 비중이 Outline에 실제 반영되지 않음

## 3. 유지할 권고 후보

다음은 폐기하지 않고 수정 검증한다.

- 단계적 합증·분산 귀환
- 5막·8구간
- 조선소 붕괴·이중 인계
- 핵심 인물 필수 사망 없음
- 쇄조도 현장 검증 + 복수 거점 결산
- 느린 단일 로맨스 가능성, 상대 미확정

## 4. 새 Plot Gate 필수 항목

1. 심소연의 시작 욕망
2. 반복 현장 적대자
3. 현재 피해와 추적의 지속선
4. 구간 반복 공식 해체
5. 조연 변화축 우선순위
6. 무협 행동축
7. 결말의 물리적·비가역 선택
8. 비대칭 신병 합증
