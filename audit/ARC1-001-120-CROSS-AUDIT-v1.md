## 1. 총판정

> 서유휘의 성격·쉬운 목표·정통 무협 표면·라이벌·귀환 거점·첫 무공 성장이 120화 안에서 독립 결산된다. 다만 후반부 인물과 배후가 과밀하고, 대회 내부 사건과 사부 과거 설명을 압축해야 정본 후보가 된다.

판정:

- 설정집 냄새: 낮음
- 원고 개방: 불가

## 2. 강점

### 2.1 작품 소개와 실제 1화가 연결된다

- 죽은 사부의 도전장
- 외상값과 장강 객잔
- 문파 없는 대련꾼
- 비무대회 참가 필요

복잡한 역사 설정 없이 주인공·상태·욕망·비틀림이 보인다.

### 2.2 서유휘의 성격이 행동으로 드러난다

- 돈과 빚을 농담으로 피함
- 가짜 문패 사용을 직접 선택
- 하진을 강제로 보호하지 않고 거래
- 자기 편이 위험할 때 농담이 줄어듦
- 사부를 자동 변호하지 않음

### 2.3 라이벌이 심판이나 연애 도구만은 아니다

- 가짜 소속을 알고도 자기 목적 때문에 폭로하지 않음
- 서유휘의 첫 무공 원리를 직접 파훼
- 문파 명령과 자기 절차 기준 사이에서 비용을 치름
- 공식 승패와 별개로 장기 재대결 관계 형성

### 2.4 첫 무공 성장에 실패와 변형이 있다

- 발자리 선점 성공
- 발을 고정한 라이벌에게 실패
- 빈손·퇴로·집단 이동으로 확장
- 마지막 승리는 상대를 쓰러뜨리는 힘보다 출구 유지에 사용

### 2.5 팔대신병을 몰라도 1부가 성립한다

- 칼집 부속과 명령 혼란은 질문만 추가
- 이름·목록·역사 설명 없음
- 도전장·사부·라이벌이 표면 이야기를 유지

## 4. P2

1. `춘풍객잔`·`백리현`·`장무겸` 작업명 명명 감사
2. 가짜 문패를 빌려주는 작은 무관의 독립 욕망·관주 이름 필요
3. 라이벌 소속을 무당으로 할 때 실제 무공 이름 남발 금지
4. 대련꾼 생계가 1부 뒤에도 자연스럽게 변하는 상태표 필요
5. 양소홍의 외상 장부 유머 반복 횟수 제한
6. 사부 필체 판별을 주인공의 만능 감정 능력으로 만들지 않음

## 6. 압축 후보

- 37~40화 상대 조사·도전장 사본 구간: 1~2화 압축 가능
- 64~65화 노인 증언: 현재 사건과 결합해 1화 압축 가능
- 72~73화 수상전·생포: 제2부 예고 기능을 유지하되 1화 축약 가능
- 91~93화 가짜 후계자 소개·증언: 대결 전 긴 설명 금지
- 108~110화 배후 대결: 집단 마무리보다 서유휘 최종 선택에 초점
