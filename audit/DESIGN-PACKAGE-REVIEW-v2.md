# 《팔대신병록》 작품 설계 패키지 전면 재검토 v2

상태: `review-complete / revision-required`
총괄: PM 오케스트레이터
검토 범위:
- 최상위 정책·범위 고정
- 설정 정본
- 인물·관계 정본
- 결말·플롯 후보와 Human Edit 패킷
- 5막·8구간·50장 Outline 초안
- 기존 교차감사·대시보드·허브

## 1. 총괄 결론

현재 설계는 **핵심 발상과 세계 작동 원리는 강하지만, 집필 준비 완료 상태는 아니다.**

유지할 강점:
- 표국의 인계 실무를 주인공의 능력과 윤리 문제로 연결한 발상
- 팔대신병을 최강 무기보다 역사 잔흔·보관·계승·책임의 유물로 만든 구조
- 국가·강호·상업·지역 공동체의 권리 충돌
- 단일 흑막 대신 서로 다른 보호 논리를 가진 세 적대 압력
- 전면 공개·봉인·파기의 삼택일을 피한 단계적 합증·분산 귀환 결말 후보

그러나 다음 문제 때문에 Plot·Outline Gate를 통과로 판정할 수 없다.

- 치명적 문서·승인 상태 문제: 2개
- 중대 서사 구조 문제: 7개
- 중간 수준 운용 문제: 5개

최종 판정:

> **설정 핵심과 인물 프레임은 유지한다. 플롯은 승인 대기 후보로 되돌리고, Outline은 검증용 초안으로 재분류한다. 수정·재감사 전 집필 준비 판정 금지.**

# 2. P0 — 즉시 교정할 문서·승인 문제

## P0-1. 플롯 Human Edit 승인 없이 Outline Gate가 개방됨

확인:
- `operations/PLOT-HUMAN-EDIT-PACKET-v2.md`는 사용자 승인 뒤 Plot 정본 승격과 Outline Gate 개방을 명시한다.
- 해당 승인 결정 파일이 존재하지 않는다.
- `design/PLOT-FOUNDATION-v2.0.md`와 적대·미스터리 문서는 여전히 `human-edit-pending`이다.
- 그 상태에서 50장 Outline과 교차감사가 작성됐다.

판정:
- 사용자의 `이어서 진행`을 플롯 권고안 승인으로 해석한 것은 과도했다.
- 50장 Outline은 폐기할 필요는 없지만 `validation-draft`로만 사용한다.
- 결말·첫 사건·필수 사망·최종부 구조는 아직 정본이 아니다.

## P0-2. Outline 산출물과 상태 문서의 무결성 불일치

확인:
- `OUTLINE-SEGMENT-FUNCTION-MATRIX-v1.md`가 구간 1과 구간 2 제목에서 끝나 완전하지 않다.
- 제1~3막 문서는 헤더가 `48장 균형형`, 제4~5막은 `50장 균형형`이다.
- 구조 후보 문서는 O-48을 기준으로 하지만 실제 기능표는 50장이다.
- Outline Gate 카드 규격은 장소·시간·다음 장 연결을 요구하지만 실제 장 카드 대부분에는 이 필드가 없다.
- 기존 교차감사는 이 결손을 잡지 못한 채 `PROVISIONAL PASS`를 선언했다.

판정:
- 기존 Outline 교차감사 v1의 통과 판정은 철회한다.
- 완전한 8구간 행렬, 상태 장부, 이동·시간 필드를 채운 뒤 새 감사가 필요하다.

# 3. P1 — 중대 서사 구조 문제

## P1-1. 무협보다 문서·관할·재심 절차가 전면에 나올 위험

현 구조의 강점은 권리와 기록이지만, 50장 중 상당수가 열람·감정·분류·재심·공개 범위 판단을 목표로 한다.

위험:
- 작품이 무협 역사 미스터리가 아니라 행정·법적 분쟁극처럼 체감될 수 있음
- 무공·병장기·강호 명예·은원·호송의 몸성이 후반 일부 장에 집중
- 전통 무협을 기대한 독자가 장르 중심을 잃을 수 있음

수정 기준:
- 각 막에 최소 하나의 **육체적 목표를 가진 장기 행동축**을 둔다.
- 전투는 정보를 얻기 위한 장식이 아니라 사람·경로·증거·약속 중 무엇을 지킬지 선택하게 해야 한다.
- 비무·호송·추적·선상 구조·군문 돌파·피난 대열을 막 단위 인과에 포함한다.
- 문서 설명은 행동 결과와 피해를 통해서만 전면화한다.

## P1-2. 8구간이 `신병·전문가·과오 검증`의 반복 공식으로 보임

표면적으로 수집형은 아니지만 다음 반복이 있다.

1. 새 권역 진입
2. 해당 신병·전문가 등장
3. 기록·잔흔 검증
4. 그 전문가의 과거 과오 대면
5. 제한적 정통성·권리 확보
6. 다음 권역 단서

위험:
- `도덕 시험형 순례` 또는 에피소드형 퀘스트로 보임
- 인물 과오가 서로 다른 내용이어도 같은 타이밍과 기능으로 반복
- 네 쌍 검증이 지나치게 정교해 팔대신병이 역사적 우연보다 설계된 시스템처럼 보임

수정 기준:
- 모든 구간에서 해당 인물의 과오를 공개하지 않는다.
- 최소 두 과오는 다른 구간의 선택 결과로 뒤늦게 드러나게 한다.
- 한 신병은 현물 없이 기록·사용자·수리 흔적으로만 기능한다.
- 한 짝의 최종 교차는 불완전하거나 결론 유보 상태로 남긴다.
- 구간 종료가 항상 `정통성 확보`가 되지 않게 실패·손실·오판을 배치한다.

## P1-3. 적대 압력이 분산돼 감정적 추적선이 약함

사문경·위철산·장계엄의 논리 분리는 훌륭하다. 하지만 현장 과실 책임자·고의 훼손 실행자·사후 탈취 세력까지 별도라 독자가 쫓을 현재의 얼굴이 흐려질 수 있다.

수정 기준:
- 전지 흑막이 아닌 **반복 현장 적대자 1명**을 둔다.
- 역할: 고의 훼손 또는 사후 회수의 실행 책임자, 초반부터 후반까지 주인공과 직접 충돌
- 이 인물은 사문경의 완전한 충복이 아니며 자신의 생존·채무·명예 목적을 가진다.
- 1막 피해 책임을 중반 이전에 부분 결산하되, 그 선택의 여파가 후반 적대 압력과 이어져야 한다.

## P1-4. 심소연의 반응성

심소연은 기록·권리 과잉 판정을 막는 데 강하지만, 많은 장에서 다른 세력이 제시한 문제를 분류하고 거부한다.

현재 잘못된 믿음은 선명하지만 **초반의 적극적 욕망**이 약하다.

수정 기준:
- 시작 욕망을 하나 고정한다.
  - 예: 직무·가업 신용 회복
  - 또는 첫 사고의 특정 피해자·동료에 대한 책임 완수
- 이 욕망 때문에 사문경의 중앙 감정 제안이 실제 유혹이 되어야 한다.
- 각 막에서 심소연이 먼저 세운 계획이 적대자 행동을 바꾸는 인과를 최소 한 번 만든다.
- 결말 선택은 조사 결과를 분류하는 행위가 아니라, 자신이 원하는 것을 포기하는 비가역 행동이어야 한다.

## P1-5. 조연과 시점 과밀

현재 Outline 1차 집계:
- 심소연 27/50장 = 54%
- 선택 시점 6명
- 핵심·반복·적대 인물 11명 외에 가족·피해자·지역 대표·현장 책임자 필요

문제:
- 기존 권고 55~65%에도 미달하며, 장편 중심 주인공의 체감은 더 낮을 수 있음
- 미스터리 정보가 여러 시점으로 분산돼 독자의 추론선이 끊길 위험
- 모든 핵심 인물에게 완전한 과오·성장·결산을 주면 50장에 과밀

수정 기준:
- 심소연 시점 목표: 32~35장, 약 64~70%
- 선택 시점 인물: 최대 4명
- 마윤경·한목수·고정문 중 일부는 외부 관찰만으로 유지 가능
- 완전한 조연 변화축은 3명, 부분 변화축은 2명, 나머지는 기능·압력 중심으로 분류한다.

## P1-6. 제3막의 두 조사와 권역 여행 사슬

금릉 장부와 서남 의료는 각각 강하지만 독립 중편처럼 분리될 가능성이 높다.

문제:
- `한 지역에서 증거를 얻고 다음 지역으로 이동`하는 사슬이 수집형과 비슷한 리듬을 만듦
- 절강→복건→금릉→서남→중원→산동→쇄조도의 14~17개월은 실제 이동·회복·계절 감사가 없으면 작위적

수정 기준:
- 금릉 결정이 서남의 환자·의료 자원·추적 상황을 직접 악화시키게 한다.
- 서남 구간의 핵심 증거 일부는 금릉부터 동행하거나, 동부 연락 거점에서 먼저 등장한다.
- 모든 핵심 인물이 전 구간을 직접 여행하지 않는다.
- 직접 방문이 불필요한 증거는 사본·전문가 파견·선단·표국 인계로 이동시킨다.

## P1-7. 결말이 행정적 분류로 끝날 위험

`단계적 합증·분산 귀환`은 주제적으로 적합하다. 그러나 49장 최종 분류, 50장 귀환만으로 마치면 정서적·육체적 절정이 약하다.

수정 기준:
- 48~49장 사이 심소연이 **결정적 증거와 현재 사람의 안전 중 하나를 선택하는 물리적 위기**를 둔다.
- 그 선택 때문에 완전한 진실은 일부 영구히 잃거나 불확실해져야 한다.
- 대신 보호·배상·재심 구조가 가능해지는 구체적 대가를 남긴다.
- 최종 제도는 위기의 결과여야 하며 회의에서 발명되지 않아야 한다.

# 4. P2 — 중간 수준 운용 문제

## P2-1. 첫 6장의 정보량

압수선 부품·노동자 보상·유류품·관부 증거·복수 인계서·D3·부실 수리·고의 훼손·사후 탈취·보호망이 동시에 열린다.

수정:
- 독자가 처음 붙잡을 현재 목표는 `사람 구조 + 빠진 고정쇠 + 사라진 한 명/한 물건` 세 축 이내로 제한한다.
- 권리 주체와 문서 종류는 1막 후반에 단계적으로 확장한다.

## P2-2. 가족·가업의 실제 Outline 반영 부족

인물 정본은 가족·가업 비중을 중간 이상으로 정했지만, Outline에서는 1막과 심소연 과오 공개 때만 주로 보인다.

수정:
- 가족·가업 관계를 1막·3막·5막에 최소 한 번씩 실제 선택 압력으로 배치한다.
- 납치·사망 대신 채무·가업 폐쇄·혼인·돌봄·지역 신용을 사용한다.

## P2-3. 팔대신병 네 짝의 과도한 정합성

D1↔D5, D2↔D7, D3↔D6, D4↔D8은 감사에는 편하지만 너무 완벽하다.

수정:
- 짝은 작가 관리용 상호 검증 축일 뿐 세계 안의 공인 네 쌍이 아니다.
- 한 교차는 다른 제3의 기록이나 현장 증거 없이는 성립하지 않게 한다.
- 한 신병은 정보보다 정치적·감정적 권리 문제에 더 크게 기능한다.

## P2-4. 현재 위협의 지속성

각 권역마다 새로운 제도·세력 갈등은 있지만, 초반 재난에서 이어지는 물리적 위험이 약해질 수 있다.

수정:
- 반복 현장 적대자와 사후 회수망을 1·2·3·4막에 걸쳐 유지한다.
- 피해자·증인·수리 기록이 실제로 사라지거나 손상되는 누적 손실을 둔다.

## P2-5. 국소 설정 카드 미작성

Outline이 요구하는 실제 사용 설정 중 다음이 아직 부족하다.

- 1막 선창·기중 구조와 표국·관부 인계 형식
- 2막 신호 체계·선단 권리·해상 전투 목표
- 3막 금릉 장부고·서남 치료 거점과 이동 연결
- 4막 재심 규칙·군문·피난 통로
- 5막 쇄조도 현장과 분산 통신·봉인 절차

이 카드는 백과사전 확장이 아니라 Outline 인과 검증용으로 작성해야 한다.

# 5. 유지 판정

## 그대로 유지

- 작품 헌법과 저강도 기환
- 팔대신병의 상위 한계와 권리 분리
- 심소연의 직업·전문성·과오·신체 제약
- 상시 핵심 인물의 전문 분야
- 사문경·위철산·장계엄의 독립 논리
- 단계적 합증·분산 귀환을 유력 결말 후보로 두는 것
- 5막·8구간을 검증용 골격으로 사용하는 것

## 재검토 없이 정본화 금지

- 조선소 붕괴·이중 인계의 세부 원인과 실행자
- 50장 확정
- 각 구간과 특정 신병의 1:1 대응
- 조연 6인의 시점 배분
- 네 짝 전부의 완전 교차 검증
- 최종 49~50장의 결산 방식

# 6. 새 상태 판정

- 설정 핵심: `canon / 유지`
- 인물 프레임: `canon-framework / 유지, Outline 통합 재검토`
- 플롯: `recommended-default / human-edit-pending`
- 5막·8구간: `validation-framework`
- 50장 Outline: `validation-draft / revision-required`
- 기존 Outline 교차감사 v1: `superseded`
- 원고: `locked`

작품 설계 진행을 숫자로 과장하지 않는다. 현재는 **핵심 기반 완료, 서사 구조 재검토 중**으로 표현한다.
