# 《팔대신병록》 Human Edit 전 통합 교차감사 v1

상태: `audit-complete / structural-pass / detailing-required`

감사 대상:

- 작품 약속·소개문 4안 v2
- 핵심 인물 이름군·첫 대사 테스트
- 8부 상세 설계
- 1~1000화 상태 펄스 v2
- 이동·계절·공간도
- 사부 성공·지지자·능력 한계
- 팔대신병 비수집 배치·재련 실패 비용
- 최종 수운 도시·결말
- 현재 설계 우선순위 색인

## 1. 총판정

> 서유휘 한 명이 약 1000화를 관통하는 한국 무협 웹소설의 장기 구조는 성립했다. 기존 설정집형 입구보다 주인공 생계·거짓 소속·비무·라이벌·객잔 관계가 앞에 서며, 팔대신병과 사부의 논리는 중후반 장면으로 작동한다. 다만 1부 개별 Outline v2와 제2~8부 10화 단위 기능표가 최신 보정과 완전히 동기화되기 전에는 설계 패키지 완료로 선언하지 않는다.

판정:

- 구조적 P0: 0
- 단일 주인공: pass
- 약 1000화 사회적 엔진: pass-draft
- 정통 무협 표면: pass-draft
- 트렌디한 입구: pass-draft
- 8부 독립 결산: pass-draft
- 팔대신병 비수집형: pass-draft
- 사부의 실제 설득력: pass-draft
- 이동·계절 논리: conditional-pass
- 인물 이름: pending
- 세부 Outline 동기화: incomplete
- 원고 개방: 불가

## 2. 개선 확인

### 주인공이 입구가 됨

- 남의 수련 상대를 해 주며 먹고사는 현재 상태
- 참가하지 않은 비무 명단
- 죽은 사부의 추천
- 거짓 소속을 사용할지 직접 결정

팔대신병·역사·기관을 몰라도 첫 사건을 이해할 수 있다.

### 1000화를 버틸 관계와 장소가 생김

- 객잔
- 세 나루
- 이름을 묻지 않는 방
- 항구 등불과 창고
- 산길 약방
- 장인·의원 짝
- 독립 구조 장소

한 조직의 지부가 아니라 서로 다른 사람이 운영한다.

### 사부가 주인공을 삼키지 않음

- 제2·3·5·6부는 사부 없이 독립 완결
- 제4부에서 생존과 큰 잘못을 지급
- 제7부에서 실제 구조 성공을 보여 줌
- 능력은 핵심 사용자·단순 동작·중간 박자로 제한

### 신병이 편리한 열쇠가 아님

- 생활 기술 없이는 사용 불가
- 사용자가 소유권보다 중요
- 제6부 첫 재련 실패와 영구 비용
- 최종부 짧은 사용·교대 필요

## 4. P2

1. 양소홍·두약란을 제외한 이름 대부분 재명명 가능
2. 라이벌 성별과 로맨스 가능성 미정
3. 첫 문파 이름은 비밀 명문처럼 들리지 않게 재설계
4. 별호는 설계 단계에서 먼저 만들지 않음
5. 회차 제목은 기능·행정 용어를 피함
6. 제4부 연해 고증은 실제 지명 확정 때 추가 조사
7. 제5부 무당 계통은 특정 궁관·속가 생활로 제한
8. 최종 결말에서 사부 생사보다 책임과 이후 생활을 우선
