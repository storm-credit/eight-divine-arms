# 《팔대신병록》 플롯 재설계 프리모텀 v3

상태: `review-complete / option-input`
총괄: PM 오케스트레이터
가정:

> 새 플롯으로 장편을 썼지만 독자가 중반에 이탈했고, 무협보다 절차극으로 기억했으며, 결말의 감정적 만족도도 낮았다.

그 실패가 왜 일어났는지 먼저 역산한다.

## 1. 함정과 예방 장치

| 함정 | 실패 원인 | 예방 장치 | 실패 신호 |
|---|---|---|---|
| 문서극화 | 조사·감정·열람·재심이 장 목표를 독점 | 각 막에 3장 이상 이어지는 호송·추적·구조·돌파 행동축 | 3장 연속 주목표가 읽기·분류·회의·판정 |
| 주인공 수동성 | 심소연이 다른 세력의 안을 거부하고 정리하기만 함 | 막마다 심소연이 먼저 계획하고 그 계획이 새 위험을 만듦 | 막 전환 두 번 이상이 타인의 명령·소환·공격으로만 발생 |
| 도덕 시험 순례 | 권역마다 새 전문가가 자기 과오를 고백하고 정통성을 판정받음 | 과오 공개 시점 분산, 구간 실패·오판·미결 배치 | 세 구간 이상이 `새 인물→과오→권리 인정` 순서 |
| 적대자 무초점 | 상위 적대 논리는 정교하나 독자가 추적할 현재 얼굴이 없음 | 반복 현장 적대자 1명, 첫 사건·중반 추적·후반 선택에 연속 등장 | 10장 이상 같은 적과 직접 충돌하지 않음 |
| 결말 회의화 | 합증과 공개 범위가 말과 문서로만 결정 | 증거 운반·사람 구조·거점 방어가 동시에 실패할 물리적 위기 | 마지막 5장 중 3장 이상이 판정·발표·분류 중심 |
| 팔대신병 퍼즐화 | 여덟 신병이 정확히 맞물려 하나의 설계된 열쇠처럼 보임 | 현물 미등장 1개, 결론 유보 1쌍, 손실·오독·불완전 반응 | 모든 신병이 정확히 한 구간씩 정답을 제공 |
| 앙상블 분산 | 모든 조연이 독립 주인공처럼 과오·성장·결산을 가짐 | 완전 변화축 3명, 부분 2명, 선택 POV 4명 이하 | 심소연 시점 60% 미만, 조연 독립 결산 6개 이상 |
| 가족 장식화 | 가족·가업이 설정 문서에만 있고 실제 선택에는 영향 없음 | 시작 기한·중반 손실·결말 포기 비용에 가족·가업 연결 | 가족이 납치·사망 또는 응원 역할로만 등장 |
| 여행기화 | 권역마다 새 장소·세력·정보를 소개하느라 장편이 순례화 | 하나의 지속 임무·추적선이 권역을 관통, 새 A급 세력 제한 | 구간 시작마다 새 조력자와 지역 설명이 장 기능의 절반 이상 |
| 회색 윤리 피로 | 모든 적대자가 일부 옳아 분노와 승리감이 희석 | 현장 고의 행위·비밀 구금·채무 전가의 구체 피해는 명확히 결산 | 독자가 누구의 행동을 막아야 하는지 1막 종료에도 불명확 |
| 기환의 건조함 | 저강도 원칙이 신비와 경이까지 제거 | 신병 반응은 희귀하되 감각·신체 비용·지역 기억에 강한 장면 기능 | 기환을 모두 문서 증거의 보조 센서로만 사용 |
| 시간 붕괴 | 장거리 이동·부상·회복·계절풍을 장 밖에서 편리하게 처리 | 막별 달력·이동·회복 장부를 Outline보다 먼저 작성 | 중상 뒤 수주 내 고강도 전투, 계절풍과 항로 무시 |

## 2. 가장 위험한 실패 다섯 가지

### F1. 무협보다 절차가 앞선다

위험도: 매우 높음

현재 작품의 고유성은 권리·기록에 있지만, 독자는 인물이 몸으로 지키고 빼앗기고 실패하는 경험을 먼저 봐야 한다.

필수 통제:
- 모든 막의 중심 동사는 `운반한다`, `구한다`, `쫓는다`, `빠져나간다`, `지킨다` 중 하나
- `확인한다`, `열람한다`, `판정한다`는 행동축을 돕는 하위 기능

### F2. 심소연이 윤리 판정기처럼 보인다

위험도: 매우 높음

필수 통제:
- 시작 욕망은 사회적·경제적·관계적 결과가 있는 구체 목표
- 심소연의 첫 계획이 좋은 의도에도 불구하고 중반의 더 큰 위험을 만든다.
- 마지막에는 첫 욕망을 그대로 얻지 못한다.

### F3. 여덟 구간이 여덟 시험처럼 보인다

위험도: 높음

필수 통제:
- 구간 수 자체를 줄이는 안도 비교
- 한 구간에 여러 신병이 섞이고, 어떤 구간에는 신병 현물이 없음
- 인물 과오와 신병 검증을 같은 구간에 자동 배치하지 않음

### F4. 결말이 이상적인 제도 설계로 보인다

위험도: 높음

필수 통제:
- 완전한 증거 일부가 실제로 소실
- 누군가는 복권되지 못하거나 배상을 받지 못함
- 심소연이 사람을 살리기 위해 자신의 첫 목표를 포기
- 분산 귀환은 승리 선언이 아니라 손실 뒤의 차선책

### F5. 직접 적대자가 상위 논리의 심부름꾼에 그친다

위험도: 높음

필수 통제:
- 반복 현장 적대자는 사문경·장계엄·위철산을 오가거나 이용함
- 자기 생존·가족·채무·명예 목적이 있음
- 중반에 사라지지 않고 결말 선택과 연결
- 최종 흑막으로 격상하지 않음

## 3. Outline 재개 전 정량 경보선

- 심소연 POV: 64~70%
- 선택 POV: 최대 4명
- 완전 조연 변화축: 최대 3명
- 막별 장기 행동축: 최소 1개
- 세 장 연속 절차 중심: 금지
- 새 A급 지역 세력: 권역당 최대 1개
- 신병 현물 미등장: 최소 1개
- 결론 유보 교차: 최소 1개
- 반복 현장 적대자 직접 충돌: 최소 4회
- 가족·가업이 선택 결과를 바꾸는 막: 최소 3막
- 마지막 5장 중 물리적 위기·운반·구조·방어 장: 최소 3장

## 4. 판정

네 시안은 위 실패 신호를 얼마나 구조적으로 막는지 비교한다. 단순히 기존 50장에 전투를 추가하는 안은 재설계로 인정하지 않는다.
