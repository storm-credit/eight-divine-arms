# 1. 총판정

> 제2~4부의 전면 재미와 승리 조건이 이전보다 선명해졌다. 사부는 실제 성공과 생활인 지지 기반을 얻었고, `돌아올 길`은 객잔 중심 조직이 아니라 여러 지역의 독립 생활망으로 구체화됐다. 구조적 P0는 없다. 다만 첫 신병 장면의 기술 설명, 제3부 세 봉투의 복잡도, 제4부 결투 장치의 편의성, 귀환망의 조직물 전환 위험을 추가 관리해야 한다.

판정:

- 구조적 P0: 0
- P1: 7
- P2: 6
- 제2부 첫 신병 무협 장면: `pass-draft`
- 제3부 정보전 승리 조건: `pass-draft`
- 제4부 반복 축소: `pass-draft`
- 사부 실제 성공: `conditional-pass`
- 핵심 지지자: `conditional-pass`
- 돌아올 길 성장: `pass-draft`
- 사용자 Human Edit: `pending`
- 원고: `locked`

# 2. 개선된 점

## 2.1 제2부 첫 신병이 물건 설명에서 장면으로 이동

- 안개, 세 척의 배, 낡은 사슬, 일곱 번의 종이라는 시각·청각 요소가 있음.
- 신병은 답을 알려 주지 않고 연화진의 생활 기술을 증폭.
- 서유휘가 신병을 잡지 않고 연화진의 지시에 따라 움직임.
- 승리 조건이 적 격파가 아니라 세 배의 충돌 방지로 명확.

## 2.2 제3부의 주제가 행동 조건으로 변환

- `선택을 존중한다`를 장문 대화로 해결하지 않음.
- 세 길 중 당사자가 직접 여는 길이 있어야 성공.
- 하진이 작전 설계자, 서유휘가 미끼 역할을 맡음.
- 서유휘가 모든 사람을 데려오면 실패라는 역전 조건이 캐릭터 성장과 연결.

## 2.3 제4부가 제2부와 다른 얼굴을 가짐

- 실종 선원 구조 반복을 줄임.
- 공식 결투장에서 두 사용자가 모두 살아 나오는 것이 독립 목표.
- 전승품과 복원품의 진짜성을 설명 대신 사용자 행동과 굳은살·사용 실패로 보여 줌.
- 백리현이 물건과 사람 중 선택하는 장면이 관계 파열의 실제 행동이 됨.

## 2.4 사부의 지지가 현실성을 얻음

- 사부의 방식은 실제 대형 사고를 빠르게 멈춤.
- 지지자는 가족을 잃고도 사부의 성공을 부정하지 못하는 생활 구조자 후보.
- 사부 측도 피해·통증·죄를 인식함.
- 최종 갈등이 선과 악보다 강제의 효율과 분산 선택의 불완전성 대결이 됨.

## 2.5 장기 욕망이 물리적 성과로 누적

- 객잔 한 곳에서 시작해 수로·도시·산길·항구로 다른 방식이 생김.
- 동일 문패나 본부를 만들지 않음.
- 제5부부터 서유휘 자신이 남들이 만든 길의 도움을 받음.
- 제7부에는 서유휘 없이 네트워크가 작동해야 함.

# 4. P2 보정

1. 첫 신병 작업명은 장면 검증 뒤 붙인다.
2. `일곱 번의 종`이 제목이나 반복 캐치프레이즈가 되지 않게 한다.
3. 하진의 이탈 희망자 숫자 `열두 명`은 작업값이며 화수에 따라 조정.
4. 묵연산이 마지막에 갑자기 악인으로 변하지 않게, 남으려는 사람을 실제로 지키는 장면 유지.
5. 조문탁은 공개 결투의 사회적 지지를 확보해야 하며 혼자 규칙을 만든 것처럼 보이지 않게 한다.
6. 고연주 작업명과 직업어는 현대 가독성 감사 필요.

# 6. 사부 공정성 검사

사부에게 필요한 세 장면:

1. **빠른 성공:** 서유휘보다 먼저 대형 사고를 막음.
2. **실제 대가:** 사용자가 강제로 움직여 부상하고 관계가 깨짐.
3. **기억하는 죄:** 사부가 버린 사람들의 이름과 결과를 알고도 같은 선택 가능성을 인정.

사부에게 주면 안 되는 면죄부:

- 사실 다른 방법이 전혀 없었다는 절대 확정.
- 모든 희생자가 사부를 이해함.
- 서유휘의 최종 방식도 사부가 미리 설계함.
- 사부가 죽으면서 모든 책임이 사라짐.

핵심 지지자 고연주 후보 검사:

- 사부 편이어도 민간인 구조를 우선해야 함.
- 서유휘에게 감화되어 즉시 전향하지 않음.
- 최종부 선택은 사부 배신이 아니라 자기 현장 원칙의 연장이어야 함.

# 7. 돌아올 길 네트워크 감사

통과 요소:

- 동일 이름·문패 없음.
- 장소마다 대가와 운영 조건이 다름.
- 서유휘 소유가 아님.
- 떠난 인물이 돌아오지 않아도 관계가 이어짐.
- 치료·숙박·운송·신분 보호 기능이 분산.

실패 신호:

- 사람들이 매번 `서유휘 님의 은혜`를 말함.
- 각 장소 운영자가 서유휘 명령을 기다림.
- 지도에 지부 숫자가 늘어나는 것이 주요 보상.
- 모든 인물이 최종부에 같은 편으로 집결.
- 객잔이 천하 정보의 중심이 됨.

예방:

- 제4부 나해란, 제5부 백리현, 제7부 고연주처럼 서유휘와 불편하거나 적대적인 인물도 귀환 기능을 운영.
- 한 장소는 제7부에 잘못된 판단으로 실패.
- 한 인물은 최종부에 참가하지 않고 자기 지역을 지키는 결말 허용.
