# 《팔대신병록》 이름·직업어·전면 문장 가독성 감사 v1

상태: `audit-complete / renaming-required / human-edit-pending`
목적:

> 전통 무협의 장르 감각은 유지하되, 작품 소개와 대사에서 낡은 번역투·설정집 용어·비슷한 이름이 독자 진입을 방해하지 않게 한다.

핵심 원칙:

> **설계서는 정확한 말, 작품 전면은 쉬운 말, 인물 대사는 그 사람만의 말.**

---

# 1. `떠돌이 대련꾼` 판정

## 장점

- 서유휘가 무엇으로 먹고사는지 즉시 보임.
- 문파에 속하지 않고 여러 무관·문파·지역을 이동할 이유가 생김.
- 돈·빚·비무·부상·명성의 반복 엔진이 있음.
- 표사·현상금 사냥꾼·교관과 다른 생활형 무인 가능.

## 문제

`대련꾼`은 뜻은 쉽지만:

- 시대 직업명처럼 들리지 않음.
- 현대 스포츠의 스파링 파트너처럼 보일 수 있음.
- 제목과 작품 소개에 들어가면 가벼운 코미디 직업물로 오해될 수 있음.

## 권고

`대련꾼`은 설계 편의상 작업어로만 사용한다.

작품 소개:

> 문파도 돈도 없는 서유휘는 남의 무공 수련 상대를 해 주며 떠돈다.

본문에서 다른 사람이 부르는 말:

- 돈 받고 비무해 주는 사람
- 무관의 임시 대련 상대
- 객원으로 불려 온 무인
- 남의 제자 대신 맞아 주는 사람

서유휘 자기소개:

> “대련비만 주면 문파 이름은 안 묻습니다.”

주의:

- 모든 곳에서 동일한 공식 직함을 사용하지 않음.
- 무관에서는 대련 상대, 문파에서는 객원 무인, 시장에서는 돈 받고 싸우는 사람으로 다르게 인식.

판정:

- 직업 구조: `maintain-candidate`
- `대련꾼` 전면 명칭: `design-shorthand-only`

# 2. 장르 관습어 판정

## 그대로 사용 가능

장면에서 설명 없이 이해 가능한 말:

- 강호
- 문파
- 사부
- 사형·사제·사저·사매
- 객잔
- 비무
- 내공
- 검법·장법·도법
- 장문인
- 개방
- 정파·사파

## 소개문에서는 쉬운 말 우선

### 후기지수

본문에서는 사용 가능.
작품 소개에서는:

- 강남에서 가장 이름난 젊은 검객
- 명문이 내세운 젊은 고수
- 이번 비무대회의 우승 후보

로 먼저 설명.

### 산문

본문 사용 가능.
첫 등장에서는:

- 문파의 정문
- 산 위로 들어가는 문

이라는 행동 맥락을 붙임.

### 검진

기술명처럼 먼저 말하지 않음.

- 여러 제자가 종소리에 맞춰 자리를 바꾼다.
- 한 사람을 상대하는데 검이 사방에서 같은 박자로 들어온다.

를 보여 준 뒤 이름을 붙임.

### 대협

초반 자기소개·칭찬에 남발하지 않음.
결말에 서유휘를 공식 `대협`으로 선포하는 장면보다, 생활인들이 도움을 기억하는 쪽을 우선.

# 3. 설계어와 본문어 분리표

| 설계서 내부 | 본문 전면 |
|---|---|
| 강제 연결 | 몸이 제 뜻과 다르게 같은 박자로 움직였다 |
| 명령 기능 | 다른 칼을 억지로 움직이게 하는 울림 |
| 감지 기능 | 먼 곳의 칼이 움직일 때 먼저 떨림 |
| 보호 기능 | 반동을 대신 받아 사용자를 살리는 성질 |
| 삼분 재련 | 한 사람이 쥘 힘을 셋으로 약하게 나눔 |
| 거부 동작 | 자기 몸의 박자를 되찾는 습관 |
| 귀환 장소 네트워크 | 돌아가서 문을 두드릴 곳들 |
| 사회적 엔진 | 자꾸 다시 만나는 사람과 장소 |
| 독립 결산 | 이번 일은 이번 부에서 끝냄 |
| 현상범 | 문파와 관부가 함께 쫓는 사람 |
| 전승품·복원품 | 오래 써 온 물건·옛 모양대로 다시 만든 물건 |
| 정통성 | 누구의 물건이라고 인정할 것인가 |

원칙:

- 본문 인물이 설계어를 말하면 수정.
- 회차 제목에 행정·기능 용어를 넣지 않음.
- 독자가 기능을 먼저 보고 이름은 나중에 듣게 함.

# 4. 현재 작업명 음성 감사

현재 작업명:

- 서유휘
- 백리현
- 양소홍
- 하진
- 진소무
- 두약란
- 연화진
- 나해란
- 문사연
- 고연주
- 석아문
- 백무진
- 심관도
- 묵연산
- 조문탁

## 문제 1 — 비슷한 끝소리

- 하진·연화진·백무진
- 두약란·나해란
- 문사연·고연주

장기 연재에서 인물 수가 늘면 독자가 이름을 헷갈릴 수 있다.

## 문제 2 — 역할을 너무 직접 암시

- `연화진`은 여성 무협 조연의 고전적 작업명 느낌이 강함.
- `나해란`은 해상 인물이라는 역할이 이름에서 지나치게 보일 수 있음.
- `심관도`는 무거운 악역명처럼 들림.
- `묵연산`은 전형적 사파 고수명에 가까움.

## 문제 3 — 성씨·음절 충돌

- 백리현의 `백리`가 복성인지 이름 구조인지 첫 등장에 혼동 가능.
- 백리현·백무진이 다른 인물인데 `백`과 `리/무` 리듬이 겹침.
- 진소무와 하진이 장면에서 자주 붙으면 `진` 음절 반복.

## 유지 우선 후보

### 서유휘

- 사용자 선택 이름.
- 음성과 인상이 독특함.
- 유지.

### 양소홍

- 생활인·객잔 주인 이미지에 비교적 잘 맞음.
- 다만 유명 무협 캐릭터 연상을 별도 확인.

### 진소무

- 말맛은 있으나 하진과 음절 중복.
- 둘 중 한 명 재명명 권고.

### 두약란

- 의원 이미지와 잘 맞지만 나해란과 끝소리 충돌.
- 나해란 재명명 시 유지 가능.

# 5. 최종 이름 선택 규칙

한 부 전면 인물 이름은 다음을 만족한다.

1. 첫 음절이 서로 다름.
2. 끝소리 `진·연·란·무`가 한 장면에 반복되지 않음.
3. 역할을 이름에 직접 넣지 않음.
4. 너무 유명한 기존 무협 인물을 즉시 떠올리게 하지 않음.
5. 한국 독자가 한 번 보고 읽을 수 있음.
6. 성별 고정관념만으로 이름을 짓지 않음.
7. 중요한 인물은 두 음절 또는 세 음절 리듬을 섞음.
8. 문파·지역 이름과 인물 이름의 첫소리를 겹치지 않음.

장면 단위 검사:

- 이름 있는 인물 5명 중 같은 끝소리 최대 2명.
- 대화 태그 없이도 말투와 행동으로 구분 가능해야 함.

# 6. 재명명 우선순위

## 1순위 — 즉시 재명명 검토

- 연화진
- 나해란
- 백무진
- 묵연산
- 심관도

이유:

- 작업명 느낌·역할명 느낌·음절 충돌이 큼.

## 2순위 — 관계 묶음에서 검토

- 하진 또는 진소무 중 한 명
- 문사연 또는 고연주 중 한 명
- 백리현의 복성 사용 여부

## 유지 후보

- 서유휘
- 양소홍
- 두약란
- 조문탁 후보
- 석아문 후보

정본화 전 이름 후보를 네 안씩 무작정 늘리지 않는다.

권고 순서:

1. 역할·성격·출신 확정
2. 같은 장면의 다른 이름 확인
3. 3~5개 후보 생성
4. 소리 내어 작품 소개·대사에 넣어 봄
5. 사용자 Human Edit

# 7. 작품 소개 문장 감사

현재 작업 문장:

> 사라진 사부의 도전장이 강남 최고의 후기지수에게 날아왔다. 문파도 돈도 없는 떠돌이 대련꾼 서유휘는 그를 만나기 위해 남의 문패를 빌려 비무대회에 끼어든다.

문제:

- `후기지수`, `떠돌이 대련꾼`, `문패`, `비무대회`가 한 문단에 몰려 장르어 밀도가 높음.
- 재미는 이해되지만 약간 기획문처럼 보임.

## 전면 쉬운 문장 후보 A

> 죽은 줄 알았던 사부가 강남에서 가장 잘나가는 젊은 검객에게 도전장을 보냈다. 서유휘는 이유를 묻기 위해 남의 문파 이름을 빌려 대회에 들어간다.

장점:

- 쉬움.
- 사부·상대·거짓말이 즉시 보임.

위험:

- 서유휘의 생계와 성격이 빠짐.

## 후보 B

> 돈을 받고 남의 대련 상대를 해 주며 떠돌던 서유휘에게, 죽은 사부의 도전장이 돌아왔다. 문제는 그 편지를 받은 사람이 강남에서 가장 유명한 젊은 검객이라는 것, 그리고 서유휘에게는 그를 만날 문파 이름조차 없다는 것이다.

장점:

- 생계와 결핍이 보임.
- 웹소설 소개형 리듬.

위험:

- 조금 길다.

## 후보 C

> 서유휘는 돈이 필요했고, 사부가 왜 죽은 척했는지도 알아야 했다. 그래서 남의 문패를 빌려 강남 청년비무에 들어갔다. 첫 상대는 그 문패의 진짜 주인이었다.

장점:

- 캐릭터 행동과 회차 훅이 강함.
- 마지막 문장이 첫 사건을 즉시 만듦.

위험:

- 현재 상세안과 `진짜 문패 주인` 관계를 맞춰야 함.

PM 권고:

- 작품 소개는 **B의 정보 + C의 짧은 행동 리듬**을 결합해 다시 작성.
- `후기지수`와 `대련꾼`은 첫 소개에서 둘 다 사용하지 않음.

# 8. 대사 톤 금지

## 올드하게 보일 가능성이 높은 방식

- “강호의 대의가 어찌 개인의 은원보다 가벼울 수 있겠는가.”
- “본좌는 천하창생을 위해 이 한 몸을 버리리라.”
- “네놈의 검에는 의가 없구나.”

뜻이 필요하면 행동과 짧은 말로 바꾼다.

- “그 사람들까지 버리자는 겁니까?”
- “늦으면 다 죽는다.”
- “그 칼, 사람보다 먼저 챙겼네요.”

## 지나치게 현대적인 방식도 금지

- 인터넷 유행어
- 현대 회사·게임 은어
- 밈을 전제로 한 비꼼
- 시대 밖 욕설 리듬

목표:

- 짧고 쉬우나 현대인이 코스프레하는 말처럼 보이지 않는 중간 톤.

# 9. 회차 제목 원칙

좋은 방향:

- 도전장을 받은 사람
- 문패를 빌리다
- 강 위에서는 걷지 못한다
- 오늘은 안 갑니다
- 둘 다 살아 나오는 문
- 칼을 넘기지 마라
- 사부보다 먼저
- 자기 문을 열다

피할 방향:

- 합증의 조건
- 보관권 분쟁
- 명령 기능의 분리
- 강제 결속 체계
- 신병 정통성 심의

회차 제목은:

- 사람
- 행동
- 쉬운 물건
- 바로 다음 위험

중 하나를 전면에 둔다.

# 10. 현재 판정

- `대련꾼` 직업 구조: `maintain / wording-revise`
- 장르 관습어: `selective-use`
- 설계어 본문 유출: `mandatory-block`
- 작업명 음성 충돌: `renaming-required`
- 현재 작품 소개: `promising / rewrite-required`
- 문체 방향: `고전의 뼈대 + 쉬운 현대 한국어`
- 정본 이름·소개문: 사용자 Human Edit 전 불가
