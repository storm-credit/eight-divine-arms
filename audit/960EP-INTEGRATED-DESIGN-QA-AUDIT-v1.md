## 3. 부별 인과 QA

### 제1부 1~110화

- 이름 도용 → 거짓 소속 → 치료비 착취 구조 → 우승권 포기 → 자기 이름 회수의 인과가 닫힌다.
- 이름 없는 신병 작동은 사부 위치를 알려 주는 만능 추적기가 아니다.
- 곽무소의 정보 이중 판매는 제3부 관계 파열의 선행 원인으로 남긴다.

### 제2부 111~225화

- 세 배 실종 → 거짓 신호 → 임도초의 생활 기술 → D3 작동 → 자기 퇴로 포기의 인과가 닫힌다.
- D3는 서유휘가 획득하는 전리품이 아니다.
- 임도초의 감각 혼선은 사건 종료와 함께 사라지지 않는다.

### 제3부 226~345화

- 진하 실종 오해 → 자발적 진입 확인 → 세 봉투 → 세 종류의 선택권 → 독립 연락망의 인과가 닫힌다.
- 서유휘는 진하를 데려오는 데 실패한 것이 아니라, 데려올 권리를 포기함으로써 승리한다.
- 빈 봉투는 제8부 분산 실행권의 선행 이미지다.

### 제4부 346~465화

- 진품 판정 제도 → 두 사용자 결투 → 기록의 폭력 → 둘의 생존이라는 승리 조건이 닫힌다.
- 위담의 자백은 사부 만능 흑막설을 확정하지 않고 오히려 일부 진실만 제공한다.
- 신병 기능 설명은 사고·결정·대가 안에서만 지급한다.

### 제5부 466~590화

- 소겸의 문파 의무 → 문계서의 생활 비용 → 산문·검진 갈등 → 젊은 제자의 선택권으로 인과가 닫힌다.
- 서유휘가 소겸 대신 문파를 구하거나 장악하지 않는다.
- 결별은 질투나 고백 실패가 아니라 서로 다른 책임 선택의 결과다.

### 제6부 591~715화

- 독점 방지 작업 → 세 지역 비동시 작전 → 재련 실패 → 영구 기능 손상 → 사용권 분산의 인과가 닫힌다.
- 실패는 다음 부를 위한 가짜 위기가 아니라 실제 손실이다.
- 모든 신병과 사용자를 한 장소에 집합시키지 않는다.

### 제7부 716~840화

- 연소담의 실제 구조 성공 → 서유휘 방식의 지연·손실 → 강제와 선택의 실전 경쟁 → 같은 내공 경로 규칙 설치가 닫힌다.
- 사부는 논리적으로만 옳거나 틀린 사람이 아니라 실제로 더 빨리 사람을 살린다.
- 서유휘가 자기 방식의 무오류성을 포기해야 제8부 선택이 성립한다.

### 제8부 841~960화

- 다섯 구역 동시 위기 → 한 점 절초의 유혹 → 실행권 분산 → 여러 퇴로 연결 → 신병별 상이한 귀환 → 사부 생존 책임의 인과가 닫힌다.
- 서유휘는 옛 집중 초식 경로를 잃지만 무공 전체를 잃지 않는다.
- 후일담에서 다중 전투·구조·지도 능력으로 절정급 전투력을 행동으로 증명한다.

## 4. 교차 장부 QA

### 인물·관계

- 소겸: 제1부 판독 → 제5부 결별 → 제8부 제한적 재협력.
- 연소담: 부재한 사부 → 상반된 증언 → 실제 성공 → 생존 책임.
- 진하: 정보 제공자 → 독립 작전가 → 최종 분산 신호 설계자.
- 곽무소: 이중 판매 → 신뢰 파열 → 제한적 협력. 완전한 원상복구 없음.

### 신병

- D1~D8은 발견 순서가 곧 소유 순서가 아니다.
- 기록명은 기관·감정·과거 문서, 생활명은 현장 사용자 공동체가 우선한다.
- D5·D6는 음성·형상 오독 감시 대상으로 유지한다.
- 결말 처리는 사용·거부·약화·공동체 귀환으로 분산한다.

### 복선

- 제1부 금속 작동은 제2부 첫 실물보다 앞서 제목 약속을 지급한다.
- 제3부 빈 봉투는 제8부 실행권 분산으로 회수한다.
- 제4부 진품 기록 문제는 제8부 기록 권한 분산으로 회수한다.
- 제7부 동일 내공 경로 규칙은 최종 무공 변형의 필수 물리 근거다.

### 연속성

- 총 시간 약 3년 반~4년.
- 서유휘 어깨·내공 경로 손상은 회복 구간은 있어도 초기화되지 않는다.
- 장거리 이동과 연락 지연은 수일~수 주로 유지한다.
- 제6부 실패의 손상은 제8부까지 남는다.

## 5. P1 제작 위험과 예방 Gate

1. **제1부 과밀**: 비무 경기보다 이름·생계·착취·사부 미스터리가 우선한다.
2. **제4부 설명 과잉**: 진품과 신병 기능은 결투·사고·선택 안에서만 드러낸다.
3. **제5부 주인공 이탈**: 소겸 문파 서사도 서유휘의 선택 비용을 통해 본다.
4. **제6부 보고 반복**: 지역 보고를 결과가 다른 행동 장면으로 바꾼다.
5. **제7부 사부 과점**: 연소담 성공을 인정하되 서유휘가 관찰자에 머물지 않게 실제 실패와 대안 설계를 병렬 배치한다.
6. **제8부 주제 연설화**: 여러 퇴로는 말이 아니라 밧줄·다리·배·종·발자리의 물리 행동으로 보여 준다.
7. **후일담 과장**: 15화 이상 정리만 이어지면 생활 사건·대련·책임 이행 장면으로 압축한다.
