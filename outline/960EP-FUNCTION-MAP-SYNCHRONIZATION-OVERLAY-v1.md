## 4. 부별 동기화

### 제1부 1~110화

보존:

- 참가하지 않은 비무 명단.
- 문서상 `반보문`, 실제 과거 `반보회`.
- 서유휘의 생계·거짓 소속·첫 패배·치료비 착취 구조.
- 80~100화 이름 없는 신병 작동.
- 공식 우승이 아닌 자기 이름 회수.

압축:

- 비슷한 예선 경기.
- 운영자 장무겸의 같은 논리 반복.
- 추천 문서 전달 경로의 중복 조사.

최신 관계:

- 소겸은 승부와 규칙의 라이벌이며 연애 진전의 보상으로 쓰지 않는다.
- 진하는 구조 대상이 아니라 제1부부터 독립 판단을 보인다.
- 곽무소의 정보 이중 판매는 제3부 배신의 선행 설치다.

### 제2부 111~225화

보존:

- 사라진 배 세 척.
- 임도초의 강 전문성.
- 첫 완전 신병 실물.
- 서유휘가 물건에서 정답을 얻지 못함.
- 한 자리 선점에서 여러 자리 연결로 확장.
- 객잔의 중립 상실.

신병 동기화:

- 첫 실물은 D3 `철조구 / 끌쇠` 계열의 수로·사슬 생활 기능으로 읽는다.
- 정확 기록명은 현장 결산 이후 감정 문서에서만 늦게 나온다.
- 임도초의 감각 혼선은 제6·8부까지 지속한다.

압축:

- 세 배의 화물·항로 조사 중 같은 정보 반복.
- 상단 호위와의 유사 검문 충돌.

### 제3부 226~345화

보존:

- 진하가 자기 발로 정보 조직에 들어감.
- 떠날 사람·남을 사람·추적받는 가족의 세 길.
- 곽무소의 배신은 이해 가능하지만 즉시 용서되지 않음.
- 진하는 객잔으로 돌아오지 않고 독립 연락망을 선택.

복선 동기화:

- 빈 봉투는 최종 도시의 분산 신호 원리와 대응한다.
- 서유휘가 다른 사람 계획의 미끼가 되는 경험은 제8부의 실행권 분산을 준비한다.

압축:

- 조직의 선악을 설명하는 반복 대화.
- 시장 추격이 같은 목적을 두 번 수행하는 구간.

### 제4부 346~465화

보존:

- 한 명만 진품 사용자로 인정하는 공식 결투.
- 둘 모두 살아남는 것이 진짜 승리.
- 위담의 자백은 일부 진실.
- 사부의 성공과 희생에 대한 상반된 증언.

복선 동기화:

- 기록이 사람을 진품·가짜로 나누는 폭력은 제8부 기록 결산으로 회수한다.
- 사부가 모든 배후가 아니라 현장 선택을 반복한 사람이라는 증거를 배치한다.

압축:

- 두 신병 기능을 순서대로 설명하는 시연.
- 위담의 같은 죄책감 진술 반복.

### 제5부 466~590화

보존:

- 소겸의 특정 궁관·속가 계통.
- 문계서의 장애와 과거 명령 비용.
- 산문 잠입·검진 파훼·젊은 제자들의 자기 선택.
- 서유휘가 소겸 대신 문파를 구하거나 차지하지 않음.

관계 동기화:

- 소겸과 서유휘는 문파 선택으로 실제 결별한다.
- 저강도 감정 긴장을 사용하더라도 결별을 연애 오해나 질투로 축소하지 않는다.

압축:

- 무당산 관광·도량·관습 안내.
- 문파 내부 파벌 설명이 행동 없이 이어지는 구간.

### 제6부 591~715화

보존:

- 신병 독점을 막으려는 분산 작업.
- 재련 실패와 영구 기능 손상.
- 세 지역 비동시 작전과 연락 지연.
- 서유휘가 해법과 책임을 독점하지 않음.

신병 동기화:

- 여덟 신병을 한자리에 모으지 않는다.
- 실제 현장에는 최대 일부만 동시 노출한다.
- 각 사용자는 자기 공동체 필요에 따라 사용·거부·약화를 선택한다.
- D5 `연생장 / 잇대`, D6 `청맥인 / 맥칼`은 생활명을 우선한다.

압축:

- 세 지역의 동일 형식 보고.
- 실패 원인을 회의에서 다시 설명하는 장면.

### 제7부 716~840화

보존:

- 연소담이 최소 두 번 서유휘보다 먼저 실제 사람을 살림.
- 강제 구조가 빠르고 성공률이 높다는 증거.
- 사용자와 사부 모두 후유증.
- 서유휘 방식도 한 지역에서 실제로 늦고 손실을 냄.
- 한 점 절초와 여러 퇴로가 같은 내공 경로를 쓴다는 물리 규칙.

관계 동기화:

- 연소담은 전지적 흑막이 아니다.
- 양홍주·위담·고유직은 같은 과거를 서로 다른 위치에서 증언한다.
- 여성이라는 사실을 반전으로 숨기지 않는다.

압축:

- 사부 지지자와 반대자의 회의.
- 세 지역 이동 보고와 사고 현황 재설명.

### 제8부 841~960화

보존:

- 최종 수운도시 다섯 구역.
- 사부를 끊을 한 점 절초와 여러 퇴로의 양립 불가.
- 서유휘가 공격 자리를 밧줄·다리·배·종소리·동료 발자리로 넘김.
- 무공 전체 상실 없음.
- 사부 생존과 지역별 책임.
- 서유휘는 장문인·맹주가 되지 않음.

결산 동기화:

- 팔대신병은 사용·거부·기능 약화·공동체 귀환으로 서로 다르게 처리한다.
- 서유휘는 옛 집중 초식은 잃지만 다중 전투·구조·지도에서 더 강한 절정 고수다.
- 로맨스는 PM B안 기준으로 확정 고백·혼인 없이 신뢰와 미완 긴장을 남긴다. 사용자 변경 가능.
- 후일담은 15화 이상 정리만 이어지지 않게 생활 대련과 새 문제를 포함한다.

## 5. 10화 묶음 공통 Gate

모든 10화 묶음은 아래 중 최소 두 가지를 바꿔야 한다.

- 직접 목표
- 관계 상태
- 신분·평판
- 무공의 성공 또는 실패
- 장소·이동 조건
- 정보 공개 수준
- 부상·사용 대가
- 제한 시간

20화 동안 비가역 변화가 하나도 없으면 통합·삭제 후보로 표시한다.

## 6. 금지 동기화

- 960화에 맞추려고 사건 핵심을 잘라 내지 않는다.
- 1000화 기능표의 번호를 정본 번호처럼 인용하지 않는다.
- 구버전 이름을 새 인물로 중복 생성하지 않는다.
- 제6부를 팔대신병 설명회나 수집 결산으로 만들지 않는다.
- 사부를 모든 부 적대자의 배후로 연결하지 않는다.
- 제8부에서 서유휘의 힘 전체를 빼앗지 않는다.
- 원고·완성 장면을 작성하지 않는다.
