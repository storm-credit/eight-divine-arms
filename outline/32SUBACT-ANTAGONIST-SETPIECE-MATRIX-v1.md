# 《팔대신병록》 32서브액트 적대자·전투 세트피스 행렬 v1

상태: `canon-production-blueprint / manuscript-locked`
작성일: `2026-08-01`

## 운용 원칙

- 적대자는 악인만을 뜻하지 않는다. 같은 보물·기록·생존을 다른 방식으로 원하는 사람·조직·환경을 포함한다.
- 한 서브액트에는 대표 적대축 1개, 보조 압력 1개만 전면화한다.
- 세트피스는 무공 과시가 아니라 목표·지형·수집품·관계 선택이 동시에 바뀌는 사건이어야 한다.
- 동일한 비무대·추격·경매·비경 구조를 연속 사용하지 않는다.

## 최종 Gate

- 32개 서브액트 대표 적대축 중 동일 조직 연속 반복: 없음.
- 비무대 중심 세트피스: ACT 1·4 일부로 제한.
- 지형 기능 반복: 물·산·도시·화로·기록·재난으로 교차.
- 서유휘 승리 방식 반복: 격파·포기·협상·구조·감정·기록으로 분산.
- 소연후·연무진·백여울이 주인공성을 대체하지 않음: 운용 조건부 PASS.
