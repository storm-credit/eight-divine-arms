# 《팔대신병록》 여성 사부 관계·설치 장부 v1

상태: `active-candidate-ledger / pm-edited / manuscript-locked`

목적:

> 여성 사부가 제7부에 갑자기 등장하거나 성별 자체가 반전처럼 소비되지 않게, 1~750화의 기억·행동·관계에 일관되게 설치한다.

원칙:

- 사부의 성별은 숨겨야 할 미스터리가 아니다.
- 본명과 현재 위치는 숨길 수 있지만, 서술이 의도적으로 대명사를 피하며 독자를 속이지 않는다.
- 모녀 대체·친모 반전·숨은 혈통 금지.
- 사부의 매력과 과거가 서유휘의 현재 선택을 압도하지 않는다.

---

## 1부 1~120화

### 1~20화

- 서유휘가 사부를 떠올릴 때 얼굴 전체 회상보다 생활 습관 하나를 사용.
- 젖은 신발을 불 옆에 바로 두지 말라는 가르침.
- 서유휘가 `그 여자`라고 냉소하거나 `어머니 같은 사람`이라고 설명하지 않음.
- 양소홍은 사부를 이름 대신 오래된 별칭으로 한 번 부를 수 있음.

### 21~50화

- 사부의 필체와 수결이 최근 명단에 남아 있음.
- 작은 무관의 나이 든 관주는 사부를 과거 나루 구조 현장에서 본 적이 있으나 영웅담을 길게 말하지 않음.
- 사부가 서유휘에게 처음 가르친 것은 상대를 쓰러뜨리는 초식이 아니라 뒤 사람의 발을 밟지 않는 법이었다는 짧은 기억.

### 51~80화

- 양소홍은 사부가 사람을 살리고도 감사 인사를 받기 전에 떠났다는 기억과, 계산이 너무 빠르다는 불편함을 함께 말함.
- 사부를 따뜻한 성녀나 냉혈한으로 한쪽만 묘사하지 않음.

### 81~100화

- 이름 없는 금속 흔적이 같은 박자를 밀어 넣을 때 서유휘는 사부가 과거 훈련에서 강제로 호흡을 맞추던 방식을 떠올림.
- `사부가 신병을 만들었다`는 추론 금지.
- 윤겸은 서유휘의 박자 끊기가 누구에게 배운 것인지 묻지만 답을 받지 못함.

### 101~120화

- 사부가 살아 있을 가능성만 지급.
- 왜 제자 이름을 사용했는지는 미지.
- 서유휘는 반가움보다 분노를 먼저 느낌.

---

## 2부 121~240화

- 장강 선주 공동체 일부는 사부를 구조 영웅으로 기억.
- 다른 나루 사람은 사부가 위험 구역을 너무 빨리 버렸다고 비난.
- 임초는 사부를 직접 존경하거나 증오하지 않고, 자기 어른들의 상반된 기억만 알고 있음.
- 사부가 첫 신병의 현재 사용자·소유자를 지정했다는 설정 금지.
- 서유휘가 여러 배의 발자리를 이을 때 사부 방식보다 느리지만 사용자 판단을 기다리는 차이가 처음 보임.

---

## 3부 241~365화

- 사부 신규 단서를 최소화.
- 하진은 서유휘가 사람의 선택보다 구조 계획을 먼저 세우는 습관이 사부에게서 왔다고 지적할 수 있음.
- 서유휘는 `사부와 나는 다르다`고 즉시 부정하지만 행동은 닮아 있음.
- 사부의 이름이나 현재 위치를 팔아 정보전의 보상으로 사용하지 않음.

---

## 4부 366~490화

### 위담의 증언

- 위담은 사부를 강하고 잔혹한 영웅 한 단어로 정의하지 않음.
- 함께 사람을 살린 구체 행동과 퇴로를 닫은 구체 행동을 모두 말함.
- 사부가 희생자 이름을 기억했다는 사실이 면죄부가 되지 않음.
- 사부는 과거 위담에게 자기 선택을 이해해 달라고 요구하지 않았음.

### 서유휘 반응

- 처음에는 사부를 변호하려다 생존자에게 거부당함.
- 이후 사부를 악인으로 단순화하려 하지만, 실제 생존자들의 감사 때문에 실패.
- 제4부 끝의 질문은 `살아 있나`에서 `그 방식이 다시 시작되면 막을 수 있나`로 바뀜.

---

## 5부 491~620화

- 윤겸 문파의 어른 일부는 사부를 문파 질서를 무시한 위험한 고수로 기억.
- 젊은 제자 일부는 사부 덕분에 선대가 살았다는 영웅담만 앎.
- 서유휘와 윤겸은 같은 사부 기억을 공유하지 않으므로 각자의 사승 문제를 서로 대신 해결하지 못함.
- 사부는 등장하지 않음.
- 서유휘가 검진 명령을 끊는 방식에서 사부의 `같은 박자`와 반대되는 원리가 발전.

---

## 6부 621~750화

- 재련 실패 때 서유휘가 물건을 먼저 보는 실수는 사부와 닮은 지점으로 드러남.
- 두약란은 `사부처럼 굴지 마라`는 주제 대사보다 현재 사용자의 작업 중단권을 요구하는 행동으로 차이를 만듦.
- 사용자별 다른 거부 동작이 사부의 동일 박자 강제에 대한 구체 대응이 됨.
- 제6부 끝의 동시 울림은 사부의 전지적 계획이 아니라, 서유휘 일행이 남긴 불완전한 흔적을 사부가 뒤늦게 포착한 것.

---

## 7부 751~880화

### 현재 등장

- 성별 공개 반전 없음.
- 사부는 서유휘를 애칭으로 부르지 않고 현장 이름으로 부를 수 있음.
- 첫 장면은 사승 재회가 아니라 실제 구조 성공.
- 재회 감정은 구조 뒤 짧은 사적 장면에서 발생.

### 사적 관계

- 서유휘가 묻는 첫 질문은 `왜 날 버렸어`보다 `왜 내 이름을 썼어`에 가까움.
- 사부는 제자의 이름을 이용한 것을 인정하지만 미래를 시험했다는 변명 금지.
- 이유 후보: 자기 계획을 막을 가능성이 있는 유일한 사람을 강호의 공개 시선 안으로 끌어냄.
- 이것도 사부의 통제 습관이며 정당화되지 않음.

### 무공 관계

- 사부는 서유휘의 초기 발자리 원리를 거의 모두 읽음.
- 서유휘가 여러 사람에게 원리를 나눠 준 뒤부터 예측이 틀림.
- 최종 초식은 사부에게 배운 원리를 완성하는 동시에 그 원리의 강제를 거부함.

---

## 8부 881~1000화

- 사부와 서유휘의 결투는 개인 감정만으로 도시를 멈추지 않음.
- 두 사람의 선택이 밧줄·신호·수문·사용자 몸에 실제 영향을 줌.
- 사부 패배 뒤 포옹·유언·즉시 화해 금지.
- 둘은 서로를 이해해도 용서·복종·절연 중 하나로 쉽게 정리되지 않음.
- 후일담에서 서유휘는 사부를 감시하거나 돌보는 사람이 되지 않음.

## 사부 정보 공개 사다리

| 구간 | 독자가 아는 것 |
|---|---|
| 1~25 | 실종 또는 사망 추정, 최근 수결 존재 |
| 26~80 | 현장 구조 무인이었고 서유휘에게 퇴로부터 가르침 |
| 81~120 | 같은 박자와 무기 반응을 아는 과거가 있음 |
| 121~240 | 장강에서 영웅과 가해자 기억이 함께 남음 |
| 241~365 | 서유휘의 통제 습관 일부가 사부와 닮음 |
| 366~490 | 생존, 대형 성공, 작은 나루 희생, 현재 계획 |
| 491~620 | 문파 세계에서의 상반된 평판 |
| 621~750 | 불완전 신병 흔적을 포착할 조건 형성 |
| 751~880 | 현재 구조 성공·강제 방식·서유휘 이름 사용 이유 |
| 881~1000 | 방식의 최종 결과와 살아서 책임질 미래 |
