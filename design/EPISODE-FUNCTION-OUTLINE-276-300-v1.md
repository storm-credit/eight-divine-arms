## 최종 25화 점검

- 276~280: 적대자 보호 논리의 최종 선택
- 281~285: 지상·해상·지하 삼중 전투
- 286~290: 결말의 양립 불가 조건과 도덕 선택
- 291~295: 원본 파괴·문 개방·대규모 구조
- 296~300: 생계·명예·관계·제도적 결과

## 결말 금지 확인

- 새 문서로 해결하지 않음
- 새 신병 능력으로 해결하지 않음
- 한 흑막 처치로 종결하지 않음
- 공개 회의가 클라이맥스를 대신하지 않음
- 주인공 사망으로 감정 비용을 간단히 처리하지 않음
- 모든 피해자 복권·모든 비밀 공개의 완전 해결을 선언하지 않음
