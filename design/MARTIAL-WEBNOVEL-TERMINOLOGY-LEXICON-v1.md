# 《팔대신병록》 한국 무협 웹소설 용어 설계 v1

상태: `canon-framework / expansion-active`
상위: `design/TERMINOLOGY-HONORIFICS-STYLE-GUIDE-v0.1.md`

## 1. 목적

무협 독자는 익숙하게 읽고, 신규 독자는 행동 속에서 자연스럽게 뜻을 배우게 한다.

용어는 백과사전처럼 많이 만드는 것이 아니라 다음 기능을 위해 만든다.

- 직업 쾌감
- 세력과 인물의 즉시 구분
- 전투 상황의 빠른 이해
- 회차 훅과 보상의 명명
- 시대감 유지

## 2. 용어층

### T1. 무료분 필수어 — 최대 7개

1. 표국
2. 표사
3. 검표수
4. 인계표사
5. 표두
6. 표물
7. 보증

운용:

- 첫 등장에 사전식 정의를 쓰지 않는다.
- 인물이 행동하거나 손실을 입는 순간 뜻을 보여 준다.
- 같은 화에 새 핵심 용어를 3개 넘게 넣지 않는다.

### T2. 첫 소구간 직업어

- 표행
- 인계표
- 표기
- 검표
- 봉인
- 인보
- 표채
- 배상
- 분점
- 총국
- 쟁자수
- 길잡이
- 전장
- 상단
- 수운

T2는 1~25화에 분산한다.

### T3. 강호 관계어

- 사부·사숙·사백·사형·사제·사저·사매
- 장문인·방주·맹주·당주·채주
- 대협·여협·소협·전배
- 객경·문객·낭인·산인

원칙:

- 사승 관계가 없는 인물에게 항렬 호칭을 붙이지 않는다.
- `낭인`은 모든 무소속 무인의 자동 명칭이 아니다.
- 같은 조직 안에서도 공식 호칭과 비꼬는 속칭을 구분한다.

### T4. 무공·경지어

공용:

- 하수·숙수·고수
- 삼류·이류·일류
- 절정에 들다
- 종사로 대우받다

수련·찬사:

- 등당입실
- 노화순청
- 화경
- 등봉조극
- 주천
- 삼화취정
- 오기조원

금지:

- 화경·현경을 모든 세력이 공유하는 숫자 레벨로 사용
- 한 번의 수치 설명으로 승패 결정
- 객관적 스탯창처럼 경지 표기

본문에서는 `누가 더 높은가`보다 다음을 우선한다.

- 거리
- 지형
- 무기 상성
- 부상
- 임무
- 동료 보호 부담
- 정보 비대칭

### T5. 병장기·전투어

- 검·도·창·봉·곤·극·궁·노·편·쇄·척·조·패
- 검로·도세·창세·보법·신법·심법·토납·운기
- 초식·변초·허초·살초·연환·봉쇄·파고들기

작가 설계용 카드:

- 거리
- 궤적
- 선행 동작
- 강점
- 약점
- 피로
- 부상 위험
- 호송 중 제약

본문에서 기술 이름을 외치기보다 독자가 움직임과 결과를 먼저 이해하게 한다.

### T6. 기환·팔대신병어

- 영물·영수·영초·법구·보패·신병
- 잔흔·감응·반응·하중 환각
- 감정·합증·보관·계승·사용 계보

무료분 원칙:

- `철조구`와 `잔흔`만 필요할 때 전면화
- 팔대신병 여덟 이름을 한꺼번에 제시하지 않음
- 기환은 설명보다 부작용과 오판으로 먼저 보임

### T7. 국가·상업·권리어

- 압수·봉인·수배·역참·위소·군문
- 별조·차견·회합·명부·패첩·노인·인보
- 전장·상단·상련·어음·채무·유예

행정극 방지:

- 용어가 등장하면 같은 장면에 물리적 대상이 있어야 한다.
- 압수는 누군가 상자를 가져가는 행동으로 보인다.
- 보증 정지는 누군가 말을 빌리지 못하고 사람을 고용하지 못하는 결과로 보인다.
- 채무 유예는 가족이 집이나 공방을 지킬 수 있는 시간으로 보인다.

## 3. 용어 도입 규칙

### 첫 도입 공식

`대상 → 행동 → 손실/보상 → 명칭`

예:

1. 서유휘가 봉인이 끊긴 상자를 발견한다.
2. 상자 주인이 바뀌었다고 판정한다.
3. 분점이 배상 책임을 지게 된다.
4. 그 뒤 `검표`라는 말을 사용한다.

### 재사용 공식

- 첫 등장: 행동으로 뜻 제시
- 두 번째: 다른 인물의 반응으로 사회적 의미 제시
- 세 번째: 독자가 이미 안다고 가정하고 훅이나 대사에 사용

## 4. 인물별 전문어 음성

### 서유휘

- 인계·하중·봉인·연결부·보증
- 짧은 반문으로 책임 소재를 찌름
- 화려한 무공 평론보다 현장 조건을 말함

### 진아령

- 집중·회수·계약·단일 책임·손실 최소화
- 규정과 결과를 짧게 단정

### 진소무

- 이름·가명·값·소문·길
- 정식 명칭보다 사람들이 실제 부르는 말을 사용

### 유청하

- 사승·명예·증언·비무·파문
- 정확하고 절제된 종문 용어

### 두약란

- 맥·열·독·용량·선후·환자
- 추상적 의리보다 몸의 결과를 먼저 말함

### 나해란

- 조류·신호·풍향·선수·선미·구조선
- 육지 강호 용어를 그대로 쓰지 않음

## 5. 용어 카드 필드

- 표제어
- 한자·이형
- 공식명·강호 통칭·지역 속칭
- 뜻
- 사용하는 인물·집단
- 첫 등장 예정 화
- 행동으로 보여 줄 장면 기능
- 독자가 오해할 가능성
- 시대착오 위험
- 유사어와 구분
- 정본 상태

## 6. 완료 조건

- 무료분 핵심어 7개 이하
- 1~25화 용어 도입표 완성
- 인물별 전문어 중복 감사
- 무공 경지와 실제 승패의 비수치화 확인
- 국가·상업 용어가 물리 행동과 연결됨
- 현대 조직·게임 용어 제거
- 화 단위 Outline에 첫 등장 위치 기록
