## 1. 공통 잠금 규칙

- 서유휘는 여덟 신병을 전부 소유·사용·적합하지 않는다.
- 신병은 무공을 자동 전수하지 않는다.
- 사용자의 생활 기술이 신병 기능보다 먼저다.
- 작동은 한 번에 단순한 물리·감각 동작만 증폭하거나 맞춘다.
- 여러 신병의 동시 작동에는 사용자·중간 신호·박자가 필요하다.
- 제6부 재련은 성공하지 않으며 영구 손상·정치 비용·사용권 분산을 남긴다.
- 최종 처리는 소유가 아니라 사용·거부·기능 약화·공동체 귀환으로 다르게 한다.

## 3. 비수집 배치표

| 부 | 전면 신병 수 | 처리 원칙 |
|---|---:|---|
| 1부 | 0개 완전 공개 | 이름 없는 금속 흔적·박자만 지급. 회수 실패 |
| 2부 | 1개 완전 실물 + 1개 흔적 | 임도초의 생활 기술이 중심. 서유휘 소유 없음 |
| 3부 | 1~2개 간접 기능 | 정보·봉투·측정의 신뢰 문제. 물건 추적극 금지 |
| 4부 | 2개 충돌 | ‘진품 하나’ 판정을 거부하고 두 사용자 생존 |
| 5부 | 1~2개 문파 사용 | 소겸 문파의 비급·계승물이 아니라 생활 비용과 연결 |
| 6부 | 여러 개 비동시 작전 | 한 장소 집결 금지. 재련 실패와 사용권 분산 |
| 7부 | 여러 개 동시 울림 | 사부의 강제 구조 성공과 후유증 동시 제시 |
| 8부 | 필요한 기능만 분산 사용 | 전부 한곳에 진열하지 않고 다섯 퇴로에 서로 다르게 기여 |

## 4. 사부 강제 연결 한계

연소담은 다음 조건이 모두 맞을 때만 개입할 수 있다.

1. 둘 이상의 신병 또는 그 기능 흔적이 같은 시간대에 작동.
2. 종·활·수문 신호 같은 중간 박자가 존재.
3. 사용자가 이미 하려던 동작과 완전히 반대되지 않는 단순 동작.
4. 거리와 지형상 신호 전달이 가능.

불가능:

- 생각·기억 읽기.
- 복잡한 무공 원격 시전.
- 사람을 장시간 조종.
- 신병 없이 천하 어디서나 개입.
- 모든 사건을 미리 설계.

대가:

- 사용자 관절·호흡·감각 손상.
- 연소담 자신의 내공 경로와 감각 손상.
- 잘못된 신호가 증폭될 위험.
- 성공하더라도 동의 없는 구조에 대한 정치·윤리 책임.

## 5. 제6부 재련 실패 고정 결과

- 목표: 신병 기능을 누구도 독점하지 못하도록 분산 가능한 형태로 바꿈.
- 실패: 기능을 동일하게 복제하지 못하고 일부 신병만 약화·오작동.
- 물리 비용: D5 사용자 오른손 감각 손상, D6 감각 혼선, D3 연결부 파손 후보.
- 관계 비용: 두약란이 작업을 중단시키며 서유휘와 충돌.
- 정치 비용: 한백지 측 회수 명분 강화, 사용자 공동체의 불신 증가.
- 서사 효과: 제8부 해결은 재련 성공이 아니라 서로 다른 생활 기술을 연결하는 방식이어야 함.
