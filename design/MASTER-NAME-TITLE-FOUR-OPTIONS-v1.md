# 《팔대신병록》 여성 사부 본명·별호·사적 호칭 4안 v1

상태: `four-options / PM-MN-A-recommended / collision-search-pending`

전제:

- 여성 현장 구조 무인
- 서유휘의 친모·혈연 아님
- 명문 장문인이나 황실 비밀 고수 아님
- 별호가 인물보다 먼저 설명되지 않음
- 서유휘는 평소 `사부`라고 부르고, 감정이 깨질 때만 본명을 사용할 수 있음

---

## MN-A — 연소담 / 선보

### 본명

**연소담**

인상:

- 부드러운 음성과 현장의 단단함이 함께 있음
- 서유휘·윤겸·양소홍과 소리 충돌이 적음
- 지나치게 장중하거나 악역처럼 들리지 않음

### 강호 별호

**선보(先步)**

뜻:

- 남보다 먼저 한 발 움직이는 사람
- 승부보다 재난 현장에서 먼저 도착한다는 기억

사용:

- 강호 고수는 `선보`라 부름
- 나루 사람은 `연 사부`, `연씨`라고 부를 수 있음
- 별호가 천하제일 무공을 뜻하지 않음

### 서유휘의 사적 호칭

- 평소: `사부`
- 어린 시절: `사부님`보다 짧은 `사부`
- 분노가 극에 달할 때: `연소담`

대표 관계 효과:

> 700화 넘게 `사부`라고 부르던 서유휘가 처음 본명을 부르는 순간 자체가 관계 사건이 된다.

판정: `PM 1순위`

---

## MN-B — 진하목 / 한발

### 본명

**진하목**

인상:

- 성별을 과도하게 설명하지 않는 중성적 이름
- 현장 책임자·떠돌이 고수의 거친 느낌

### 현장 별칭

**한발**

- 나루·구조 인부들이 붙인 생활 별명
- 정식 강호 별호는 없거나 후대 기록이 `일보(一步)`로 한자화

### 사적 호칭

- 서유휘: `사부`
- 양소홍: `하목`
- 위담: `진씨`

장점:

- 생활형·트렌디한 말맛
- 강호 별호의 과장 감소

위험:

- `한발`이 가볍거나 코믹하게 들릴 수 있음
- 진하목의 음성이 현대 한국 이름처럼 느껴질 수 있음

판정: `field-strong / tone-test-needed`

---

## MN-C — 담여진 / 반각

### 본명

**담여진**

인상:

- 고전 무협색을 조금 더 남김
- 강한 여성 고수의 무게

### 강호 별호

**반각(半刻)**

유래:

- 재난 현장에서 반각 먼저 움직여 수백 명을 살렸다는 말
- 실제로는 영웅담이 과장한 이름이며, 사부는 싫어함

### 사적 호칭

- 서유휘: `사부`
- 강호: `반각 담여진`
- 고유선: 본명만 부름

장점:

- 정통 무협의 별호 감각이 강함
- 빠른 구조 방식과 잘 맞음

위험:

- 다시 올드한 번역 무협 인상
- 시간 단위 설명이 필요할 수 있음

판정: `classic-strong / old-tone-risk`

---

## MN-D — 고서린 / 무문

### 본명

**고서린**

인상:

- 날카롭고 차가운 첫인상
- 실제 행동은 사람 이름을 기억하는 구조자라 대비 가능

### 강호 별호

**무문(無門)**

유래:

- 어느 문파에도 속하지 않음
- 막힌 곳에서도 출구를 찾았다는 이중 의미

### 사적 호칭

- 서유휘: `사부`
- 문파 세계: `무문`
- 현장 사람: `고씨`

장점:

- 가짜 문파와 `문이 없다`는 관계가 생김
- 기억하기 쉬움

위험:

- 무문관·선종·기존 무협 용례 연상 가능성 높음
- 주제어 `문`을 과점

판정: `symbolic-strong / collision-risk`

## PM 권고

**MN-A 연소담 / 선보**

권고 이유:

1. 여성 사부의 부드러움과 냉정한 구조 판단을 한 이름에 담기 좋다.
2. `선보`가 화려한 무공보다 먼저 움직이는 삶을 뜻한다.
3. 서유휘가 본명을 부르는 장면에 감정적 힘이 생긴다.
4. 가짜 문파·팔대신병·최종 수운 도시 이름과 음성 충돌이 적다.
5. 별호를 본문 전면에 자주 쓰지 않아도 된다.

필수 충돌 검색:

- 동명 웹소설·웹툰 주요 인물
- 실존 유명인
- 게임·무협 캐릭터
- `선보`의 일반 명사·종교·무술 용례

현재 정본 아님.
