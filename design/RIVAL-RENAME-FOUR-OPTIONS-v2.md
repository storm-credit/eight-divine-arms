# 《팔대신병록》 라이벌 재명명 4안 v2

상태: `four-options / PM-RN-A-recommended / user-veto-pending`

배경:

- 기존 작업명 윤겸은 영화 《물괴》의 중심 무사와 장르 인물 사용이 확인되어 정식명 후보에서 내린다.
- 역할·성격·무당 계통·성별 작업값은 유지하고 이름만 다시 고른다.

인물 고정 기능:

- 남성 작업값
- 무당산 특정 궁관·속가 계통
- 부드럽고 사교적이지만 승부·규칙에는 냉정
- 서유휘의 발자리 원리를 처음 파훼
- 자기 문파를 사랑하지만 명령을 맹신하지 않음
- 초반 로맨스 계약 없음

## RN-A — 소겸(蕭謙 작업 한자)

### 음성

- 두 음절이라 짧고 기억하기 쉬움.
- 서유휘와 리듬이 다르고, 하진·곽소무·두약란과도 구분됨.
- 부드러운 겉태도와 절제된 검법에 잘 맞음.

### 한자 작업값

- 성 소(蕭)
- 이름 겸(謙)

`겸손하다`는 뜻을 대사로 설명하지 않는다. 실제로 예의 바르지만 승부에서는 양보하지 않는 반어가 생긴다.

### 충돌 감사

- 공개 장르 검색에서 널리 알려진 무협 핵심 캐릭터 충돌은 두드러지지 않음.
- 고려 사료에 금나라 사신 소겸(蕭謙)이 등장하는 역사 인명 사례가 있음.
- 동일 역사 인명의 구체 이력·관직을 차용하지 않으므로 현재 위험은 낮음.

### 대표 호명

- 문파: `소 사형`, `소 사숙` 등 관계에 따라 변화
- 서유휘: 초반 `소 공자`를 비꼬듯 사용 가능, 이후 대부분 본명
- 대외: `무당의 소겸`보다 특정 궁관 이름과 함께 소개

장점:

- 기존 윤겸의 절제된 인상을 거의 보존.
- 올드한 3음절 영웅명보다 가볍고 현대 독자에게 읽기 쉬움.
- 정통 무협의 중국계 성씨 감각 유지.

위험:

- 사부 연소담의 이름 안 `소`와 양소홍의 이름 일부가 겹침.
- 대화에서 양소홍을 대부분 `주인장`, 사부를 `사부`로 불러 실제 혼동을 줄인다.

판정: `PM 1순위`

## RN-B — 담겸(譚謙 작업 한자)

### 음성

- 차분하고 조용한 인상.
- 소겸보다 조금 더 낯설고 문인형으로 들림.

### 충돌 감사

- 공개 검색에서 두드러진 장르 핵심 인물 충돌은 확인되지 않음.
- 희귀한 현대 인명 사용 사례는 존재.

장점:

- 주요 인물과 첫 음절 충돌이 적음.
- 검법의 기다림과 신중함에 적합.

위험:

- `담율` 같은 현대 작명 느낌과 가까울 수 있음.
- 강남 젊은 검객의 선명한 첫인상이 약함.

판정: `clean-but-soft`

---

## RN-C — 류겸(柳謙 작업 한자)

### 음성

- 고전 무협에서 익숙한 류씨 성과 짧은 이름.
- 유연하고 정석적인 검법 이미지.

### 충돌 감사

- 한국 역사 인물 류겸 사례가 있음.
- 현재 웹툰 창작자·필명 사용 사례도 검색됨.
- 유명 장르 캐릭터 직접 충돌은 윤겸보다 낮지만 식별력이 충분히 높지는 않음.

장점:

- 정통 무협 독자가 즉시 인명으로 받아들임.
- 무당 검객 이미지와 자연스럽게 어울림.

위험:

- 너무 익숙하고 평범함.
- 실존·필명 사용이 소겸보다 많음.

판정: `usable / not-distinctive`

---

## RN-D — 담율(譚律 작업 한자)

### 음성

- 규칙과 박자를 중시하는 라이벌 기능에 의미상 잘 맞음.
- 짧고 트렌디한 소리.

### 충돌 감사

- 세무·법률·상업 상호와 현대 아동 이름 사용이 다수 확인됨.
- 장르 캐릭터 직접 충돌은 낮음.

장점:

- 서유휘와 음성 대비가 좋음.
- `율`의 박자·규칙 이미지가 검법에 어울림.

위험:

- 지나치게 현대 한국 이름처럼 들림.
- 이름이 인물 기능을 노골적으로 설명.
- 상호 검색 결과가 많아 고유성이 낮음.

판정: `tone-reject / archive-only`

## 폐기 후보 기록

- 윤겸: 영화·장르 인물 충돌
- 위겸: 게임 NPC 충돌 + 위담과 음성 충돌
- 백규: 역사 인물 연상 과다
- 백유현: 최근 무협 주인공 충돌
- 진율: 기존 무협 《천위》 주인공 충돌
- 강무연: 네이버 무협 《흑객》 주인공 충돌
- 류담: 유명 배우·소설가 실명
- 연백: 동명 로맨스 판타지 제목

## PM 권고

**소겸**

적용:

- 기존 문서의 윤겸 역할을 소겸으로 교체.
- 과거 파일을 모두 즉시 치환하지 않고 현재 우선순위·통합 바이블·대시보드에서 먼저 오버라이드.
- 정본 병합 때 구버전 윤겸 표기를 일괄 정리.

대표 대사 작업값:

> “다시 겨루고 싶군요. 이번에는 남의 이름 말고, 본인 이름으로 오십시오.”

이 대사는 음성 검사 후보이며 원고가 아니다.

현재 정확한 표현:

> **라이벌의 역할은 유지하되 윤겸 이름은 폐기한다. PM 새 작업명은 소겸이며, 사용자 검토와 최종 충돌 검색 전에는 정본이 아니다.**
