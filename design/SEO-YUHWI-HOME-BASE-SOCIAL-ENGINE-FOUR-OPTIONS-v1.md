# 《팔대신병록》 서유휘 귀환 거점·관계 집단 4안 v1

상태: `four-options / longform-social-engine / human-edit-pending`

## 1. 설계 기준

1000화 장편의 거점은 단순한 장소가 아니다.

- 독자가 다시 만나고 싶은 사람이 남는 곳
- 주인공이 돌아왔을 때 변화가 보이는 곳
- 돈·식사·치료·수련·정보·갈등이 자연스럽게 생기는 곳
- 대서사부가 끝난 뒤 성과와 손실이 누적되는 곳
- 주인공을 묶어 두지 않고 강호 여행을 가능하게 하는 곳

## 2. H-A — 강남의 작은 무관

구조:

- 문을 닫기 직전인 하급 무관
- 서유휘의 사부가 과거 잠시 머물렀거나 이름을 빌려 준 곳
- 정식 문파 제자가 되지 못한 청년·상인 자제·부상 무인·고아가 섞여 있음

반복 인물:

- 현실적인 관주
- 실력은 없지만 눈치 빠른 사범대리
- 서유휘를 무서워하면서 따르는 첫 제자 후보
- 라이벌 무관의 젊은 고수
- 치료비를 외상으로 달아 놓는 의원

반복 사건:

- 무관 대항전
- 제자 모집·이탈
- 지역 상단과의 갈등
- 문파 추천권·비무 초청권
- 서유휘가 없는 동안 거점이 스스로 버티는 문제

장점:

- 성장 상태가 눈에 보임
- 사제·동료·후배 관계를 만들기 쉬움
- 정통 무협과 웹소설의 반복 보상에 모두 적합

위험:

- 육성·학원물처럼 보일 수 있음
- 《화산귀환》·《일타강사 백사부》의 표면을 연상시킬 수 있음

## 3. H-B — 객잔 겸 임시 무림 중개소

구조:

- 장강 수로와 육로가 만나는 도시의 낡은 객잔
- 주인은 서유휘의 친족이나 사부의 옛 동료
- 무인·상인·개방 제자·도망자·관부 사람이 드나듦
- 서유휘는 방값을 갚기 위해 사건에 끼어듦

반복 인물:

- 돈 계산에 엄격한 객잔 주인
- 소문을 사고파는 점소이
- 장기 투숙 중인 정체불명의 노인
- 늘 외상인 젊은 검객
- 술만 마시면 사라지는 라이벌

반복 사건:

- 객잔 싸움과 소문
- 의뢰가 아니라 부탁·빚·은원으로 시작되는 사건
- 도망자를 숨길지 넘길지
- 강호 인물이 재등장하는 자연스러운 접점
- 객잔이 중립지대가 되며 생기는 공격과 보호

장점:

- 《용비불패》·고룡식 인물 등장과 말맛에 유리
- 생활 유머와 긴장 완급이 좋음
- 강호 전체가 드나드는 작은 무대가 됨

위험:

- 주인공의 집단 성장 보상이 약할 수 있음
- 점소이·객잔 회귀물과 표면이 겹칠 수 있음
- 서유휘가 사건 해결사로만 소비될 위험

## 4. H-C — 버려진 산문 아래의 공동 연무장

구조:

- 명문 문파의 정식 산문은 아니지만 여러 소문파가 함께 쓰는 산 아래 연무장
- 비무·장터·숙소·치료소가 섞인 강호 공동 구역
- 누구나 돈을 내거나 품을 팔면 잠시 머물 수 있음
- 서유휘가 여러 사승과 무공을 접하지만 어느 한 문파에도 완전히 속하지 않음

반복 인물:

- 산문을 관리하는 노무사
- 각기 다른 문파의 후기지수
- 늘 시비를 거는 명문 제자
- 실전을 두려워하는 천재
- 패배 뒤에도 계속 돌아오는 라이벌

반복 사건:

- 공개 비무
- 문파 간 추천·징계·영입
- 사승 갈등
- 무공 교환과 금지
- 대회 전후의 암투

장점:

- 정통 무협 표면이 가장 강함
- 다양한 문파를 소개하기 쉬움
- 서유휘의 무공 성장과 라이벌 축이 선명함

위험:

- 생활 거점보다 무대 기능이 강함
- 새 인물이 너무 많이 등장할 위험
- 학교·아카데미처럼 보일 수 있음

## 5. H-D — 이동하는 작은 동행단

구조:

- 고정 건물이 아니라 서유휘와 함께 움직이는 4~7명의 장기 동행단
- 무인·의원·개방 정보꾼·상인·도망자 등 기능과 욕망이 다름
- 부마다 일부가 남고 새 사람이 합류하지만 핵심 3~4명은 유지
- 특정 도시의 객잔이나 무관을 계절별 귀환점으로 사용

반복 인물:

- 서유휘와 정반대인 정통 검객
- 돈과 안전을 우선하는 정보꾼
- 사람을 살리지만 싸움을 싫어하는 의원
- 서유휘를 경쟁자로 보는 젊은 고수

반복 사건:

- 강호 여행
- 동행 목적 충돌
- 헤어짐과 재회
- 각자의 과거가 다음 대서사부를 여는 구조
- 전투 뒤 누가 남고 떠나는가가 보상과 손실이 됨

장점:

- 김용식 강호 여행과 인물 교차에 가장 강함
- 주인공을 한곳에 묶지 않음
- 관계 변화가 직접적인 연재 엔진

위험:

- 돌아갈 고정 거점과 집단 성장 상태가 약함
- 동료가 많아지면 주인공성이 흐려짐
- 파티형 판타지처럼 보일 위험

## 7. PM 권고

### 권고: H-B 객잔 + H-D 이동 동행단

통합 구조:

> 서유휘는 장강 변의 낡은 객잔을 돌아갈 곳으로 삼고, 사건마다 몇 사람과 함께 강호를 떠돈다. 떠날 때는 서유휘 혼자였지만 돌아올 때마다 객잔에 한 사람이 더 남는다.

핵심 차별점:

- 망한 문파 재건이 아님
- 객잔은 문파 본부가 아니라 사람들이 돌아오는 생활 거점
- 강호행은 동행단이 담당하고, 누적 성장은 객잔의 사람·방·빚·명성·적이 담당
- 서유휘는 장문인이나 사부 역할로 고정되지 않음
- 객잔이 커지는 것이 아니라 그곳을 자기 집이라 부르는 사람이 늘어남

장기 보상 지표:

- 빈방 수가 줄어듦
- 외상 장부의 이름이 늘거나 지워짐
- 객잔을 지키는 사람이 생김
- 강호 인물이 중립 장소로 인정함
- 적이 객잔을 공격하기보다 거래하거나 경계하기 시작함

## 8. 금지

- 매 사건을 객잔 의뢰로 시작
- 주인공이 모든 동료를 구제하고 가르치는 완벽한 리더가 됨
- 조연을 기능 슬롯으로만 사용
- 거점이 커질수록 회계·운영 설명이 전면화
- 유명 작품의 점소이·문파 재건 표면을 복제
