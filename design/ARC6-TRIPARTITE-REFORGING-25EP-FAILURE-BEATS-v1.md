# 1. 제6부 전면 원칙

제6부의 질문은 `누가 신병을 가져야 하는가`에서 시작하지만 결말은 소유자 선발이 아니다.

> 신병을 한 사람에게 맡기지 않으면서도, 지금 사람을 살리는 기능까지 망치지 않을 수 있는가?

삼분 재련 후보 기능:

1. **감지:** 다른 신병의 움직임과 사용자의 위험을 느낌
2. **보호:** 현재 사용자가 폭주·반동으로 죽지 않게 일부 충격을 받아 냄
3. **명령:** 다른 신병 사용자에게 짧은 박자를 밀어 넣음

목표:

- 명령 기능은 한 세력이 독점하지 못하게 약화·분산.
- 감지와 보호 기능은 가능한 한 생활 공동체에 남김.
- 완전한 해체나 파괴는 실패로 본다.

필수 참여:

- 현재 사용자 석아문
- 장인
- 의원 두약란 또는 현지 의원
- 서유휘
- 먼 지역 사용자 최소 2명
- 각 지역에서 독립 판단할 동료

# 2. 621~645화 — 사람을 먼저 빼낸다

## 직접 목표

> 산길에서 석아문과 피난민을 세 세력보다 먼저 안전한 곳으로 옮긴다.

### 621~625화

- 신병이 울릴 때마다 석아문의 팔이 자기 의지와 다르게 멈춤.
- 정파·사파·관부의 세 추격대가 서로 다른 명분으로 접근.
- 서유휘는 물건보다 피난민을 먼저 빼기로 결정.

보상:

- 신병이 보물보다 사람의 몸에 붙은 위험이라는 사실 즉시 제시.

### 626~630화

- 석아문은 신병을 놓으면 보호 기능도 사라질까 두려워 협력을 거부.
- 피난민 일부는 서유휘가 현상범이라며 떠남.
- 백리현이 문파 추적대의 속도를 늦추지만 합류하지 않음.

### 631~635화

- 첫 강제 동작의 약한 전조.
- 석아문이 자기 사람을 밀쳐 위험 구간으로 보낼 뻔함.
- 서유휘는 신병을 빼앗지 않고 석아문의 몸을 제압.

손실:

- 석아문이 서유휘를 믿지 않음.
- 사용자 팔의 신경 손상이 시작.

### 636~640화

- 하진이 세 추격대에 서로 다른 이동 정보를 흘림.
- 피난민들이 나뉘어 움직여야 살아남는 상황.
- 서유휘의 `여러 발자리 연결`이 실제 피난에 사용.

### 641~645화

- 산길 탈출 성공.
- 정파 측 백무진이 피난민을 공격하지 않고 길을 열어 줌.
- 서유휘는 백무진이 단순 악인이 아님을 확인.

결산:

- 석아문 조건부 협력.
- 첫 승리지만 신병의 보호 기능 없이는 석아문이 위험하다는 사실 확인.

# 3. 646~670화 — 좋은 사람에게 맡기면 되는가

## 직접 목표

> 공개 회수판에서 어느 세력도 신병을 즉시 가져가지 못하게 한다.

### 646~650화

- 백무진이 여러 문파·상단·사용자 대표가 참여하는 임시 보관안을 제시.
- 실제로 공정하고 현실적인 안처럼 보임.

### 651~655화

- 사파는 정파가 바뀌면 약속도 바뀐다고 반발.
- 관부는 전쟁 위험을 이유로 압수를 요구.
- 석아문 공동체는 외부 누구도 믿지 않음.

### 656~660화

- 서유휘는 공개 비무·경매·협상을 한 판으로 합치려는 세력을 방해.
- 힘센 한 사람을 뽑아 해결하는 구조를 깨뜨림.

보상:

- 백무진과 서유휘가 잠시 같은 편으로 움직임.

### 661~665화

- 신병이 먼 사용자 두 명의 통증에 반응.
- 현재 장소의 선택이 다른 지역 사람에게 영향을 준다는 사실 공개.

### 666~670화

- 서유휘가 `누구에게 줄지`가 아니라 `무엇을 남기고 무엇을 없앨지`를 목표로 제안.
- 석아문은 물건을 부수지 않는다는 조건으로 동의.

결산:

- 삼분 재련팀 구성.
- 장소는 본부가 아니라 임시 장인 작업장.

# 4. 671~695화 — 첫 재련 실패

## 직접 목표

> 명령 기능을 찾되 보호 기능을 건드리지 않는다.

### 671~675화

- 장인은 물건의 세 기능이 부품 세 개처럼 깔끔히 분리되지 않았다고 설명.
- 같은 금속 결·사용 습관·석아문 몸의 반응이 얽혀 있음.

### 676~680화

- 첫 시험.
- 감지 울림을 약하게 만들자 석아문의 통증은 줄지만 먼 사용자 한 명이 갑자기 균형을 잃음.
- 시험 중단.

### 681~685화

- 두약란이 `물건을 고치는 순서`보다 `사용자의 몸이 버티는 순서`를 우선하라고 요구.
- 장인과 의원이 충돌.
- 서유휘가 장인 편을 들었다가 석아문이 쓰러짐.

치명적 실수:

- 서유휘가 신병 구조를 먼저 보고 사람의 반응을 늦게 봄.

### 686~690화

- 보호 기능이 잠시 끊기며 석아문의 옛 부상이 한꺼번에 되살아남.
- 먼 지역 연화진에게 같은 손목 통증이 전이.
- 제2부 첫 신병 사용자까지 후반 인과에 연결.

### 691~695화

- 첫 재련 실패 선언.
- 장인 도구 하나가 망가져 다시 구할 수 없음.
- 석아문은 오른손 감각 일부를 영구적으로 잃을 가능성.
- 연화진은 서유휘에게 작업 중단을 요구.

실제 손실:

- 보호 기능 완전 복원 불가 가능성.
- 동료 신뢰 하락.
- 작업 위치가 세 세력에 노출.

# 5. 696~720화 — 세 사람이 각각 멈출 권리

## 직접 목표

> 한 번에 기능을 뜯지 않고, 사용자 세 명이 각자 멈출 수 있는 방법을 만든다.

### 696~700화

- 서유휘가 작업 책임을 혼자 지려 함.
- 두약란과 석아문이 거부.
- 현재 사용자와 먼 사용자 모두 작업 중단권을 가져야 한다는 조건 확정.

### 701~705화

세 역할 분담:

- 석아문: 현재 물건의 몸 반응 확인
- 연화진: 먼 지역 감지 울림 확인
- 세 번째 사용자 후보: 명령 박자 반응 확인

서유휘는 세 사람의 신호를 연결하지만 결정권을 갖지 않음.

### 706~710화

- 사용자별 다른 거부 동작 시험.
- 같은 동작을 가르쳤을 때 오히려 울림이 강해지는 실패.
- 사부 방식은 같은 박자를 강요할수록 강하다는 단서.

### 711~715화

- 각자 생활 무공과 습관에서 다른 거부 동작을 찾음.
- 연화진은 조타 손바꿈.
- 석아문은 산길 지팡이 놓기.
- 다른 사용자는 호흡 멈춤이 아닌 발끝 박자 변경.

보상:

- 거부 동작 첫 성공.
- 사부 강제 연결에 대한 실제 대응의 씨앗.

### 716~720화

- 명령 기능이 한 점에 모이지 않도록 세 부분으로 약화.
- 감지·보호·명령을 `세 물건`으로 깔끔히 나누지 않음.
- 사람·사용법·도구에 각각 불완전하게 남김.

손실:

- 보호 기능은 이전보다 약해짐.
- 석아문은 신병을 오래 사용할 수 없게 됨.

# 6. 721~750화 — 세 지역, 서로 다른 실패

## 직접 목표

> 세 지역에서 동시에 진행되는 회수 작전을 막고, 약화된 기능이 한곳에 다시 모이지 않게 한다.

### 721~725화

세 지역 작전 시작:

1. 산길 사용자와 보호 기능
2. 장강 사용자와 감지 기능
3. 문파·관부가 노리는 명령 흔적

서유휘는 한 지역만 직접 갈 수 있음.

### 726~730화

- 서유휘는 가장 위험해 보이는 명령 흔적 쪽을 선택.
- 하진은 정보망을 맡음.
- 백리현·문사연은 문파 추격을 막음.
- 연화진은 장강에서 자기 판단으로 경로 변경.

### 731~735화

첫 지역 결과:

- 연화진이 감지 기능 일부를 지키지만 상단에 현재 위치가 드러남.
- 완전한 승리 아님.

### 736~740화

두 번째 지역 결과:

- 백리현이 문파 회수대를 막지만 백무진이 명령 흔적 일부를 확보.
- 백무진은 독점하려는 것이 아니라 위험을 확인하려 가져감.
- 적에게 빼앗긴 단순 실패가 아니라 다음 갈등의 정당한 균열.

### 741~745화

세 번째 지역 결과:

- 석아문이 보호 기능을 살리기 위해 예정된 분산을 일부 거부.
- 그 선택 때문에 명령 흔적이 완전히 사라지지 않음.
- 서유휘는 강제로 계속하지 않고 석아문의 선택을 인정.

### 746~750화

결산:

- 어느 한 세력도 전체 기능을 얻지 못함.
- 세 기능은 약화되고 서로 떨어짐.
- 사용자들은 각자 거부 동작을 가짐.
- 보호 기능은 불완전하지만 생존 가능.
- 명령 흔적 일부가 남아 있음.
- 흩어지는 순간 여덟 신병 흔적이 같은 박자로 한 번 울림.
- 사부가 개입할 조건이 처음 완성됨.

제6부 승리:

- 독점 방지.
- 동료 독립 행동.
- 사용자 선택권 유지.

제6부 실패:

- 보호 기능 약화.
- 석아문 영구 손상 후보.
- 백무진이 일부 흔적 확보.
- 사부 발동 조건 개방.
- 서유휘 네트워크 위치 일부 노출.

# 7. 실패가 이후에 남는 방식

## 제7부

- 석아문은 전투 핵심 고수가 아니라 거부 동작을 가르치는 사람으로 역할 변화.
- 연화진은 통증 전이 때문에 첫 강제 연결을 가장 빨리 감지.
- 백무진이 가진 흔적이 사부 신호점으로 이용될 위험.
- 두약란은 재련을 성공으로 부르지 않음.

## 제8부

- 보호 기능 약화 때문에 사용자들이 마지막 전투에서 신병을 오래 쓰지 못함.
- 각 지역은 짧은 사용과 교대를 선택.
- 서유휘가 혼자 절정 초식을 쓰면 빠르지만, 여러 사람에게 시간을 나눠야 하는 물리 이유가 됨.

# 9. 금지

- 첫 실패가 사실 계획된 성공이었다는 반전.
- 석아문 손상이 다음 기연으로 완전 회복.
- 서유휘가 마지막 순간 혼자 정확한 부품을 찾아 해결.
- 장인·의원이 설명만 하고 선택하지 않음.
- 세 지역이 모두 완벽히 성공.
- 백무진이 일부 흔적을 얻었다는 이유만으로 갑자기 악역화.
- 사부가 제6부 전 과정을 이미 예상했다는 전지적 계획.
