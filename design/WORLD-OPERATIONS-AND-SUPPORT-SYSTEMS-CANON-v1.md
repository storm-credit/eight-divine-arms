# 《팔대신병록》 세계 운용·보조 체계 정본 v1

작성일: `2026-08-01`

## 1. 경제·생계

- 화폐 숫자는 장면 필요 때만 사용하고 기본 비교 단위는 `한 끼 / 하루 숙박 / 일반 치료 / 내상 치료 / 배 한 척`이다.
- 서유휘의 대련비는 한 끼와 숙박을 해결하지만 내상 치료비는 감당하기 어렵다.
- 고급 병기와 비급은 현금 가격보다 신용·접근권·감정서·정치 비용이 크다.
- 보물은 즉시 팔 수 없다. 위조 의심, 압수 위험, 전승자 분쟁, 구매자 보복 때문에 감정·중개·보증이 필요하다.
- 경매는 돈만으로 끝나지 않으며 추천서·보증패·신원·운송 책임이 요구된다.

## 2. 권력 경계

### 관청

- 치안·세금·수운 허가·시신·압수·공개 경매에 권한을 주장.
- 문파 비고와 사승 전승까지 직접 통제하지 못함.
- 대형 재난에서는 군선·창고·나루 폐쇄 권한을 가짐.

### 문파

- 제자·산문·비고·무공 전승·도전 규칙을 관리.
- 지역 주민과 상단에 영향력을 행사하지만 법적 국가기관은 아님.
- 문파 내부 처벌이 관청법과 충돌할 수 있음.

### 상단·수운 공동체

- 배·창고·운송·보험성 공동 부담·노선 정보를 지배.
- 강에서의 실제 생존 권력은 무공보다 조타수·선주·나루 책임자에게 있음.

### 사파·암시장

- 밀수·정보·위조·보호비·신분 세탁을 제공.
- 불법이지만 관청과 문파가 해결하지 못하는 분쟁을 중개.

### 전문망

- 의원·장인·감정가는 작업 중단권과 진위 판정 권위를 가짐.
- 절대 중립은 아니며 의뢰·빚·계보·지역 책임 때문에 선택한다.

## 3. 통신·정보 지연

- 같은 도시: 인편·전령·객잔 게시·종 신호, 수 시간~하루.
- 인접 지역: 말·배·상단 전령, 수일.
- 강남↔무당산권 등 장거리: 수 주.
- 비밀 정보는 암호 매듭·절반 인장·분할 서신을 사용하며 중간 탈취 위험이 있다.
- 신병 공명은 통신이 아니다. 정해진 신호와 박자를 전달할 뿐 내용·생각을 전하지 못한다.
- 지연은 플롯 장식이 아니라 잘못된 판단·중복 구조·배신 오해를 만든다.

## 4. 소유·압수·경매·상속

- 발견권: 먼저 찾았다는 사실만으로 소유권이 완성되지 않는다.
- 제작권: 장인 계보와 제작 기록이 주장 근거가 된다.
- 전승권: 문파·가문·제자의 계승 문서가 근거가 된다.
- 사용권: 현재 사용자가 공동체 기능을 유지했다면 강한 정당성을 가진다.
- 공공 기능권: 나루·수문·교량·의료와 연결된 신병은 개인 반출이 제한된다.
- 압수권: 관청은 재난·살인·밀수 증거일 때 압수할 수 있으나 진품 판정과 보관 능력이 부족하다.
- 경매권: 합법 경매도 도난품·전승품이면 분쟁이 지속된다.
- 상속권: 혈연만이 아니라 제자·공동체·기능 계승이 경쟁한다.

최종 처분은 `소유 / 사용 / 중단 / 기록 / 증언` 권리를 분리할 수 있다.

## 5. 신수·영수 생태

장기 동행 영수 작업명: `연철비` 후보. 정식명은 원고 직전 명명 감사에서 확정 가능.

- 소형 족제비 계열 이수.
- 광맥·쇳가루·기름·숯·약초 냄새를 구별.
- 먹이: 작은 물고기·알·견과·말린 고기.
- 물을 두려워하지 않지만 장시간 수영은 불가.
- 고열 화로 가까이 오래 머물 수 없고 연기에 약함.
- 전투력은 낮으며 경고·추적·도난·생활 소동 역할.
- 서유휘 명령에 자동 복종하지 않고 먹이·안전·신뢰에 반응.
- 장거리 이동 때 휴식·먹이·은신처가 필요.

## 6. 제련·복원 시간과 손실

- 단순 균열 확인: 반나절~수일.
- 일반 병기 수리: 수일~수 주.
- 비급 해독과 부속 복원: 수 주~수개월.
- 신병 핵심 복원: 계절·연료·광석·장인 협업이 필요하며 수개월 단위.
- 급한 수리는 성능·수명·안전 중 하나를 희생한다.
- 재료 손실, 화로 오염, 열처리 실패, 장인 부상, 기록 오류가 실제 실패 원인이다.
- 복원은 원형 복귀만이 아니라 현 사용자와 용도에 맞춘 개조일 수 있다.

## 7. 부상·치료·회복

- 타박·찰과상: 수일, 전투 가능하나 누적 피로 반영.
- 깊은 베임·골절: 수 주, 해당 부위 전투 제한.
- 내상·경맥 손상: 수개월, 강행 시 영구 후유증.
- 독: 종류별 해독 시간과 장기 장기 손상 차등.
- 영약은 시간을 줄이거나 생존 가능성을 높일 뿐 손상을 삭제하지 않는다.
- 서유휘의 왼쪽 어깨·내공 경로 손상은 만성으로 유지.
- 도해원은 작전을 중단시킬 수 있지만 현장 결정을 대신하지 않는다.

## 8. 운용 Gate

- 순간 이동·즉시 소식 금지.
- 보물 즉시 현금화 금지.
- 관청·문파·상단 중 하나가 전권을 갖는 설정 금지.
- 신수의 편의적 단서 발견 반복 금지.
- 장인의 하룻밤 신병 복원 금지.
- 영약의 부상 초기화 금지.
