# 《팔대신병록》 제6부 신병 명령 기능 처리 4안 v1

상태: `four-options / human-edit-pending`
목적: 신병의 명령 기능을 서유휘 혼자 편리하게 제거하는 작위성을 막고, 실패·대가·전문가 협력을 플롯에 포함한다.

## 공통 전제

- 중심 신병은 다른 신병 사용자에게 신호와 압력을 전달할 수 있음
- 기능 전체를 파괴하면 현재 사용자 공동체의 생업·방어 기능도 함께 사라질 수 있음
- 서유휘는 구조를 읽을 수 있지만 단독으로 제거·수리하지 못함
- 최소 세 영역의 협력이 필요함: 현재 사용자, 장인 또는 수리인, 몸의 반응을 보는 의원
- 잘못 처리하면 먼 지역 사용자에게 통증·경련·판단 혼란이 전이
- 처리 순간 사부가 기다리던 결속 신호가 깨어나는 인과가 필요

---

## F-A 명령환 분리형

### 구조

손잡이 또는 중심축 안에 명령 신호를 증폭하는 금속 고리가 따로 존재한다.

### 방법

- 신병을 열어 명령환만 제거
- 기본 감지·생활 기능은 보존
- 제거한 고리는 세 조각으로 나눠 다른 보관처에 둠

### 장점

- 독자가 이해하기 쉬움
- 물리적 장면이 선명
- 제6부 목표가 구체적

### 위험

- 너무 편리한 부품 제거처럼 보임
- 마지막에 다시 조립할 수 있다는 수집 퀘스트 가능성
- 서유휘의 수리 능력이 만능 열쇠로 복귀

### 필수 제약

- 고리는 다른 구조와 달라붙어 있어 제거하면 사용자 몸에도 손상
- 두약란과 현재 사용자가 중단 시점을 결정
- 제거 뒤 기본 기능도 크게 약화

---

## F-B 사용법 봉쇄형

### 구조

명령 기능은 물건 한 부품보다 특정 호흡·손잡이 순서·동작의 조합에서 발생한다.

### 방법

- 물건을 부수지 않음
- 사용 공동체가 명령 동작을 폐기하고 새로운 사용법을 만듦
- 여러 지역에 다른 거부 동작을 전수

### 장점

- 물건보다 사람과 전승을 중시
- 수집·부품 조립 위험이 낮음
- 제7부 강제 연결의 `거부 동작`으로 자연 연결

### 위험

- 물리적 클라이맥스가 약함
- 설명과 훈련 장면이 많아질 수 있음
- 누군가 옛 사용법을 다시 쓰면 해결이 무효화

### 필수 제약

- 새 사용법 습득 중 실제 추격과 전투 발생
- 사용자마다 몸이 달라 하나의 정답 없음
- 옛 사용법을 완전히 잊을 수 없어 심리적 유혹 유지

## F-C 삼분 재련형 — PM 권고

### 구조

중심 신병의 세 기능이 하나의 축에 겹쳐 있다.

1. 주변 신병 감지
2. 현재 사용자 보호
3. 다른 사용자에게 명령 압력 전달

세 기능을 완전히 분리할 수 없고, 재련 과정에서 하나는 반드시 약화된다.

### 방법

- 현재 사용자 석아문이 신병을 계속 잡고 몸의 반응을 견딤
- 장인이 축을 세 방향으로 갈라 세 개의 불완전한 매개체로 재련
- 두약란이 먼 사용자들의 반응과 현재 사용자의 한계를 판단
- 서유휘와 동료들이 외부 공격을 막고 세 매개체가 각기 다른 길로 빠져나가게 함

### 결과

- 감지 기능: 연화진 또는 수로 공동체가 맡음
- 사용자 보호 기능: 석아문 공동체에 남음
- 명령 기능: 완전 제거되지 않고 매우 약한 경고 신호로 변형
- 어느 한 조각도 단독으로 원래 기능 복구 불가
- 세 조각을 모아도 사용자들의 자발적 동작 없이는 작동하지 않음

### 장점

- 한 세력 독점 방지와 공동체 분산을 물리적으로 보여 줌
- 여러 전문가와 동료가 필요
- 기능을 없애는 대신 대가와 불완전성을 남김
- 처리 순간 세 방향의 울림이 발생해 사부 계획을 깨우는 인과 자연스러움

### 위험

- 재련 과정이 설정 설명으로 길어질 수 있음
- 세 조각이 다시 수집 대상처럼 보일 수 있음
- 장인 기술이 과도하게 판타지화될 수 있음

### 필수 제약

- 재련은 한 번만 가능하고 되돌릴 수 없음
- 세 조각은 전투력 상승 아이템이 아님
- 조각 위치를 장편 미스터리로 끌지 않음
- 재련 원리는 설명보다 불꽃·금속 변형·사용자 몸의 반응으로 보여 줌

## F-D 기능 폐기·대체망형

### 구조

신병 명령 기능을 보존하지 않고 완전히 망가뜨린다.

### 방법

- 중심축을 파괴
- 대신 하진 전령망·연화진 수로 신호·백리현 문파 연락망을 연결해 사람 중심의 느린 대체망 구축

### 장점

- `강제 명령보다 느린 협력`이라는 작품 주제가 선명
- 팔대신병 기능에 의존하지 않는 결말 방향
- 사부와 서유휘의 가치 대비가 직접적

### 위험

- 제6부에 신병을 단순 파괴하는 결론
- 생활·방어 기능까지 잃은 공동체 피해가 큼
- 대체망 구축이 행정·설명 중심이 될 위험

### 적합 조건

- 작품이 신병 기능보다 인간 관계망의 성장에 더 강하게 집중할 경우
- 석아문 공동체의 손실과 배상을 장기적으로 다룰 경우

## 실패 시나리오

### 실패 1 — 현재 사용자 손상

재련 또는 봉쇄 중 석아문의 호흡·신경 경로가 무너져 기능 중단. 서유휘는 계속할지 중지할지 선택해야 한다.

### 실패 2 — 먼 사용자 전이

한 기능을 건드리자 다른 지역 사용자가 동시에 경련. 하진·연화진·백리현이 각 지역에서 사람을 보호해야 한다.

### 실패 3 — 외부 세력 개입

백무진 또는 다른 세력이 `실패하기 전에 중립 보관으로 넘기라`며 공격. 그의 주장이 실제로 합리적이라 내부 동료도 흔들림.

### 실패 4 — 기능 오인

제거하려던 부분이 명령 기능이 아니라 현재 사용자를 보호하는 기능이었음이 드러남. 서유휘의 판별이 틀릴 수 있음을 명확히 한다.

## PM 권고

**F-C 삼분 재련형에 F-B의 거부 동작을 결합.**

- 물건의 기능을 세 갈래로 약화·분산
- 사람마다 다른 거부 동작을 함께 전수
- 물건만 모아서는 원래 강제 명령을 복구할 수 없음
- 서유휘 혼자 해결하지 못함
- 제7부에서 사부는 약한 경고 신호와 옛 사용법을 이용해 강제 결속을 시도

## 본문 표현 원칙

설계어:

- 명령 기능
- 감지 기능
- 사용자 보호 기능
- 삼분 재련

본문 행동어:

- 칼이 먼 곳의 칼에 울림
- 사용자의 손이 자기 뜻과 다르게 움직임
- 쇠가 세 방향으로 갈라짐
- 한 사람의 통증이 다른 지역 사람에게 번짐
- 옛 손잡이 순서를 거부하는 새 동작

본문에서 기능표를 대사로 설명하지 않는다.
