# 《팔대신병록》 사부 강제 연결 한계 4안 v1

상태: `four-options / human-edit-pending`
목적:

> 사부의 힘이 천하 어디서든 누구든 조종하는 만능 능력이 되지 않도록, 시작 조건·거리·인원·명령 복잡도·지속·대가·대응법을 고정한다.

본문에서는 `강제 연결 시스템` 같은 말을 쓰지 않는다.

독자가 보는 현상:

- 떨어진 신병 사용자들이 같은 순간 같은 방향으로 몸을 돌림
- 본인이 멈추려 해도 한 번의 동작이 끝날 때까지 멈추지 못함
- 서로 모르는 사람들이 같은 통증과 호흡을 느낌
- 사부가 긴 명령을 말하는 것이 아니라 짧은 움직임 하나를 강요

정본 아님.

---

# 1. 공통 금지

- 생각과 기억을 읽음
- 복잡한 전투를 원격 조종
- 무한 거리·무한 인원
- 일반 무인까지 이유 없이 조종
- 사부가 아무 준비 없이 즉시 발동
- 연결된 사람이 완전히 의식을 잃은 인형이 됨
- 한 번 연결되면 영구 지배

필수:

- 사용자가 자기 의식으로 저항함
- 단순한 동작일수록 강하고, 복잡할수록 실패
- 사용자 몸과 신병에 미리 남은 조건이 필요
- 연결할수록 사부 자신도 몸과 판단이 무너짐
- 제6부 서유휘 선택이 제7부 발동 가능성을 높임

---

# 2. L-A — 흔적이 남은 사용자만 연결

## 시작 조건

사부는 아무 신병 사용자나 잡을 수 없다.

다음 중 하나가 있어야 한다.

- 과거 중심 신병과 직접 맞닿은 적이 있음
- 제6부 삼분 재련 때 같은 울림을 공유함
- 사부가 과거 남긴 금속 표식·수리 흔적이 신병 안에 남음

몸에도 흔적이 생긴다.

- 특정 관절의 통증
- 같은 박자의 이명
- 위기 때 반복되는 손동작

## 범위

- 흔적이 있는 핵심 사용자 최대 여덟 명.
- 주변 동료는 통증·균형 상실 같은 약한 영향만 받음.
- 일반 무인에게 직접 명령 불가.

## 명령

한 번에 한 가지 단순 동작.

예:

- 칼을 내린다.
- 문을 닫는다.
- 세 걸음 앞으로 간다.
- 손을 놓는다.

불가:

- 누구를 죽여라.
- 어느 길로 도망가라.
- 복잡한 검법을 펼쳐라.

## 대가

- 사용자는 동작 뒤 자기 기억과 강제된 감각을 잠시 구분하지 못함.
- 같은 흔적이 반복될수록 관절·호흡 경로 손상.
- 사부는 여러 사용자의 통증을 동시에 받아 자기 몸의 위치 감각을 잃음.

## 대응

- 사용자마다 다른 `거부 동작`을 만들어 같은 박자를 끊음.
- 신병의 흔적을 완전히 지우면 보호 기능도 손상될 수 있음.

장점:

- 제6부 삼분 재련이 제7부 위기를 직접 촉발.
- 대상과 인원이 명확.
- 각 사용자 맞춤 대응이 필요.

위험:

- 표식 찾기·제거가 게임 퀘스트처럼 보일 수 있음.

---

# 3. L-B — 신병들이 동시에 울릴 때만 개입

## 시작 조건

사부가 마음대로 연결을 시작하지 못한다.

다음 상황에서 여러 신병이 같은 순간 반응해야 한다.

- 대형 재난
- 다수 사용자의 동시 전투
- 중심 신병 기능의 파손·재련
- 옛 사용 순서가 우연히 재현

사부는 이미 열린 울림에 끼어들 뿐이다.

## 범위

- 울림이 이어지는 지역과 사용자만.
- 산 하나·수로 한 구간처럼 자연·금속 연결이 있는 범위에서 강함.
- 울림이 끊기면 거리와 무관하게 연결 종료.

## 명령

- 처음에는 반사 동작 하나.
- 사부가 릴레이를 준비하면 짧은 연속 동작 가능.

## 대가

- 사부도 발동 시점을 완전히 통제할 수 없음.
- 적이 일부러 동시 울림을 만들면 사부 계획이 앞당겨지거나 왜곡됨.
- 사용자들은 이후 신병을 쓰는 것 자체를 두려워함.

## 대응

- 한 사용자가 일부러 박자를 늦추거나 기능을 멈추면 연결 약화.
- 서로 다른 지역에서 같은 동작 대신 다른 선택을 하면 흐름이 깨짐.

장점:

- 사부가 신처럼 보이지 않음.
- 제6부 성공이 실제로 문을 여는 인과.
- 최종전에서 각 지역 독립 판단이 강한 대응이 됨.

위험:

- `동시에 울림` 조건이 편의적으로 발생할 수 있음.

---

# 4. L-C — 중간 신호점이 있어야 멀리 닿는다

## 시작 조건

먼 거리 연결에는 중간 신호점이 필요하다.

신호점 후보:

- 오래된 종
- 수문 사슬
- 문파 검진의 중심 무기
- 항구 신호탑
- 장인이 남긴 금속 표식

사부는 과거 재난을 막으며 이 점들을 일부 준비했다.

## 범위

- 신호점 하나가 끊기면 그 뒤 지역은 연결에서 빠짐.
- 도시·수로·산문처럼 금속과 사람이 반복 신호를 전달하는 곳에서 강함.
- 황야나 바다 한가운데서는 약함.

## 명령

- 신호점은 명령 내용을 전달하지 않고 박자만 전달.
- 현지 사용자의 몸이 박자를 자기 무공으로 번역하면서 오차 발생.

## 대가

- 신호점 주변 일반인도 이명·멀미·공황을 겪을 수 있음.
- 사부가 강제로 오래 유지하면 신호점이 파손되고 현지 생활 기반도 망가짐.

## 대응

- 신호점을 부수는 것만이 답이 아님.
- 종을 다른 박자로 울리거나, 수문 사슬을 풀거나, 현지 신호를 섞어 명령을 흐림.

장점:

- 장강 수문 도시·무당 종루·항구 신호를 장기 회수.
- 동료들이 각 지역에서 독립 역할을 가짐.
- 최종전이 여러 물리 장면으로 분산됨.

위험:

- 모든 장소가 사실 사부의 준비였다는 느낌을 줄 수 있음.
- 신호점 설명이 설정집처럼 보일 수 있음.

---

# 5. L-D — 사부가 대신 치르는 몸의 값

## 시작 조건

사부는 연결할 사용자와 한 번 이상 직접 호흡·무공을 맞춘 적이 있어야 한다.

## 범위

- 인원은 적지만 한 사람에게 강함.
- 여럿을 연결할수록 동작은 단순해짐.

## 대가

사부는 사용자의 강제 동작을 자기 몸에도 동시에 재현한다.

- 사용자의 팔을 들게 하면 사부의 같은 팔도 움직임.
- 사용자가 상처를 입으면 사부도 일부 통증과 근육 손상을 받음.
- 여러 방향의 동작이 겹치면 사부의 몸이 실제로 찢어질 수 있음.

사부가 강한 이유는 고통을 느끼지 않아서가 아니라, 느끼면서도 명령을 유지할 수 있기 때문이다.

## 대응

- 사용자들이 서로 다른 방향의 거부 동작을 하면 사부 몸에 충돌이 생김.
- 다만 이를 이용해 사부를 고문하는 전개로 소비하지 않음.

장점:

- 사부가 비용 없이 사람을 조종하지 않음.
- 최종 대결의 몸과 감정이 강함.

위험:

- 고통을 감당하는 사부가 지나치게 영웅적으로 보일 수 있음.
- 능력 규칙보다 정신력 대결이 될 가능성.

# 6. PM 권고 조합

권고:

> **L-A 흔적 대상 + L-B 동시 울림 시작 + L-C 신호점 거리 확장 + L-D의 사부 신체 대가 일부**

단, 네 안의 장점을 전부 더해 복잡하게 만들지 않고 다음 일곱 규칙만 본선에 노출한다.

## 본선 규칙 7개

1. **대상:** 중심 신병 흔적이 몸과 물건에 남은 핵심 사용자만 직접 연결 가능.
2. **발동:** 여러 신병이 같은 순간 울릴 때만 사부가 개입 가능.
3. **거리:** 먼 지역에는 종·사슬·신호탑 같은 중간 박자가 필요.
4. **명령:** 한 번에 단순 동작 하나. 말·생각·복잡한 초식은 전달 불가.
5. **지속:** 초반에는 한 번의 공방, 최종 준비를 마쳐도 긴 전투 전체를 지배할 수 없음.
6. **대가:** 사용자에게 관절·호흡·기억 혼선, 사부에게 통증·방향 감각 붕괴.
7. **대응:** 사용자 고유 거부 동작, 지역별 다른 박자, 중간 신호 흐리기.

## 수치 작업값

본문 숫자 계급처럼 쓰지 않는다. 연속성 감사용 작업값이다.

- 직접 연결 핵심 사용자: 최대 8명
- 약한 영향 범위: 주변 동료·생활인 수십 명 가능하나 직접 명령 불가
- 첫 발동 지속: 한 번의 단순 동작
- 제7부 중반: 2~3개의 연속 동작
- 최종부: 여러 차례 반복 가능하지만 매번 중간 신호와 사부의 몸이 무너짐
- 연결 재사용: 같은 사용자에게 짧은 시간 반복하면 치명적 후유증

# 7. 장기 설치

## 제2부

- 첫 신병 사용 뒤 연화진의 손목에 낯선 박자 통증.
- 독자는 사부와 연결하지 않음.

## 제3부

- 오래된 영웅담 속 사용자들이 같은 순간 몸을 돌렸다는 짧은 기록.
- 설명하지 않고 기괴한 일화로만 제시.

## 제4부

- 두 신병 동시 작동 때 항구 종이 이유 없이 같은 박자로 울림.
- 나해란이 십 년 전에도 들었다고 반응.

## 제5부

- 문파 검진 중심 무기가 여러 제자의 호흡을 강제로 맞추는 현상.
- 사부 연결의 작은 모형처럼 작동.

## 제6부

- 삼분 재련으로 흩어진 기능들이 처음 같은 울림을 공유.
- 사용자 몸에 흔적이 선명해짐.
- 사부가 개입할 문이 열림.

## 제7부

- 사부가 첫 단순 동작으로 대형 사고를 막음.
- 이후 사용자들이 고유 거부 동작을 배움.

## 제8부

- 사부는 중간 신호를 통해 여러 지역을 맞추려 함.
- 서유휘 측은 신호점을 모두 부수지 않고 각 지역의 다른 박자를 섞음.
- 마지막에는 사부 한 사람의 완벽한 박자보다 여러 사람의 불완전한 박자가 퇴로를 엶.

# 8. 실패 신호

다음이 보이면 능력 축소:

- 사부가 멀리서 전투 승패를 마음대로 결정.
- 사용자가 자기 의지 없이 긴 시간 싸움.
- 신병이 없는 사람까지 같은 방식으로 조종.
- 중간 신호점이 매번 우연히 존재.
- 서유휘가 규칙을 설명 한 번 듣고 완벽히 대응.
- 모든 사용자가 같은 거부 동작을 사용.
- 사부의 고통이 면죄부나 숭고함만 강화.
